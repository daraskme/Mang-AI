# 世界観Bible（テンプレート・雛形ジェネレータ）

新作開始時に本ファイルを参照し、`world-bible/` ディレクトリ一式をコピー作成する。
**単一ファイル管理は廃止**。core / ondemand / log の三層分割で長編・群像劇に耐える設計とする。

下記の汎用ファイル名は作品の世界観に合わせて読み替えてよい（例：魔法のない世界なら `05-magic.md` → `05-abilities.md` 等）。

---

## 1. 設計の核

| 層 | 役割 | Grokでの読み込み | 更新頻度 |
|---|---|---|---|
| **core/** | 全話で参照候補となる世界観の基底（メタ・階級・表記・用語集・全体時系列）| `00-INDEX.md` から当該話に必要なファイルだけ読む | 設定変更時のみ／glossary・年表は末尾追記 |
| **ondemand/** | 話の機能に応じて選択参照する設定（地理・魔法・文化・組織・関係）| シーンカードに関係するファイルだけ読む | 設定追加・変更時 |
| **log/** | 話ごとの確定事項を時系列で記録 | 当該話に必要な確定事項だけ読む | 話完成後に末尾追記（append-only）|

> 各層の運用詳細は本ファイル §3〜§5 を参照。

---

## 2. 新作開始時のディレクトリ構造（コピーして埋める）

```
world-bible/
├── 00-INDEX.md          # ファイル一覧・ビート→読み込み対応表・連結順序固定ルール
├── core/
│   ├── 01-meta.md           # 世界名・時代・視点・通貨・章構造既定
│   ├── 02-class-honorifics.md  # 階級表・敬称・国家別階梯・違反禁則
│   ├── 03-language-notation.md # 記号派閥・ルビ・数字・地名表記・AI出力禁則
│   ├── 04-names.md          # ①既出固有名詞（地理・国家都市・神話・組織系統・種族）append-only
│   ├── 05-magic.md          # ②既出魔法（術式・特典術・現象）＋本文使用実績ログ append-only
│   ├── 06-items.md          # ③既出アイテム（武具・術具・許可札・遺物）＋本文登場実績ログ append-only
│   ├── 07-creatures.md      # ④既出生物・モンスター（種・名前付き個体）＋本文遭遇実績ログ append-only
│   └── 08-timeline.md       # ⑤全体時系列（暦法・史実年表・章別作中日付）＝作中の日付の正本 append-only
├── ondemand/
│   ├── geo-political.md     # 地理・国家配置・気候・街道・海路
│   ├── magic-system.md      # 魔法系統・階位・扱い区分・現象ラベル（概念定義）
│   ├── culture-items.md     # 地域別の物品可否・服飾・建築・食文化・祭礼
│   ├── organizations.md     # ギルド・神殿・商会・中央ダンジョン・騎士団
│   └── relations.md         # 国家間関係・三大論点・種族間関係・キャラロール
└── log/
    └── canon-log.md         # 章ごと確定事項の時系列ログ（append-only）
```

> セットアップ手順：リポジトリのコピー直後に `bash scripts/init-work.sh` を1回実行すると、`00-INDEX.md`・`core/08-timeline.md`・`log/canon-log.md` のスタブと `core/` `ondemand/` ディレクトリが作られる。core/ondemand の各ファイルは本テンプレート §3 の記入指針に従って作成する。

## 3. 各ファイルの記入指針

### 3-1. `00-INDEX.md`
- ファイル一覧（core / ondemand / log を列挙）
- ビート→読み込みファイル対応表（章機能ごとに必要な ondemand を指定）
- 連結順序の固定ルール（cache 破壊防止）
- core の append-only ファイル（04〜08）の更新ルール（append-only 規律）

### 3-2. `core/01-meta.md`
- 世界名・英表記・ジャンル・投稿先・縦横・視点形式の既定
- 既定時代（default era）と時代固定の制約（canon constraints）
- 通貨・度量衡・章構造の既定
- 「参照時の整合性ガード」セクション（生成前に読む）

### 3-3. `core/02-class-honorifics.md`
- 共通階梯（王・公・侯・伯・子・男・騎士・平民の呼称）
- 国家別の独自階梯（神権／樹権／商会／都市評議／軍政等）
- 違反禁則チェックリスト（生成後の自己点検）

### 3-4. `core/03-language-notation.md`
- 記号派閥（三点リーダ・ダッシュ・強調・場面区切り・「！？」後スペース・閉じカギ前句点）
- ルビ運用（投稿先記法）
- 数字表記
- 魔法・術式の表記原則
- 地名・固有名詞の表記方針
- 作中言語と読者表記
- AI出力で残しがちな禁則

### 3-5. `core/04-names.md`（①固有名詞）
- **append-only ガード**を冒頭に明記
- 既出固有名詞のみ登録（地理／国家・都市／神話・宗教／ダンジョン・地下界／組織系統／種族）
- 個別の魔法・アイテム・生物は登録しない（05〜07 の各辞典へ）
- 誤りの修正時は関連する本文・台帳と同時に該当箇所を直し、別の改訂履歴は残さない

### 3-5b. `core/05-magic.md`（②魔法）
- **append-only ガード**を冒頭に明記
- §1 マスター登録表（術式・特典術・現象ラベル）：表記・系統・階位・扱い・初出話を固定
- §2 使用実績ログ（章ごと append）：発動／言及のみ／新規登録 を区別して記録
- 誤りの修正時は関連する本文・台帳と同時に該当箇所を直し、別の改訂履歴は残さない

### 3-5c. `core/06-items.md`（③アイテム）
- **append-only ガード**を冒頭に明記
- §1 マスター登録表：表記・カテゴリ・所有者・扱い区分・初出話を固定
- §2 使用実績ログ（章ごと append）：登場・使用／受け渡し・発行／破損・紛失／言及のみ を区別して記録
- 誤りの修正時は関連する本文・台帳と同時に該当箇所を直し、別の改訂履歴は残さない

### 3-5d. `core/07-creatures.md`（④生物・モンスター）
- **append-only ガード**を冒頭に明記
- §1 マスター登録表：1-1 種・系統／1-2 名前付き個体／1-3 神話生物・伝承
- §2 使用実績ログ（章ごと append）：遭遇・戦闘／討伐・死亡／使役・契約／言及のみ を区別して記録
- 誤りの修正時は関連する本文・台帳と同時に該当箇所を直し、別の改訂履歴は残さない

### 3-5e. `core/08-timeline.md`（⑤全体時系列）
- **append-only ガード**を冒頭に明記
- **作中の年・日付・経過日数はすべて本ファイルが正本**。`character-sheet §経歴・年表`（個人史）と `scene-card §1`（当該話の時間）は本表の年・日付を参照して書き、世界史イベントや日付を他ファイルで再掲・独自管理しない
- §1 暦法・紀年法：紀年法・1年の構成（月・日数）・季節・物語開始日（**執筆前に凍結**）
- §2 史実年表：物語開始以前の世界史・主要キャラ誕生・前提事件を年単位で記載（**執筆前に凍結**・追加は末尾 append）
- §3 章別作中日付：話ごとに「作中日付（開始〜終了）・前話からの経過・視点・同期（同日の別話）」を1行で記録（**章完成後に append**）。多元視点の並行場面の同期、同時刻複数場所・季節逆行の検査に使う（`guidelines/06 §C-3`）
- 誤りの修正時は関連する本文・台帳と同時に該当箇所を直し、別の改訂履歴は残さない

### 3-6. `ondemand/geo-political.md`
- 大陸全体像
- 国家配置（位置関係・隣接国）
- 主要地形（山脈・高原・砂漠・海・湖・河川）
- 風と航程
- 街道・海路
- 地政学（時代に応じた論点）
- **MAP 画像があれば一次資料として優先**

### 3-7. `ondemand/magic-system.md`
- 系統概念（4系統 or 作品独自）
- 階位（強さの倫理）
- 扱い区分（制度線：一般／要資格／特別許可／禁止／伝承）
- 表記ルール
- 制度と現場安全（執筆チェック）
- 特典術・関連カテゴリ・現象ラベル（系統枠のみ。個別術式名は `core/05-magic.md` に、術具・許可札等は `core/06-items.md` に append する運用）

### 3-8. `ondemand/culture-items.md`
- 地域・時点ごとの物品可否と根拠（交易・技術・制度・魔法）
- 食文化（全域共通＋国別）
- 服飾の物理整合
- 建築の時代考証
- 季節・暦・祭礼
- 文化ディテール

### 3-9. `ondemand/organizations.md`
- 冒険者ギルド（共通仕様＋国別差）
- 雇用型組織（会社モデル）
- ダンジョン管理・労務体系
- 神殿組織
- 学術組織
- 公的・準公的組織
- 商会・交易組織

### 3-10. `ondemand/relations.md`
- 国家間関係マップ（図または表）
- 主要論点（時代固有）
- 種族間関係
- キャラロール定義（群像劇用）
- 関係性タグ（character-sheet 同士に振る）

### 3-11. `log/canon-log.md`
- **append-only ガード**を冒頭に明記
- 記入フォーマット（章番号・場所・視点・確定事項・関係変化・喪失獲得・章末引き）
- **作中日付は記録しない**（日付の正本は `core/08-timeline.md §3`。重複管理しない）
- 確定事項ログ（時系列・章順）
- 誤りの修正時は関連する本文・台帳と同時に該当箇所を直し、別の改訂履歴は残さない

## 4. Grokの段階読み込みとの連動

| 優先 | 内容 | 読み込み方 |
|---|---|---|
| 1 | `work/continuity/current-state.md` | 直前話終了時点を最初に確認 |
| 2 | 当該話のシーンカードと `work/pov-plan.md` | 局所目標、視点、情報格差を固定 |
| 3 | 登場人物のキャラシート | 当該場面の人物だけ読む |
| 4 | `work/plot.md` | 現在アークと前後3話だけ読む |
| 5 | `world-bible/` | `00-INDEX.md` が指定する必要な正典だけ読む |
| 6 | `log/canon-log.md` と `core/08-timeline.md` | 当該話に関係する確定事項と日付を照合 |

## 4-2. 肥大対策（百万字級の長編）

core/04〜08 の使用実績ログ・08-timeline §3・pov-plan §3 は話数に比例して成長する。放置すると必要箇所の特定が遅くなり、読み込み量も増える。以下を規定とする：

1. **圧縮はアーク切れ目のみ**：plot.md のフリーズ部を改稿するタイミング（数十章ごと）に合わせて行う。通常章の執筆中は途中行を触らない（append-only 維持）。
2. **退避先**：`world-bible/log/archive/` に `05-magic-arc1.md` のようにアーク単位で移し、元ファイルには「第1〜30話の使用実績は log/archive/05-magic-arc1.md（要点：初出3術式・上限制約は §1 に反映済み）」の1〜3行サマリを残す。**§1 の定義・ルール部分は退避しない**（正典の現役部分）。退避するのは「どの話で使ったか」の実績行のみ。
3. **目安**：各成長ファイルが200行を超えていたら、次のアーク切れ目で圧縮する。
4. **監査のタイミング**：圧縮は途中行改変なので、plot.md のアーク境界監査と同じターンで行い、本文・時系列・正典の整合をまとめて確認する。
5. **正典性は不変**：archive へ移した内容も確定事実のまま。矛盾を修正する場合は、影響する本文・時系列・状態台帳を同じ作業で更新する。

## 5. 破綻抑止のための鉄則

1. core 全ファイルは**連結順固定**（INDEX で順序を明記）
2. 辞典・年表（core/04〜08）と canon-log は**append-only**（途中行改変禁止。肥大したら §4-2 の規定でアーク切れ目に圧縮）
3. ondemand は**章ビートに応じて選択ロード**（無関係情報を載せない）
4. `world-bible/` は **self-contained**。リポジトリ内の他ディレクトリへ構造的依存を作らない（ユーザーが資料を明示参照した場合のみ補助的に使う）
5. core の途中行を書き換える必要があれば、本文・時系列・状態台帳も同じ作業で更新する。別の改訂履歴は残さない
