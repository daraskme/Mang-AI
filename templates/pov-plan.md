# 視点運用表（pov-plan）テンプレート

三人称多元視点の**中枢設計書**。`work/pov-plan.md` としてコピーし、**本文執筆前に**埋めて凍結する。変更時は関連するscene-card・本文・状態台帳も同じ作業で照合する。
どの話・どの場面を誰の視点で書くか、誰が何を知っているかをここで一元管理し、scene-card・本文はこの表に従属させる。

運用規則は `AGENTS.md §執筆規則` と `guidelines/02-narrative-craft.md §1` を正とする。

---

## 1. POVキャラ一覧（必要な視点だけ置く）

視点キャラ全員分の `character-sheet.md`（§視点フィルタ含む）を先に完成させること。

| POV# | キャラ名 | 物語上の機能 | この視点でしか描けないもの | 想定視点シェア |
|---|---|---|---|---|
| P1 | （主人公） | 主筋の推進 | （例：事件の当事者としての恐怖） | |
| P2 | （必要時） | 主人公の盲点の開示 | （例：敵陣営の内情） | |
| P3 | （必要時） | その人物にしか見えない因果 | | |

**追加の条件**：新しいPOVキャラは「その人物にしか見えない情報・感情が物語進行に必須」な場合のみ追加する。追加時は本表→character-sheet→§3情報格差の順に整備してから書く。

## 2. 視点割当表（章×場面）

**1場面1視点**。場面は本文の場面転換記号（plot.md §作品基本情報で固定した1種。既定 `※　※　※`）で区切られる単位。執筆前にここで決め、scene-card §1 に転記する。

| 話数 | 場面 | 視点 | 場面の機能（1行） | 引き→受けのメモ |
|---|---|---|---|---|
| ep001 | 1 | P1 | （例：日常と欠落の提示） | |
| ep001 | 2 | P1 | | 場面末の引き：（例：正体不明の影） |
| ep002 | 1 | P2 | （例：影の正体を敵側から開示） | ep001の引きを別視点で受ける |
| ep002 | 2 | P1 | | |

**チェック**：
- [ ] 場面数と視点切替は、状態変化と読者の理解に必要な分だけに絞られている
- [ ] 同一シーンの別視点リプレイは、視点を替えることで新しい因果・誤解・選択が生まれる場合だけ使う
- [ ] 視点シェアが §1 の想定から大きく乖離していない（脇役視点の肥大は水増しの兆候）

---

## 3. 情報格差マトリクス（誰が何を知っているか）

重要事実ごとに「知った話数」を記録する。**空欄＝知らない**。視点キャラが知らない事実は、その視点の場面の地の文・内心に出してはいけない。

| 事実ID | 事実（1行） | 読者 | P1 | P2 | P3 | 全員が知る予定の話数 |
|---|---|---|---|---|---|---|
| K001 | （例：黒幕の正体） | ep010 | ep024 | ep003 | — | ep025 |
| K002 | | | | | | |

**運用**：
- 「読者」列＝その事実が本文に開示された話数。キャラ列より先なら**ドラマティック・アイロニー**（読者は知っているがキャラは知らない）が発生している区間。意図的かを確認する。
- 章を書き終えるたびに、当該章で開示・伝達された事実をここに追記する（append。canon-log と併走）。
- 執筆前チェック：当該場面の視点キャラの列を見て「この時点で知らないこと」を scene-card §8 に転記する。
- **肥大対策（百万字級）**：全POVキャラ・読者ともに開示済みになった行は、**アーク切れ目（plot.md フリーズ部を改稿するタイミング）でのみ**まとめて `world-bible/log/archive/pov-plan-arc<N>.md` へ退避し、本表には「〜ep030 で全員周知（詳細は archive）」の1行に畳む。通常章の執筆中は途中行を触らない（append-only 維持。詳細は `templates/world-bible.md §4-2`）。

## 4. 視点検査チェックリスト（本文完成後・話単位）

`AGENTS.md §完了の定義` の視点・キャラ照合。場面ごとに目視確認する：

- [ ] 視点キャラが本表 §2 の割当と一致している
- [ ] 切替のあと、冒頭近くで誰の知覚か分かる（文数のノルマは置かない。`guidelines/02-narrative-craft.md` §1-4）
- [ ] 場面内に視点キャラ以外の内面描写がない（外面推察に書き直されている）
- [ ] 視点キャラがこの時点で知らない事実（§3で空欄）が地の文・内心に混入していない
- [ ] 地の文の声（文長・注目対象・比喩）が §1 の書き分けサマリに沿っている
- [ ] 台詞と明示的な内心では、登場キャラ全員の一人称・二人称・呼称・語尾・禁則語が character-sheet と一致している
- [ ] 地の文の固有人名が中立呼称（`guidelines/02-narrative-craft.md §1-5`）になっている
