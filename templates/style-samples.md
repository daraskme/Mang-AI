# style-samples — この作品の声（凍結サンプル）

長編で最初に崩れるのは規則違反ではなく**声の漂流**である。文体規約をいくら足しても、数十話を書くうちに地の文の温度、比喩の源泉、会話のテンポは少しずつ動く。規則ではなく**実例**で固定するのがこのファイルの役割。

`work/style-samples.md` としてコピーし、第1話〜第3話を書き終えた時点で、**実際に書けた本文から抜き出して**埋める。想像で書かない。以後の話は、規約に加えてここへ合わせる。

凍結後に差し替える場合は、確定本文から再採録し、人物の声と既存話への影響を同じ作業で照合する。

---

## 1. 作品の基調

| 項目 | 値 |
|---|---|
| 既定の文体モード | 地の文主体／会話主体／混合 |
| 地の文の人称・時制 | （例：三人称・過去形基調、加速時のみ現在形） |
| 一文の標準的な長さ | （例：40〜60字。加速時は20字以下を連ねる） |
| 段落の作り方 | （例：意味段落。1動作1段落にはしない） |
| 会話と地の文の比率 | 場面の機能で変える（固定比率を設けない） |
| 三点リーダ・ダッシュ | `guidelines/01-writing-rules.md` に従う |
| 場面転換記号 | `work/plot.md` の作品基本情報で固定した1種 |

## 6. 参照のしかた

- 毎話の執筆前に §1 と、その話の視点人物の §2 を読む。
- 文体が漂流している疑いがあるときは §2 の全サンプルと直近話を並べて比較する。
- アーク境界の監査では、最新話の地の文が §2 のサンプルとどう違うかを言語化して記録する。
- サンプルを新しい話で置き換えるのは、意図的に文体を変えたときだけ。無自覚な変化に合わせて更新しない。
