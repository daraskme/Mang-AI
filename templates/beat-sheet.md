# 転換点シート

採用した構造の主要転換点を置く任意資料。新作開始時に本ファイルをコピーして `work/beat-sheet.md` として保存する。三幕構成、起承転結、序破急、独自構造では、見出しをその作品の転換点へ置き換える。
各話のシーンカードには、現在の転換点とその機能だけを必要時に転記する。配分率は診断用の目安であり、話数や文字数を配分率へ機械的に合わせない。

## 転換点（採用時のみ）

各転換点に以下を埋める：
- **配分**：全体のどのあたりか。数値は目安
- **担当章**：第何話で達成するか
- **機能**：この章で何を読者に伝えるか
- **シーン概要**：1〜3行で何が起きるか
- **前章までの確定事項**：この時点で確定している設定・関係性

## 各話の状態変化チェック

各話で、開始時から終了時までに少なくとも一つの状態を変える。移動や情報提示だけでなく、以後の判断・関係・危険・資源へ何が効くかを書く。
- [ ] 情報開示（読者が知らなかった事実が判明）
- [ ] 関係変化（キャラ間の関係が変わる）
- [ ] 位置・期限・危険の変化（物理条件が以後の選択を変える）
- [ ] 決断（主人公が選択する）
- [ ] 喪失または獲得（何かを失う／得る）

---

## 話末の効果（作品の読み味に合わせて使い分ける）

毎回強いクリフハンガーにせず、今回の返済と次の圧力の釣り合いを選ぶ。
- [ ] 次話への問い
- [ ] 異常事態の発生
- [ ] 選択の提示
- [ ] 場面転換予告
- [ ] 小さな決着・安堵
- [ ] 選択の余韻・関係の含意

---

## テンプレ展開を採用する場合の固有化チェック

なろう典型の「ワンオペ→追放→スパダリ→裁判で勝つ→没落」骨格を使う場合の独自要素：

- [ ] 主人公の能力が、固有の経験・価値観・代償とつながっている
- [ ] 相手役や対立役の選択が、役割名ではなく本人の利害と誤解から生じる
- [ ] クライマックスの解決手段が、序盤から積み上げた選択と関係の結果になっている
- [ ] 典型的な台詞や場面を使う場合も、人物固有の含意か結果を加えている
