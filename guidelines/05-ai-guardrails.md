# 05. 表現の採否と検査の使い方

語句を見つける処理と、直すべきかの判断を分ける。文法・意味の誤りを先に、文体の好みを後に扱う。頻出語、文字種、短文、投稿量から生成手段を判定しない。

参照節：§1 分担／§2 任意の検査／§3-4 採否と改稿／§3-5 圧縮癖5系統／§4-4 不自然な連語／§5 確認と終了。

## 1. 規則の分担

| 対象 | 正本 |
|---|---|
| 表記・ルビ・本文外情報 | [01](01-writing-rules.md) |
| 台詞の人物関係・生成・短縮 | [02 §4-10](02-narrative-craft.md) |
| 正典・視点・時間・関係 | 当該作品の設定と[03](03-character-and-world.md) |
| 展開・読者への約束 | [04](04-structure-and-plot.md) |
| 表現を残すか直すか | 本ファイル§3-4 |
| 確認範囲・終了条件 | [06](06-revision-checklist.md) |

診断はai-novel-detector、実際の文章修正はhumanize-ai-writingが担当する。小さな直接改稿に診断Skillの先行を義務づけない。

## 2. 任意の検査スクリプト

次は既存プロジェクトにある場合の接続先で、この配布物には同梱しない。実ファイル、使い方、対象、出力の意味を読んでから実行する。未確認のオプション・閾値・終了コードを前提にしない。

| 接続先候補 | 用途 | 無い場合 |
|---|---|---|
| scripts/check.sh | 作品ごとの書式・文字種チェック | 01の必要項目を目視 |
| normalize_blanklines.py | 空行の検査 | 改行と意味段落を目視 |
| repeat_check.py | 長い一致表現の検索 | 対象範囲を検索・比較 |
| vocab_check.py / cliche_check.py | 語彙・構文の密集候補 | 頻度、人物間共有、文脈を確認 |
| metaphor_sweep.py | 比喩・圧縮表現の候補抽出 | §3-5で対象範囲を読む |
| dialogue_context.py | 台詞と文脈の抽出 | 場面ごとに台詞を確認 |

抽出器は日本語の意味や行為者を保証しない。警告ゼロを自然さの証明にせず、候補一覧だけで全文監査済みとしない。既存スクリプトが新しい作品方針と食い違う場合は差分を記録し、本作業の範囲外のスクリプトを無断で変更しない。

局所修正は変更箇所とその応答・指示対象を確認する。全文監査では対象範囲の全台詞を確認する。全話横断は反復・整合性の調査を依頼された場合、または局所では原因が判断できない場合に限る。

## 3. 定型化の候補

### 3-1. 抽象動詞

対象、行為、結果を隠している「整える・回す・削る」等を具体化する。意味が通る専門語や通常の用法は残す。語の置換表を機械的に適用しない。

### 3-2. 語彙の密集

事務語、職能語、雰囲気語、身体反応が狭い範囲に集まり、人物を替えても同じ判断を代行するかを見る。題材上の必要な頻出語や、場面の中心語を削らない。

### 3-3. 定型句

否定対句、警句、抽象的な締め、感情のぼかしは、近接反復と場面での機能を合わせて判断する。単独の「それで十分」「何か」「静かに」などを禁止しない。「○年間」のような正確な情報を、抽象的という理由だけで回想へ置き換えない。

### 3-4. 場面テストと改稿の選択

**残す価値**：事実だけでなく、視点人物の知覚・判断、感情、距離、人物の声、リズム、笑い、余韻を含む。その表現を除いたとき何が失われるか、前後と合わせて判断する。直叙でも同じ事実が伝わる、という理由だけで文飾と決めない。

**直す根拠**：読解を妨げる、意味が変わる、同じ説明が重なる、人物間の声が均一になる、場面に無関係な言い回しが密集する、という具体的な影響を示せること。

改稿は問題の種類で選ぶ。

1. **意味の誤り・欠落**：人物関係・指示対象・必要な因果を修正する。削除で必要な情報を失わせない。台詞は02 §4-10。
2. **不要な重複・装飾**：削除を試し、声・感情・テンポが損なわれなければ終える。語を足して帳尻を合わせない。
3. **必要だが読みにくい表現**：同じ意味を平明に述べる。人物主語、適切な動詞、短い説明を候補にする。
4. **具体性が不足**：原文または確定設定にある具体を使う。裏付けのない小道具、失敗、記憶、感情、動作は作らない。材料がなければ既存の意味を保って書き、結果を左右する不明点だけ確認する。

**書き換えの不変**：主張、比重、言い切りの強さ、文の働きを保つ。否定していたものを並列や順位づけへ移さない。評価の文を目的や予定の文にしない。推量を断定へ上げず、断定を推量へ落とさない。比喩を別の言葉にするときは、その語が持っていた気持ちの向きを残す。地の文の骨格は [02 §2-8](02-narrative-craft.md)。

不要な比喩を別の比喩へ取り替えるだけの修正は避ける。ただし原文の比喩が機能し、語法だけに問題がある場合は、意味を保つ局所修正も選べる。「必ず削除から」「比喩は最後の手段」を全表現へ強制しない。

**反復の機能**：意味の変化だけでなく、確認、儀礼、安心、恐怖、予告、天丼、回収にも価値がある。同じ機能の反復が必要な演出なら残す。効果が薄れる同義反復は減らす。回数上限を作文の割当量へ変換しない。

### 3-5. 圧縮癖・装飾比喩の5系統

| 系統 | 候補 | 確認すること |
|---|---|---|
| 1 役割・心理の名詞貼り付け | 商人の顔で、開戦の声で | 実際の表情・演技・口調か、内容を説明せず名詞で済ませているか |
| 2 部位の判断主体化 | 目が言う、手が判断する | 慣用、身体の知覚、実際の設定か、誰の行為かを隠す装飾か |
| 3 心理の物品管理化 | 保留の棚、皮肉の鎧 | 何を保留・抑制したかが分かるか。毎回同じ物品比喩へ逃げていないか |
| 4 無生物の行為主体化 | 卓が笑う、噂が営業する | 通常の換喩や幻想設定か、知覚・因果を追いにくくする表現か |
| 5 固有モチーフの過密 | 全感情を矢・帳簿・物差しで語る | 人物の声として機能する範囲と、感情差を消す反復を分ける |

「目が覚める」「手が覚えている」などの慣用、実際の所有、作中で演じる役割、魔法や生物の設定上の機能、作品世界の実物は、形が似ているだけでは誤りではない。除外語の一覧も免罪符にせず、意味と文脈で判定する。

身体部位・無生物が主語の全ての文を人物主語へ戻さない。「側」も身体の左右、物理的な位置、立場など通常の用法がある。一語単位の禁止ではなく、意図した関係が読めるかを見る。

## 4. 笑い・どもり・口癖

02 §4-1〜4-6を参照する。全員に異なる笑い声や口癖を割り当てることを必須にしない。同じ場面を繰り返し、人物の反応が均一になる場合を見直す。

### 4-4. 不自然な連語・翻訳調

外国語由来かどうかではなく、日本語として何が読みにくいかを確認する。

- 代名詞・所有格：省略して人物関係が保てる場合だけ減らす。主体の交替、対比、所有者の区別に必要なら残す。
- 動詞と名詞の組合せ：通常の文脈で「決断を作る」など意味を取りにくい連語を、意図を保って直す。
- 「温かい歓迎」「声が重い」など、文脈によって自然な語まで一律に誤用扱いしない。
- 受身・使役：責任、視点、行為者の関係を保つ。能動化して意味が変わる修正をしない。
- 「ようだ」「かもしれない」：不確実性を担うなら残す。削って断定に変えない。
- 英語で思考している、特定の学習データが原因、と出力だけから断定しない。

## 5. 確認と終了

変更後に、元の事実・行為者・対象・否定・時系列・視点・声を照合する。明らかな意味の誤りは直し、任意の表現候補は作品の効果で採否を決める。[06](06-revision-checklist.md)に沿い、具体的な残存問題がない時点で終了する。同じモデルの「問題ありません」という宣言を検証の代用にしない。

## 6. 本文外情報の除去

AI応答の前置き、制作手順、依頼の復唱、不要なMarkdownが本文へ混入した場合だけ取り除く。「承知しました」など作中人物の自然な台詞を、語句だけで消さない。脚本のト書き・話者欄は制作上必要な別欄として残す。

## 7. 診断項目との対応

ai-novel-detectorの従来の観点番号は参照用に維持できる。番号は重みや生成確率を意味しない。

| 対象 | 従来番号 | 確認先 |
|---|---|---|
| 表記・本文外情報・文字種 | 1・2・3・5・21・22・26・27・28 | 01、02 §2-4 |
| 台詞・文体・反復 | 6・7・10・15・16・23 | 02、本ファイル§3 |
| 人物・世界・生活 | 8・9・11・12・14 | 03、02 §3 |
| 構造・あらすじ | 13・24 | 04 |

投稿頻度、相互反応、話数の切りのよさ、感想返信などから本文品質・生成手段を推定する評価は行わない。規約確認は明示依頼と現行の規約本文がある場合の別作業とする。
