# 03. キャラクター設定・世界観・階級・敬称

「致命的な整合性破綻」「キャラの平坦さ」「設定の薄さ」「階級違反」を構造的に防ぐため、当該場面で必要な事実を整理する。短い台詞修正へ世界設定一式の作成を要求しない。

---

## 1. キャラクターシート

視点人物は知覚・判断・声・既知情報を、継続登場人物は本文で矛盾し得る外見・呼称・関係・経歴を整理する。既存の `templates/character-sheet.md` があれば利用できる。未提供なら必要事項だけを短い表やメモにする。端役や未登場事項まで全欄を埋めない。

### 記録する項目の例
| 項目 | 例 |
|---|---|
| 名前（フル）| エリザベス・ヴァンス・アシュレイ |
| 通称・愛称 | リズ |
| 年齢 | 18 |
| 外見：髪色・髪型・瞳色・身長・体型 | 銀髪を肩で切り揃え、紫水晶の瞳、165cm、痩せ型 |
| 一人称 | わたくし |
| 二人称 | あなた／あなた様（相手の階級により切替） |
| 語尾 | 〜ですわ／〜なのです |
| 敬語ライン | 公爵以上は敬語、伯爵以下はタメ口 |
| 禁則語 | 「うん」「アンタ」「マジ」「やべえ」 |
| 口癖 | （特になし。あえて持たせない場合は明記）|
| 身体的癖 | 緊張時に右手で耳たぶに触れる |
| 性格3要素 | 義理堅い・潔癖・自己評価が低い |
| 好物（具体）| 黒パンの硬い端、林檎のコンポート、ミルクティー |
| 嫌悪 | 蜘蛛、煙の匂い、八百長 |
| 階級・所属 | 侯爵令嬢、王立学園3年 |
| 家族 | 父：侯爵当主、母：第二夫人、弟：12歳 |
| 主要関係性 | 婚約者：王太子（仮）、親友：男爵令嬢サラ、宿敵：継母 |
| 過去の決定的事件 | 8歳時、母親が原因不明の高熱で1年寝込み、薬代を捻出するため帳簿を学ぶ |
| 現在の欲求 | 母を療養地に送り、自身は学園を卒業し領地経営を継ぐ |
| 物語上の機能 | 主人公／視点キャラ |

### キャラ平坦化の防止
- 善良・冷静・有能という属性だけで、全ての人物の判断を同じにしない。個性化のために欠点や失敗を無条件で追加しない
- 欲求と恐れ、得意と代償、公的な顔と私的な判断の間に、その人物固有の摩擦を置く
- サブキャラは人数合わせで増やさず、場面の利害や情報経路に固有の役割がある人物だけ名付ける
- 名前は作品の言語・地域・階級の命名規則に従い、同一作品内の識別性を優先する

## 2. 世界観資料

継続作品では事実の正本をまとめ、各話で必要な箇所だけ読む。既存の `templates/world-bible.md` や `world-bible/00-INDEX.md` があれば利用する。以下のパスは任意の配置例であり、この配布物には含まれない。既存の管理先があればそちらを優先する。

### 構成セクション

#### 2-1. 世界の基本
- 時代設定（中世欧州風／近世風／架空現代）
- 魔法の有無・原理・制約
- 主要国家・地理・気候
- 通貨・度量衡

#### 2-2. 階級・身分制度（必要な作品で定義）

敬称と発言権は、参照する地域・時代・制度、親族関係、公私の場、話者の反抗や無知によって変わる。次は西欧風宮廷ファンタジーの仮置き例であり、普遍規則ではない。採用する場合も `world-bible/core/02-class-honorifics.md` で作品固有の規則へ確定する。

本節の敬称規則は、台詞、作中引用、明示的な内心の発話に適用する。地の文では `02-narrative-craft.md` §1-5に従い、採用した語りと既存の呼称を保つ。一人称や人物に寄った語りの敬称を機械的に除かない。

| 階級 | 敬称（自分から見て下）| 敬称（自分から見て上）| 備考 |
|---|---|---|---|
| 王 | 名前呼び捨て or 役職 | （存在せず） | 「陛下」と呼ばれる |
| 王妃 | 名前 or 役職 | 陛下 | |
| 王太子・王子 | 名前 or 役職 | 陛下／父上・母上 | 配下から「殿下」 |
| 公爵 | 卿／○○殿 | 閣下／殿下 | |
| 侯爵 | 卿／○○殿 | 閣下／殿下 | |
| 伯爵 | 卿／○○殿 | 閣下／殿下 | |
| 子爵 | 卿／○○殿 | 閣下／殿下 | |

| 平民 | 名前 | 様／殿（場合による）| |

#### 2-3. 階級・敬称の整合を検査する

- 誰が誰へ、どの場で、どの敬称・人称・発言手順を使うかを正典と照合する
- 規則から外れる呼称や口調は、親密さ、侮辱、反抗、偽装、制度差など本文上の意味があるか確認する
- 現実史を参照する場合は地域と時代を特定し、架空制度へ無断で一般化しない
- 制度から外れる発言は、公私、相手、黙認、制止、評判等の条件と照合する。全ての無礼へ即座の処罰を追加しない

#### 2-4. 物品・文化の時代考証

作物、飲料、甘味、筆記具、窓材などの可否と価格は、参照地域・世紀、交易路、植民・伝播史、技術、魔法によって変わる。単一の「中世禁止物品リスト」は持たない。

- 史実準拠なら対象地域と年代の資料で確認する
- 複合世界なら、産地、輸送、加工、誰が入手できるかを正典化する
- 魔法で代替する場合も、費用、利用者、既存産業への影響を決める
- 本文では物品の存在そのものより、価格、手間、身分差、人物の選択へ影響させる

#### 2-5. ドレス・服飾の物理的整合
- 裾の長さ、履物、裾を持つ動作、足場等から、動作が成立するか確認する
- 素材だけで断定せず、仕立て、重ね着、裏地、支持構造とシルエットを照合する
- 装飾は価格、入手経路、職業、贈答、作品内の服制と照合する。平民の金糸刺繍を普遍的に禁止しない

## 3. 関係性マップ

### 必要に応じて記録する関係
本作の主要キャラ間の：
- 血縁関係
- 主従関係（誰が誰に仕えているか）
- 婚姻・婚約・破棄歴
- 友情・敵対・恋愛感情の現状
- 経済的関係（誰が誰の借金を肩代わり等）

関係が複雑な作品は図や表にまとめ、本文で変化した関係を更新する。単純な二人の場面なら短いメモでもよい。

## 4. 長編で起こしやすい設定事故と対策

| 事故 | 対策 |
|---|---|
| 髪色が話を跨いで／同一場面内で変わる | 登場人物のキャラシートで髪色を執筆前に照合する |
| 同僚の性別が「彼」「彼女」交互 | 人物設定と呼称を照合する。代名詞は参照先が分かる範囲で使い、初出だけに制限しない |
| 王太子の婚約者が王弟と第二王子で揺れる | 関係性マップとキャラシートを執筆前に照合する |
| 朝のシーン直後の段落が夜 | 採用している時系列表と場面の時刻・経過時間を照合する|
| 退場キャラが次話で復活 | キャラシートに「退場済み」フラグ |
| 18歳が「15年勤めた」と言う | 開始年齢、暦、種族や時間設定を確認し、作品内で成立する経歴か判断する|
| 5年前死んだ先妻の子が今3歳 | 誕生年・死亡年・親子関係と、特殊な時間設定の有無を照合する|
| ナーロッパで「漢字を習ってない」 | 作中文字と読者向けの翻訳表現を区別し、作品の文字設定と照合する |
| 物語に関わる親族の状態が話ごとに変わる | 関係する親族だけ生死・所在・関係をキャラシートへ記録する |

## 5. テンプレ設定の回避

### テンプレ化しやすい職業・設定（要警戒）
- ワンオペ経理令嬢（一人で何年も帳簿管理）
- 白い結婚で家宰として家を切盛り
- 異父姉妹（年齢構成がよく破綻する）
- 18歳で「○年勤めた」設定（年齢と経歴の不整合）
- 辺境と王都の距離・交通条件が場面ごとに変わる

これらを完全禁止せず、表面に特技や弱点を足して差別化したことにもしない。主人公の選択が職業・階級・関係のどの制約から生じ、その選択が誰にどんな代償を渡すかを変える。

## 6. キャラの個性化チェック

差別化は項目数ではなく、同じ圧力を受けたときの判断差で確認する。比較場面では次を見る。

1. 何を最初に知覚し、何を見落とすか
2. 何を守るためなら、どの代償を払うか
3. 誰の前で声・姿勢・語彙が変わるか
4. 過去の経験が現在の誤解や選択へどうつながるか

身体的癖、食の好み、禁則語は有効な素材だが、毎場面へ出すノルマにしない。

## 7. 人物・設定の確認候補（観点11／12）

ai-novel-detector の観点11（キャラの平坦さ）・観点12（設定の薄さ）に対応する設計上の確認項目。単独該当を著者性の根拠にせず、複数項目が場面の選択差・因果・生活実感を損なう場合に見直す。

### 7-1. キャラ平坦化シグナル（観点11）

| 確認候補 | 読者への影響 | 対策 |
|---|---|---|
| 主人公が試行錯誤しない・失敗しない | 成功までの段取りが圧縮され、選択の重みが消える | 能力不足だけでなく、価値観、情報不足、他者の利害が生む誤算と代償を設計する |
| 主人公の性格が場面を変えても同じ反応だけ | 無難な主人公像へ収束し、選択差が消える | 公私、相手、疲労、損失によって何が変わり、何が変わらないかを定義する |
| 群衆・組織が匿名の機能だけで動く | 社会が舞台装置に見える | 物語上の決定や摩擦を担う人物にだけ、固有の利害と名前を与える |
| 強い属性を足しただけで判断が同じ | 表面的な奇抜さに留まる | 属性ではなく、守るもの、見落とすもの、支払える代償を分ける |
| ヒーローが寡黙すぎる（「ああ」「構わない」「それでいい」しか言わない）| 短文棒読み | `02-narrative-craft.md` §4-2と照合。短い返事でも応答が成立すれば残す。不足がある場合だけ既存の判断や動作で伝える |
| ヒロインの愛情表現が真空 | 関係性が薄い | その人物にとっての愛情の表し方と、既存の関係変化を確認する |
| 同一作品内で名前・役割・声が識別しにくい | 読者が人物を混同する | 命名規則、音の輪郭、呼称、場面上の利害を比較する |
| 全員が同じ性格・思考をする（人物描写は細かいのに） | キャラ構築失敗 | 同じ事実へ異なる結論を出す理由を、経歴と現在の欲求へ接続する |

### 7-2. 設定薄さシグナル（観点12）

| 確認候補 | 読者への影響 | 対策 |
|---|---|---|
| 物語に関わる家族関係が必要な場面で未設計 | 因果や感情の前提が欠ける | 本筋へ影響する親族だけ、生死・所在・関係・情報を記録する |
| ワンオペ経理令嬢（一人で何年も帳簿管理）| 仕事量や権限の因果が省略される可能性 | 仕事の規模・補助者・権限を確認。職業だけで欠点にしない |
| 箱入り令嬢が市井で即戦力で働ける | 設定矛盾 | 既存の経歴と能力の取得経路を確認する。整合のためだけに過去を新造しない |
| 辺境と王都の距離・交通条件が場面ごとに変わる| 地理感の欠如 | 移動に必要な所要時間と交通手段を正典へ記録する |
| キャラが疲労しない（事件→動揺→即100%回復）| 連続性の欠如 | 継続する消耗・負傷・回復条件を正典へ記録する |
| 18歳の主人公が「15年勤めた」 | 年齢×経歴の整合破綻 | 開始年齢・暦・作品固有の時間設定を照合する |
| 5年前に亡くなった先妻の最後の子が今3歳 | 親族年齢の整合破綻 | キャラシートで親族年表を縦持ち（誕生年 / 死没年） |
| 異父姉妹が誕生日2か月違いの同い年 | 同上 | 同上 |
| 主人公が追い出された先で同じ仕事をして感謝されるだけ | 選択と代償が変わらず、場面が反復する | 新しい環境で仕事の意味、権限、責任、失敗条件のどれが変わるかを設計する |
| ドレスの素材と完成形のシルエットが整合しない | 物理整合の欠如 | 素材・仕立て・下着等を合わせて確認する |
| 料理シーンで「その材料でそれは作れない」 | 物理整合の欠如 | `02-narrative-craft.md` §3-2で材料と工程を確認する |

### 7-3. 設計時の自己問診

新作開始時に、当面のプロットと視点へ関係する問いだけ答える。未登場地域や無関係な親族まで埋めない。

- [ ] 主人公は何を守り、何を誤認し、どの代償までは払えるか
- [ ] カウンターパートは同じ事件をなぜ別の意味に受け取るか
- [ ] 当面のアークで決定権・情報・資源を持つ人物は誰か
- [ ] 移動、年齢、経歴、負傷、所持品のうち本文に関わる値が正典と整合するか
- [ ] 主要人物の呼称と声を、台詞を伏せても判断・語彙・反応から区別できるか
