# 06. 変更範囲に応じた確認と終了条件

台詞の生成・短縮前の手順は[02 §4-10](02-narrative-craft.md)。本ファイルは、その後の照合を扱う。局所修正で全話・全設定の確認を強制しない。

## 確認範囲

| 依頼 | 確認する範囲 |
|---|---|
| 一つの台詞の修正 | 当該台詞、相手の応答、人物関係を決める場面・絵 |
| 一場面の改稿 | 変更箇所と、その因果・視点・呼称が及ぶ前後 |
| 一話の生成・全文監査 | 対象話の全台詞、本文、当該正典 |
| アーク・全編診断 | 指定範囲、話またぎの状態・反復・伏線 |

確認していない範囲を「全件確認済み」と報告しない。入力が足りない項目は判定不能、機械検査を使えない場合は未実施として区別する。

## A. 表記と本文の境界

- [ ] [01](01-writing-rules.md)または作品の表記方針に沿っている。
- [ ] 意図しない文字混入、括弧漏れ、ルビの範囲ずれ、本文外の応答がない。
- [ ] 作中ログ・外国語・数式・意図した引用を誤削除していない。
- [ ] 数値、回数、文字数表現が元の事実と一致する。

利用できる検査スクリプトは実装と対象を確認して使う。警告を無条件で失格にしない。

## B. 台詞と表現

- [ ] 最終的な言い換え・短縮・吹き出し分割の後も、話者、行為者、対象、所有者が元の場面と一致する。
- [ ] 能動・受身・使役・授受、否定、時点、願望、命令の強さが変わっていない。
- [ ] 役割整理、設定解説、執筆依頼を修正のためだけに台詞へ足していない。
- [ ] 発話目的と人物の口調を保ち、全員を同じ短文・恩恵表現へそろえていない。
- [ ] 意図的な含み・嘘・皮肉・独り言・心内語を、不要な説明へ変えていない。
- [ ] 主張、比重、言い切りの強さ、文の働きが変わっていない。比喩を別の言葉にしたとき、元の気持ちの向きが残っている。
- [ ] 読者に必要な情報が、台詞・地の文・絵の適切な場所にある。
- [ ] 重複や装飾は[05 §3-4](05-ai-guardrails.md)で採否を判断し、別の定型句へ置き換えただけになっていない。

## C. 人物・世界・時間

当該資料がある場合、変更の影響がある点を照合する。

- [ ] 名前・外見・一人称・呼称・関係・所持品・所在・生死が正典と一致する。
- [ ] 年齢・経歴・親族・経過時間・移動距離に矛盾がない。
- [ ] 身分・権限・文化・技術・服装・能力の条件を保つ。
- [ ] 原文にない行動、心理、物品、記憶、結果を自然化のために作っていない。

## D. 感覚・説明・視点

- [ ] 視点人物が知り得る範囲と、推測の確度を保つ。
- [ ] 地の文の述語は、視点と場面から行為者が解ける（[02 §2-8](02-narrative-craft.md)）。概念を意志のある主体にしておらず、ラベルだけの前置きや中身のない否定対比で同じ事実を言い直していない。
- [ ] 感情語・身体反応・五感を機械的に変換・追加していない。
- [ ] 説明が必要な因果は残り、既に伝わる意味を重複説明していない。

## E. 構造と進行

場面・話・全編を扱う依頼の場合だけ確認する。

- [ ] 欲求、対立、選択、結果、感情の変化が追える。
- [ ] 読者への約束に合う報酬・余韻・次への期待がある。
- [ ] 手続きや準備だけが続き、肝心の対立・行動・結果を遅らせていない。
- [ ] 元の葛藤・悪意・欲望・勢いを、自然化のために無難にしていない。

## F. 最終確認と出力

依頼された形式で完成稿または診断結果を返す。本文のみの依頼には監査表を付けない。検証報告が必要なら、対象範囲・実施方法・未確認事項を短く示す。既存の台帳は新しい確定事実が生じ、更新が依頼範囲に含まれる場合だけ更新する。

## G. 読後感と終了

### G-1. 確認する効果

声、感情、速度、具体性、含み、読み進める理由が元の目的に合うかを通読で確認する。点数を埋めるための加筆をしない。

### G-2. 残った問題

問題があれば「どの箇所で、何が読み取れず、どの効果が損なわれたか」を特定する。静かな場面、儀礼、天丼、同じ決め台詞などは機能があれば残す。

### G-3. 終了条件

重大な意味・整合性の誤りが解消され、変更箇所に新しい誤りがなく、残る候補が作品意図または好みの範囲なら終了する。警告ゼロ・比喩ゼロ・説明ゼロを目標にしない。同じ問題が再発するときは採用済み案または原文へ戻し、表現の一部分ずつ直す。新しい弱い指摘を際限なく追加しない。
