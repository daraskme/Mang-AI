# キャラクタータグの参照

辞書の正本は `user-provided/` の一覧ファイル。Skill に転載しない。配布zipに含めない。

## いつ読むか

ユーザーが特定キャラを指名したとき（「〇〇で描いて」など）、または画像・原稿からキャラが特定できるとき。オリジナル作品の外見分解だけなら使わない。

## ファイル

```text
user-provided/ にあるキャラクタータグ一覧（利用者が用意する。配布物に辞書本体は含まれない）
```

同系統の更新があれば、ファイル名の日付が新しいものを使う。無ければこの手順を飛ばし、[Tag_Search_Workflow.md](Tag_Search_Workflow.md) で分解する。記憶からタグを作らない。

## 読み方

全文をコンテキストへ入れない。日本語名・英語名・タグで検索し、該当作品の節だけ読む。

## Character への置き方

`girl` / `boy` / `other` の直後に、辞書の**推奨タグプロンプトをそのまま**置く。構図・行為・今の状態はその後ろ。差し替えは上書きする。以前のキャラタグは残さない（R-TAG-15）。修正版では差し替え前の作品タグ・人物タグを削除する（R-TAG-16）。

ゲーム作品：

```text
girl, <series tag>, <character tag>
```

- 作品タグ＋キャラクタータグ。括弧の有無は辞書の表記を機械変換しない。
- 作品ごとの正式な作品タグは辞書の表記に従う。省略形へ機械変換しない。
- 髪色・目色・服は足さない。衣装差分が辞書にあればそれを使う。

二次元キャラクター（ゲーム・アニメ・VTuber）：

- 人名タグが本体。所属タグは任意の補助。
- `virtual youtuber` は自動で足さない。
- 括弧付きタグは辞書表記の一部。勝手に外さない。
- 衣装が混ざるときは、長文の外見より辞書の衣装差分タグを先に見る。
- 二次元キャラクターは架空のキャラクターとして扱う。実在の演者とは同一視しない。

## 確度

| 辞書の印 | 扱い |
|---|---|
| ✅ | V4.5 Full で実生成確認。そのまま使う |
| 🟡 | Danbooru にタグがあるだけ。候補として使う。似なければ外見補助を足す |
| 衣装✅ | 衣装差分タグを優先 |

V5でも同じタグを置く。V5実生成確認とは書かない（辞書の検証は V4.5）。

優先：辞書の ✅ → 辞書の 🟡 → ユーザー独自タグ → 外見分解。

## 使わないとき

- ファイルが無い、または載っていない
- ユーザーが外見分解だけを指定した

載っていない名前を辞書風に捏造しない。

## 安全

二次元フィクションのみ。実在人物の写真・実写化は拒否。各権利者の二次創作ガイドラインに従う。VTuberなどの二次元キャラクターは架空のキャラクターであり、実在の演者とは同一視しない。既成キャラクターを性的文脈で扱うときは成人と定義し、原作設定には準拠させない。性的生成の拒否は `AGENTS.md`「成人向けの前提」。
