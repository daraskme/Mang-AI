## キャラクター

各カード：性別アイコン、名称（既定 `キャラクター1`…）、並び替え、有効/無効、削除、展開。タブは `プロンプト` と `除外したい要素`。名称はメタデータに残らない。

`位置` は **AIにおまかせ / カスタム**。カスタムのピン操作は下節。`|` 区切り構文は UI キャラ欄と併用しない。

## カスタム位置（ピン）

実測（2026-08-21、生成結果エリア上の「位置の編集」）。旧5x5マスではない。カード番号と同じ番号のピンをキャンバスへドラッグする。グリッド線ボタン（田）は任意。編集の終了は「位置の編集を終了する」。

- 原点は **キャンバス左上 (0, 0)**。右下は (100, 100)。単位は **パーセント**（解像度が変わっても同じ）。832×1216 なら画素は `x*8.32`, `y*12.16` の目安。
- ピンは **そのキャラの肩〜胴（顔アップなら顔）** の位置。作例では指定座標に肩が来る目安（2026-08-21）。1キャラ1ピン。ページ全体に1組だけ（コマごとには置けない）。複数コマに出る人は、空室になる段を優先して避ける。
- ピンは対象コマ矩形の中央付近。漫画ページの骨格ごとの目安は [Layout_Skeletons.md](Layout_Skeletons.md)。
- ピン同士は重ねない。x か y を **15以上** 離す。重なると品質が落ち、bleed する。
- 使わないカードは **削除**。無効（✕）でもピンが残る。残ピンが空コマに人を呼ぶ。脚だけ・手元だけの端役はカードごと作らない。人物のいないコマにピンを置かない。
- 座標は `## 配置` にだけ書く。Base / Character のプロンプト文字列へ `x=` や画素を埋め込まない。番号は Character 番号。

出力の既定（カスタム時）：

```text
## 配置
位置: カスタム
グリッド線: オン
キャンバス: 832×1216。原点は左上。ピンを画像上へドラッグ。

| ピン | 誰 | 有効 | 目安 | x | y |
| 1 | 澪 | オン | 上段中央・胴 | 50 | 38 |
| 2 | 剛 | オン | 上段左 | 18 | 18 |
```

x, y は 0–100 の整数。ユーザーはピンをその百分率の位置へ置く。

挿絵の目安（主ピン。副は 15 以上離す）：Character 1＝35, 50、2＝65, 50。前後なら y を 40 と 60。漫画ページは [Layout_Skeletons.md](Layout_Skeletons.md)。等分の縦3（50,16 / 50,50 / 50,83）は使わない。

## 参照画像

V5 Full で選べるのは **i2i（元画像を加工）のみ**。精密参照と NovelAIポーションは同じ位置に出ない（V4.5 Full へ切り替えると出る）。添付画像は外見タグ化する。前回生成を直すなら結果ステージの「ベース画像として使用する」。ポーション・精密参照の Strength / Fidelity は出さない。コマ割りを元画像から維持する i2i は、2026-09-07 の実測で強度 0.66 前後かつ `high complexity` が骨格を残しやすい。`ultra complexity` や 0.7 は枠が崩れやすい。通常の1ページ生成は i2i を使わない。

V5 に無い：多様性(Variety+)、ノイズ設定（karras 等）。推奨しない。
