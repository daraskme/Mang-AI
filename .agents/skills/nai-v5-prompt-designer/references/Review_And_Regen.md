# 生成PNGの解析→選別→再出力

ユーザーが生成結果の確認または3回出力を明示したときだけ使う（R-API-07）。『生成して』『OK』だけでは入らない。入ったあとの正本は依頼の **目的・セリフ・見える事実**。プロンプト文字列の一致率ではない。

生成コマンドと確認ゲートは [API_Generate.md](API_Generate.md)。プロンプトの組み方は [Workflow_Single.md](Workflow_Single.md)。このファイルは **見たあと、どのページを何枚出して、いつタグを変えるか** を持つ。

## いつ

- R-API-07。ユーザーが「画像を確認して」「生成結果を確認して」「違うものを再生成」「解析して打ち直して」「選別」「問題ページだけ再生成」「3回出して」「3枚出して」と依頼したとき
- 「プロンプト修正して生成選別」は、下の「プロンプトを直すとき」へ進んだあと、同じ3回選別を繰り返す

## 選別の順

この順を飛ばさない。読めるページは触らない。

1. 現行フォルダの `page-NN.png` を全部見る。page_script があれば目的・発話・読める事実。無ければ今の Markdown。
2. 「見方」表の1〜12。目的が読めて表が足りるページは通す。擬音・コマ番号の余分だけで通るページは通す。
3. 壊れたページだけ記録する（`ページ / 壊れた項`）。この時点ではタグを書かない。
4. 壊れたページだけ、**同じプロンプトのまま** `--count 3`。`page-NN.png` は上書きしない。`--count 1` は使わない。選別は現行フォルダへ候補を足す。全ページ出し直しで既存PNGを残すときだけ `--out-dir`。
5. 3枚を上表の若い順で見る。番号の若い項が欠けた候補は落とす。綺麗さでは逆転しない。
6. 読める1枚があれば `scripts/nai_adopt.py --take K`。ここでそのページは終わる。
7. 3枚が同じ系統の失敗だけなら `scripts/nai_adopt.py --take canonical`。そのページだけプロンプトを直す（下節）。`--dry-run`。承認後、また `--count 3`。読める1枚を採用する。
8. 採用したページ、現行のまま残したページ、まだ直す軸を短く報告する。プロンプト Markdown へ作業メモの見出しを混ぜない。

セリフの誤字だけなら、ページ全体を捨てず V5 Full のインペイントでそのフキダシ領域だけ直す。1つずつ。Strength は低めから。

## 正本

1. そのページの目的
2. セリフ・思考（話者と「」）
3. 見える事実（着衣、体勢、結合、誰が上、手、誰の目か、視線、軸）
4. 漫画ページなら骨格と読み順
5. 外見凍結（今の髪・服の色・裸、体格差の錨）

目的が読めても、軸・誰の目か・時点が壊れていたら打ち直す。

## 見方

| 順 | 見る | 打ち直す |
|---:|---|---|
| 1 | 行為 | 系統が違う |
| 2 | 着衣 | 着衣が裸、指定していない下着中間、指定色と違う |
| 3 | 誰 | 行為者が消える。写さない人・小さい挿入顔・フキダシ内のちび顔 |
| 4 | 軸 | 騎乗なのに受けが上。向かい合いが同じ方向 |
| 5 | コマ | 数が違う。融合して1枚絵。読み順が逆 |
| 6 | 視点 | 肩越しなのに手前の肩が無い |
| 7 | 視線 | 相手と逆を見る |
| 8 | 時点 | 構えと接触が同じコマ |
| 9 | 発話 | 話者が違う。空楕円。文字化け。指定外の文字 |
| 10 | モザイク | 竿・結合が見えるのに無い |
| 11 | 場所 | 室内と屋外が混ざる |
| 12 | 画風 | 漫画ページなのに `cel shading` / `high contrast`。挿絵なのに `cel shading` |

「綺麗だが別の行為／軸／視点」は打ち直す。「粗いが上表が読める」は通す。

## プロンプトを直すとき

3枚が同じ系統の失敗のあとだけ。直す軸は1つ。変えたらまた最大3回。`artist:` は今回の依頼が明示していない限り足さない（R-STY-01）。

直す順序: 行為の系統を1つ（lexicon）。反対系統の `-1::` は Base 1セット（R-TAG-05）。今の服・裸。コマの誰・カメラ・軸。発話は話者 Character 末尾の「」（R-TXT-01）。本数を落とさない。ピンは15以上離す。Markdown を保存し、`--dry-run` で Character 数とピンと `Text:` を見る。

## よくある直し

| 絵 | 直し |
|---|---|
| 騎乗なのに後背 | Base に `cowgirl position, girl on top`。反対体位の `-1::` は Base 1セット |
| クンニがパイズリ | Base に `cunnilingus`。`-1::paizuri ::` は Base 1つ |
| コマにならない／等分の縦3 | 骨格の階層英語とピンを [Layout_Skeletons.md](Layout_Skeletons.md) どおりにする。日本語のコマ割り文・YAMLを足さない（R-LAY-02、R-LAY-04） |
| 縦4コマが 2×2 | 階層英語の `not a two-by-two grid`、縦長、ピンの y（R-LAY-03） |
| フキダシが別人 | 「」を話者の顔カードへ。口元の日本語を消す（R-TXT-05） |
| 話者取り違えが3枚同じ | 人物ごとに `yellow speech bubble` 等を固定する。ページ間で同じ人物の色を変えない。既定では付けない |
| フキダシに英語 | タグ行の `text:` をやめる。末尾は「」だけ。ドライランで `Text:` が日本語のみか見る（R-TXT-01） |
| 空フキダシ | 無言ページから `speech bubble` を外す。無言 Character から `speech bubble` / 「」を外す（R-TXT-02） |
| 文字化け | 思考は `thought bubble` と「」。`sound effects` を外す（R-TXT-04, R-TXT-06） |
| ツーショットが別コマ | ピンを同じコマ矩形内へ。発話者だけに「」。相手は無言カード（R-LAY-05） |
| 小さい挿入顔 | 二人目に画角タグ。UC の `chibi, extra faces`。フキダシ内の顔を禁止（R-LAY-05, R-TXT-04） |
| 指定服が別物 | キャラ固定の服を Character にフル。反対服の `-1::` は Character 1セット |
| 指定色が違う | 色タグを外見固定どおり。同じ服のあいだページで変えない（R-TAG-01） |
| 体格差が消える | `size difference` と体型タグ。`chibi` で小柄を代用しない（R-TAG-10） |
| 着衣が裸 | 着衣カードの `-2::nude ::`。同一ページに全裸カードを置かない |
| 軸が逆転 | 誰が上／向きを残し、逆系統を `-1::` |
| 4コマが同じ立ち絵 | カードを出現どおり。画角を分ける。余ったピンを置かない（R-LAY-05、R-TAG-11） |
| 隣接コマが同じ絵 | 領域語だけでは足りない。コマごとの動作（屈む／キス／ベルト／振り返る等）かカメラを変える。Base に1コマだけのキスを置かない |
| 再生のセリフが生身 | そのカードを `cellphone, phone screen`。今の人物は別。Base から再生の体勢を外す（R-LAY-06、R-LAY-07） |
| 話者が脚本と違う | 「」を発話者の顔カードへ。脚本の話者が間違っているなら脚本を先に直す（R-TXT-05） |

## コマンド

1ページあたり、**プロンプトを変える前に**再生成3回（現行1枚は残し、候補最大3枚）。

```bash
python3 scripts/nai_generate.py --page 4 --count 3 --out-dir work/generated/<folder> work/drafts/<prompt>.md
python3 scripts/nai_adopt.py --dir work/generated/<folder> --page 4 --list
python3 scripts/nai_adopt.py --dir work/generated/<folder> --page 4 --take 2
python3 scripts/nai_adopt.py --dir work/generated/<folder> --page 4 --take canonical
```

`--count 1 --page N` は `page-NN.png` を上書きする。再生成ループでは使わない。
