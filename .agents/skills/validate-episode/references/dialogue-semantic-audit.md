# 台詞監査の手順

判定の正本は `guidelines/02-narrative-craft.md` §4-10、確認項目は `guidelines/06-revision-checklist.md` の B、迷う構文は `guidelines/07-dialogue-examples.md`。このファイルは抽出と裁定の手順だけを持つ。

## 範囲

| 依頼 | 範囲 |
|---|---|
| 一話の生成・全文監査・修正モードの再確認 | 対象の全台詞 |
| 局所修正 | 06 の表。当該台詞、応答、関係を決める場面 |

抜き取りや検索語に当たった箇所だけを、全文監査の完了にしない。

## 抽出

```bash
python3 .agents/skills/validate-episode/scripts/dialogue_context.py <対象ファイル>
```

通し番号と近傍行は読みの足がかりである。近傍二行は判定窓ではない。省略が解けるかは、その時点で読者に示された場面と既知情報で決める（02 §4-10）。`--only-candidates` は予備であり、完了証跡には使わない。

地の文内の引用と埋込発話も、人物の声や叙述ラベルに関わるときは飛ばさない。

## 裁定

各台詞を、完成した表現から読める関係と場面とで比べる。02 §4-10 の手順で、話者、聞き手、各動詞の行為者と対象、態、否定、時点、発話目的を見る。

要修正にするのは次である。

- 行為者、対象、所有者、能動・受身・使役・授受、否定、時点、命令の強さが場面と違う
- 役割説明や執筆依頼が、修正のためだけに「」へ入っている
- 絵または地の文が既に見せている進行中の行為を、台詞が説明している（02 §4-10 の定義）
- 必要な人物関係が、提示済みの場面を読んでも定まらない

残置にするのは次である。

- 場面から解ける省略、機能する短答
- 皮肉、嘘、言いよどみ、詩的表現、気持ちが一つに定まらない余白

気持ちが一つに定まらないことと、行為者が取り違えられることは別である。一文への言い換えを合格条件にしない。

「〜ながら」「〜たまま」「〜て」は 02 §4-10 の接続の注意に従う。形だけでは落とさない。行為者を省いた能動の「〜たまま」を別の人への命令へつなぐと、命令された人の行為として読まれやすい。状態の「開いたまま」まで同じ規則にしない。

このリポジトリで繰り返し誤る型は、規則の追加ではなく次の節で見る。

| 型 | 見る節 |
|---|---|
| 汎用動詞だけで工程が消える | 02 §2-2 |
| 回数や文字数が、読める流れと違う | 02 §2-4 |
| 役割説明を「」に足して修理する | 02 §4-10、07 §9 |
| 行為者を省いた能動の「たまま」＋別の人への命令 | 02 §4-10 接続の注意、07 §6 |

## 直し方

採否は `guidelines/05-ai-guardrails.md` §3-4。台詞の構文は 02 §4-10 の手順4へ戻る。役割説明を足して修理しない。文章の修正は `humanize-ai-writing` が受け持つ。

## 証跡

ファイルごとに「抽出台詞数／要修正数／修正数／意図的残置数／未裁定数」を記録する。未裁定が残る間は監査未完了とする。残置には、場面のどこから関係が読めるか、または余白を残す理由を一文付ける。

固有語や能力の言い方を変えたときは、同じ略記を持つ scene-card・continuity・正典を検索し、正本と本文を同期する。
