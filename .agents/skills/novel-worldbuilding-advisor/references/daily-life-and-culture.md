# 風土・食事・文化・宗教・言語（生活の手触りの各論）

## 0. 因果チェーン設計（このファイルの使い方）

生活文化の設定は単発で置かず、**気候・地形 → 農業・産物 → 食事 → 経済 → 祭事・宗教 → 気質・対立**の順に因果で降ろす。相談では、ユーザーが決めている一点（たとえば「寒い山国」）を起点に、この鎖を一緒に降りていくのが基本の進め方。

例：寒冷な高地 → 小麦不可・燕麦と大麦、羊の放牧 → 主食は燕麦粥と黒パン・乳製品豊富・野菜は根菜と塩漬け → 羊毛が唯一の輸出品で塩と鉄を輸入に頼る → 春の放牧開始と秋の屠畜が二大祭。冬の間の手仕事（織物）が女性の社会的力の源泉 → 気質は寡黙・倹約・相互扶助が固い。平地の商人を「軽い連中」と呼ぶ → 塩の値段を吊り上げる隣国との慢性的な緊張……

このように**1つの地理条件から対立と物語のフックまで一本で繋がる**。鎖が繋がった設定は、どこを本文に出しても他の部分の気配が滲む。

## 1. 風土と気候

- **決めるのは3点だけでよい**：①緯度帯（作物と冬の厳しさ）②海との距離（海洋性＝温和多雨／大陸性＝寒暖差と乾燥）③水源（大河・湧水・氷河）。この3点から農業・交易路・国境線がほぼ導ける。
- 山脈は「気候の壁」かつ「文化の壁」。山脈の風上と風下で降水量が変わり（雨陰）、言語・宗派・食文化が分かれるのが自然。**国境を川や山に引くと、世界が勝手に立体になる**。
- 気候は暦とセット：作付け・収穫・航海可能期・戦争可能期（収穫後〜降雪前が伝統的な戦役季節）を決める。「なぜ今この季節に事件が起きるか」に世界が答えられるようになる。

## 2. 食事（最強の世界観アクセント）

食事描写は最少の字数で階級・地域・季節・経済を同時に開示できる。本リポジトリ三大原則の「固有名詞＋非視覚感覚」とも直結する。

- **食事の基準線**：穀物、豆、野菜、乳製品、肉、魚、酒の比率は、地域、世紀、季節、身分、宗教上の禁忌で大きく変わる。中世西欧風ならパンや粥、豆、地域の野菜、エールや葡萄酒は候補になるが、「肉は祝祭だけ」と一律にしない。
- **飲料**：安全な水は井戸、泉、河川、雨水などから日常的に飲まれた。酒も栄養、保存、嗜好、社交のため広く飲まれたが、「水は危険なので子供まで酒しか飲まなかった」という説明は避ける。水質は場所と管理状態で決める。
- **階級差の見せ方**：精製度の高い穀物、輸入香辛料、砂糖、調理燃料、食器、供される品数は富の表示になり得る。価格は産地・交易路・時期で変動するため、「香辛料は同重量の銀」と固定しない。
- **保存技術が食の骨格**：塩漬け・燻製・乾燥・酢漬け・チーズ化。冬の間は保存食で生きるため、**塩は戦略物資**（塩税・塩街道・製塩地の争奪は戦争の理由になる）。
- **季節の飢え**：収穫前の端境期（春〜初夏）が最も飢える、という逆説は物語に使える。豊穣の秋→冬至の宴（家畜の間引き屠畜で一時的に肉が出回る）→春の飢え、の年周リズム。
- **アクセントの入れ方**：料理名を1つ発明し（実在名の直用より「地名＋調理法」型：「○○風の腸詰め」「峠の黒粥」）、食感・温度・匂い＋「誰がいつ食べられるか」を1行添える。それだけで階級と風土が同時に立つ。

## 3. 社会構造・法・仕事

- **土地と身分**：土地保有、賦役、地代、軍役、移動制限の形は地域・世紀ごとに異なる。農奴、小作、自営農、季節労働者、巡礼者、商人が併存し得る。庶民の移動範囲を一律の半径で決めず、市場、婚姻、出稼ぎ、巡礼、戦争、街道から導く。
- **都市**：自治権、市民権、ギルド、居住による身分変化は都市ごとの法慣行として設計する。「一年と一日で自由」等は特定地域のモデルであり普遍法ではない。冒険者ギルドには、参入、独占、相互扶助、徴税のどれを担うか決める。
- **識字と情報**：読み書き能力は言語、用途、身分、都市化、時代で大きく異なる。固定の識字率を置かず、契約を読める、典礼文を読める、帳簿を付けられる等の機能で設計する。市場の噂、商人、説教、使者、代読も情報経路になる。
- **法と刑罰**：近代的警察がなくても、夜警、役人、領主・都市裁判所、教会法廷、共同体の自警など多様な執行機関があり得る。身体刑、罰金、賠償、追放、拘禁の比重は地域・犯罪・身分で決める。
- **医療**：体液説・薬草・祈祷・理髪外科医。抗生物質なき世界では**化膿が死病**。傷・出産・疫病の致死性が、治癒魔法の価値（＝経済と権力）を規定する。

## 4. 宗教・暦・祭事

- 宗教設定は神話から書かず、**生活側から書く**：①庶民は何を祈るか（豊作・安産・航海安全）②聖職者は何を禁じられているか③暦のどの日が休みか④葬送の作法。この4点が決まれば神学は後回しでよい。
- **暦と祭は労働のリズム**：播種祭・収穫祭・冬至祭・年迎え。祭は「合法的な無礼講」（身分の一時逆転・仮面・大食）として設計すると、事件の舞台に使いやすい。
- **時刻**：機械時計以前は「鐘」と「祈りの時刻」で1日を区切る（夜明けの鐘・正午の鐘・晩鐘）。夜間は更（見張りの交代単位）で数える。「午後3時」ではなく「晩鐘の前」と言う世界は、それだけで時代の空気が出る。
- 多神世界なら**職掌の重複と縄張り争い**（商業神と航海神のどちらに祈るか）、一神世界なら**正統と異端**（教義解釈の分裂）が対立の自動生成器になる。

## 5. 言語・名前・呼称

- 人工言語は不要。**文化圏ごとに音韻ルールを3行**決める：使う子音・母音の傾向／音節数／語尾のパターン。例：「山岳氏族＝硬い子音と単音節（ドルグ、カズ）」「古帝国系＝母音終わりの3音節（アウレリオ、サビナ）」。読者は音だけで出身を識別できるようになる。
- **名前の構造**が社会を語る：姓の有無（庶民に姓がない世界）／父称（「○○の息子□□」）／地名姓／職業姓。貴族だけが姓を持つ、という一点だけで身分社会が伝わる。
- **蔑称・自称・敬称**：隣接文化圏への俗称（蔑称）と、その語源を1つ作ると民族関係の歴史が滲む。敬称体系は `guidelines/03-character-and-world.md` の階級・敬称ルールと整合させて設計する。
- 度量衡・通貨の名称は technology-and-logistics.md §5〜6 と連動。**名づけの原則は「意味が透ける造語」**（「一鐘」「半日里」）で、無意味な音の羅列を避ける。

## 6. アクセント移植の作法（ナーロッパ既定の作品向け）

王道ナーロッパ（ゲーム的異世界）の作品に本格要素を足す場合の規律：

1. **少数に絞る**。本格アクセントは、物語と読者負荷に見合う数だけ選ぶ（例：塩の経済／鐘の時刻制／端境期の飢え）。個数を固定せず、全域の考証が作品のジャンル契約を壊さないか確認する。
2. **快感の邪魔をしない**。テンプレの快感原理（novel-plot-advisor の管轄）を停滞させる考証は入れない。アクセントは「風景と手触り」に留め、手続きの複雑化（両替のたびに計算描写等）はしない。
3. **主人公の困りごとに絡める**：導入するアクセントは、できれば主人公が一度つまずく形で登場させる（設定開示の原則。reader-immersion.md 参照）。
