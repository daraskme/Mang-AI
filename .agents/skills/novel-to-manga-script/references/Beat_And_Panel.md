# 変化の単位からコマへ

小説の文・段落・章をコマにしない。**場面**（場所または目的）と**変化の単位**（ビート）と**コマ**は別の数。ページへ書く前にビートを置く。欄の形は [Page_Handoff_Contract.md](Page_Handoff_Contract.md)。台詞の本数は [Principles.md](Principles.md)。

5コマ以上、横長3段の回数制限、79種テンプレ、PSD/PNG工程、フキダシ形は所有しない。物語ページは2〜4コマ。

## ビート

各ビートに次を持つ。欠けたらページにしない。

- 動詞（探す、気づく、隠す、頼む、拒む、待つ、決める、見せる、受け取る、など）
- 誰の変化か
- 何が変わるか（知識／関係／選択肢。雰囲気だけは不可）
- 原作範囲

同じ動詞が続くときは、強調として差分を残すか、重複として MERGE する。1ページ1目的。複数ビートを載せるときは主たる変化の動詞を **目的** にし、他は小さいコマへ。話題名（教室、鍵、会話）だけにしない。体勢不変の連続発話のまとめは [Page_Handoff_Contract.md](Page_Handoff_Contract.md)。

## 刺激 → 認識 → 選択 → 応答

出来事を見た人物が、何を理解し、何を選び、どう動くかを絵で追う。反応が唐突なら、見たもの・理解・判断のどれかが抜けている。全部をコマにしなくてよい。欠けている輪だけ足す。

転換の前は予期する材料、後は受け取る反応。両方を長くしない。その場面で味わわせたい側へ面積を使う。待つ時間を延ばすなら、危険・期待・迷いのどれかを変化させる。同じ状態の反復は短くする。

場面は、目的に関わる変化が始まる位置から描く。終わりは決着に加え、結果を受け取る反応が必要かを見て残す。同じ状態のあと置きは残さない。

一つの出来事への反応を並べる順で、誰の感情を追うかが決まる。主役へ戻る位置を決める。群像でも感情の軸を一人に残す。

## 前振りと応答

次のコマは、前のコマが作った「次に知りたいこと」に答える。コマを増やす前に、密度を変えるのか、知らせる時点を変えるのかを決める。

| 後で渡すもの | 先に作る関心 |
|---|---|
| 動作の結果 | 起点。「どうなるか」 |
| 正体 | 一部だけ。誰か、何か |
| 表情 | 状況の引き。どんな顔か |
| 位置と周囲 | 寄りの反応。何を見ているか |
| 理由 | 気になる結果・発言・反応。なぜか |

寄りと引きを交互にする規則にはしない。関心がすでにあるなら、そのまま答えを渡す。状況が不明なことと、分かった先が気になることを混ぜない。驚きや余韻を優先する場面は、前振りを省いてよい。長い説明は、その理由を知りたくなる足場がある範囲だけ残す。答えが先に読める配置は下の「核心の位置」。

説明者の主張、画面で観測できる結果、人物の仮説を一つの事実にしない。予測と違う結果でも前の事実は消さず、どの仮説と次の行動が変わったかをつなぐ。

## 切る／まとめる

切る（別コマにする）:

- 動作の時点が違う（構えと接触。既定は [Page_Handoff_Contract.md](Page_Handoff_Contract.md) 動作のコマ）
- 期待が外れる、事情が分かる、方針が変わる（動作が続いていても）
- 相手から得るやり方（頼む、試す、隠す）が変わる
- 原因より結果が先に目に入ると困る
- 出入り・音・中断で、誰の選択が変わる。飾りなら切る。中断を、元の問題が解決したことにしない。元の争点は残す

まとめる（同一コマにしてよい）:

- 同時に見えても狙いが保たれる
- 移動の全過程より、理解に必要な始点と結果

一文一コマにしない。一発話一コマにもしない。

## 情報差

次を混ぜない。作者だけが知る事情を、読者既知として台詞や表情にしない。

| 配置 | 使うとき |
|---|---|
| 読者だけが知る | 心配・伏線。人物は知らない顔と行動のまま |
| 人物だけが知る | 読者は後で追う。先に結論の顔を出さない |
| 同時に分かる | 発見と反応を同じ拍で渡す |

隠すこと自体を目的にしない。心配／疑問／驚きのどれを作るかを先に決める。

## コマの主対象と働き

各コマで最初に見てほしい対象を一つ決める（顔／手／小物／空間／距離）。働きは動詞一つ。指定は「何を理解させるか」＋「何が画面にあるか」。角度や距離だけの指定にしない。

受け止めが核なら聞き手を描く。話し手は、話者が特定できる位置で足りる。顔の無いコマに発話を置かない（[Page_Handoff_Contract.md](Page_Handoff_Contract.md)）。切り返しは発言順ではなく、距離・主導・参加者が変わるとき。

見る人 → 対象 → 反応、の順は [Principles.md](Principles.md) 視覚優先。誰が何を知ったかが核なら、対象だけで終わらせず人物側の変化も出す。

空景は時間経過・不在・状況変化のどれかの役割を持つ。何も変わらない背景は切る。無言コマは、見る対象と直前からの見える変化（手、物の状態、距離、光）を置く。無言**ページ**は禁止（[Page_Handoff_Contract.md](Page_Handoff_Contract.md)）。

同じ構図を反復するときは、比較してほしい差分だけ変える。前後のコマは対で意味を作る。単独の絵がよくても、並べて因果が壊れたら失敗。

## 核心の位置

核心語と核心の絵は、反応が始まる位置へ置く。同一ページで答えが先に読める配置にしない（右上や大きいコマにオチの顔、先に読めるフキダシ）。話末ヒキとオチは次ページへ送ってよい。本Skillは1ページ単位（NAIは1生成1ページ）。見開き同時視認は見ない。

## 時点が飛ぶとき

回想、同時進行、時間の省略があるコマだけ、読める事実に次を書く。切替の無いページへは足さない。時系列順への統一はしない。

- 描く時点（いつ、どこ）
- 語っている時点と描く時点が違うなら、その差
- 切替または戻りの手掛かり（台詞、姿、場所、物の状態）。黒いコマ間だけで時点を伝えたことにしない
- 時点を伏せるなら、後のどのページで分かるか

## 小道具

初出に、今の場面で自然な役目を与える（持つ、渡す、隠す、見る）。後で効くためだけの置物にしない。再登場は情報か関係を更新する。同じ意味の重複は MERGE。以前した行動をしないことも変化になる。

直接言えない争点は、共同の作業や持ち物の扱いに預けてよい。小物だけでは事情が分からないなら、前後のコマに手がかりを足す。日常の作業が止まる、速くなる、やり直される変化を、感情の手がかりにする。同じ楽しさの反復だけで、関係が深まったことにしない。

前振りと応答、時点の飛び、やり方の変化、中断、小道具への争点は、MangaAgentsStudio-A（MIT、2026-09-23確認）の制作提案を本契約向けに縮約した。読者試験済みの規格ではない。
