# 解析からページまで

正本は小説本文。要約してからページを書かない。読む（因果・決め台詞・服／軸）→「」を割る → 変化の単位を置く → 場面ごとに原作範囲を開き直してページを書く。文とコマを一対一にしない（[Beat_And_Panel.md](Beat_And_Panel.md)）。

## ターゲット

```text
format: manga_page
output_mode: analyze | episode_map | page_script | storyboard
fidelity: strict | balanced | bold
panels_per_page: 2–4
```

未指定の output_mode は `page_script`。数値は初期値。1ページあたりのコマ数目安としてのみ使う。換算・目標化はしない。ページ数の指定があるときだけページ重みと目標に使う。ユーザー指定とジャンルで上書きする。1話コマ数の普遍換算は置かない。入稿画素は所有しない。長い対象は場面単位でページを足す。全文IRから一括でページを出さない。

## 読む（まだ書かない）

抜くもの：前提、ジャンル契約、主人公の目的と不足、中心対立、登場人物の目標／恐れ／矛盾、因果、開示、伏線、逆転、決め台詞、固有ルール、モチーフ、原作にある外見、確定した服・色・場所・軸の連続、読者と人物の情報差。ミステリーは開示順を先に固定する。

この抜粋を正本の代わりにしない。ページを書くときは対応する本文を開き直す。

## 発話割当

対象範囲の「」を先に列挙する。各行をいずれかのページへ載せる。長さだけ切ってよい。本数は落とさない。未割当が一つでもあれば未完成（Q-DI-02）。

話者ラベルの無い連続「」は、直前話者の続きか相手の応答かを直後の地の文で決める。拒否・制止は行為を受けている側。根拠が無い相手への割り当てはしない（Q-DI-16）。観察（視線が止まる、手が止まる、匂い）は読める事実であり、「」にしない（Q-DI-15）。

出力は `## 発話割当`（[Output_Formats.md](Output_Formats.md)）。内部メモで済ませない。

## 変化の単位

「」の次に、場面を変化の単位へ分解する。詳細は [Beat_And_Panel.md](Beat_And_Panel.md)。ページの前に動詞・誰・知識／関係／選択肢の差・原作範囲を持つ。読者だけが知る／人物だけが知る／同時に分かる、を混ぜない。

## シーンの機能

各シーンに function（人物紹介、目的、世界説明、関係変化、伏線、開示、行動、感情の報酬、接続）。must_preserve / visual_anchor / cut_risk。開始と終了で、知識・関係・選択肢のどれが変わるかを書く。変わらないなら導入・余韻としての働きを持てるか見る。持てなければ切る。

雰囲気だけの小説シーンを機械削除しない。恋愛の距離、恐怖、愛着、世界の手触りを担っているなら背景・小物・短い交流へ移す。交流まで消して無言だけにしない。小道具の初出には今の場面の役目を与える。

## 再配分タグ

VISUAL / ACTION / EXPRESSION / PROP / DIALOGUE / MONOLOGUE / NARRATION / SFX / CUT / DEFER / MERGE / REORDER。

一文一タグに縛られない。主搬送を一つ決める。CUT/DEFER は今の場面に不要な設定だけ。**今開いている原作範囲の観察を薄くするために使わない。**

## 各話

章の切れ目を捨て、因果で切る。原作第1章が導入だけなら、衝撃場面を第1話末へ前倒してよい（重大事件の新造ではない）。各話：

- 読者の問い
- 主人公が今しようとしていること
- 開始状態／終了状態
- 今回返す答えと、続きへ持ち越す課題
- エスカレーション
- 見せ場
- 感情の報酬
- ヒキと次話の約束
- must_show / can_defer

1話は原則1〜2シーン。場所または目的が変わったら切る。

第1話ゲート：主人公が誰か、何を望むか、何が問題か、ジャンルの約束、感情の種、次の問い。lore dump で始めない。

## ページ重み（指定時だけ）

compress / normal / emphasize / showcase / climax。ジャンルとヤマで再配分する。固定の話数型を当てない。体勢も位置も変わらない連続発話は compress で同一ページへ（[Page_Handoff_Contract.md](Page_Handoff_Contract.md)）。

後工程（NAIの1ページ引用数など）の上限を、この段階の発話リストへ当てない。載り切らなければプロンプト側がページを分ける。

## ネーム（page_script / storyboard）

場面ごとに、その原作範囲を開き直す。ビートの動詞をページの目的にする。見せ場コマを先に決め、カタログから骨格を選ぶ。各ページに **原作**（行番号）、骨格名、読み順、各コマの絶対位置。各コマは主対象一つ・働きは動詞一つ。刺激のあと認識または反応を残す。核心は同一ページの先に漏らさない。選び方・無言禁止・読める事実の粒度・体勢不変の発話のまとめ・位置の軸・誰の目か・背景の出し分け・動作の状態差分は [Page_Handoff_Contract.md](Page_Handoff_Contract.md)。切る／まとめるは [Beat_And_Panel.md](Beat_And_Panel.md)。読める事実は、その範囲の観察（手、距離、光、髪、接触）を移す。ラベルだけにしない。その文に無い服・軸・場所は [Principles.md](Principles.md) の文脈補完。隣接ページは骨格名を変える。カメラだけの差分で同じ骨格を続けない。同じカメラ型を3ページ連続しない。等分の縦3で埋めない。初期値のコマ数を満たすために、体勢不変の発話を1本ずつ割らない。ロック文と x,y は書かない。

## ページが読めるか

脚本を出す直前に、各ページで次が残っているか見る。欠けたら未完成。

- **原作**（行番号。本文と対応する）
- 誰がいるか
- どこか（場面の最初のページで場所が出ているか。以降の寄りは必要な物だけ）
- 何をしているか（1コマが1時点か）
- なぜ今それが起きるか（ページの目的が変化の動詞か）
- 各コマの主対象が一つ、働きが動詞一つ
- 刺激のあと、認識または反応が見えるか。動作が続いていても、期待が外れる／事情が分かる／方針が変わる瞬間が別コマか
- 核心の絵または核心語が、反応より先に同一ページで読めていないか
- 無言コマに、直前からの見える変化があるか
- 発話があるとき：話者 → 相手 ／ 関係と「」。関係は相手を動かす動詞
- 骨格名、読み順、各コマの絶対位置（誰と見える動作とカメラ）
- 出現（人物×コマ）
- 読める事実（今の服と色、場所1系統、その原作範囲の観察、コマの状態・視点＝誰の目か・向き・視線の先・位置の軸・体勢・手、行為があれば系統と誰が上。体格差があれば錨。[Page_Handoff_Contract.md](Page_Handoff_Contract.md)）
- 無言コマの配置に話者なしがあるか
- 同一場面で、引きを挟まず左右／上下が逆転していないか
- 対象範囲の「」が発話割当ですべてページに載っているか
- 観察の地の文が「」や内心の命令になっていないか
- 再生の声と今の人物が別コマか
- 前ページの終了がこのページの開始に残っているか
- 時間が飛ぶページは、描く時点と戻りの手掛かりがあるか（[Beat_And_Panel.md](Beat_And_Panel.md)）
- 長い説明の前に、その理由を知りたくなる足場があるか

保存したあと、確認ゲート（SKILL.md）で止める。

## 中間表現（内部）

脚本の前に、シーン単位で持ってよい。出力にYAMLを常時出さない。ページ本文の正本にしない。

```text
scene_id / source_span
function / turn
beats（verb / actor / delta / knowledge）
visual_anchors
dialogue_candidates（draft。長さは切ってよい。本数は落とさない。話者・相手・関係を持つ）
must_preserve / flexible / cut_candidate
page_weight / episode_target
```

## 変換ログ（内部）

大胆に動かしたら残す。利用者へは求められたとき、または因果に触れたとき。発話の落ちは変換ログではなく `## 発話割当` で見る。

```text
source / action（defer|merge|cut|reorder|visualized|added_bridge|added_from_context|split_on_turn|delayed_reveal） / reason / preserved_information / moved_to
```
