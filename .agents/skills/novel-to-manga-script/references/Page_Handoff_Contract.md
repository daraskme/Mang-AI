# ページ受け渡し契約

`contract: page-handoff-v3`

page_script のスキーマとページ欄の正本。ロック文とピンの x,y は脚本に書かない。1ページ＝日本漫画2〜4コマ。縦スクロールWEBTOON連作の画像化はしない。骨格名は下のカタログだけ。英語タグはプロンプト側。各ページの正本は小説本文の **原作** 範囲。

相互にファイルパスで参照しない。本ファイルを改めたら `contract` の版を上げ、参照側の版と揃える。

## 所有

脚本が書く：原作範囲（行番号）、ページの仕事、骨格名、読み順、各コマの絶対位置と大きさ、各コマの誰、そのコマで見える動作、今の服／裸、誰の目か、視線の先、各人の右／左または上／下、行為の系統（日本語）、竿・結合が見えるか、話者の顔があるコマ／話者なし、出現（人物×コマ）、色（必要なとき）。

脚本が書かない：ロック文、ピンの x,y、英語タグ、フキダシの形、Text mode、Artist、Quality Tags。顔の寄りはショット。読める事実が身体・行為ならそのコマに身体を出す。その一文に無い観察可能事実は [Principles.md](Principles.md) の文脈補完。

## ページ欄（欠けたら未完成）

```markdown
**原作:** L1–8
**ページ:** 縦2（上大） ／ 読み順 上から下
**配置:**
- 第1コマ（上の大）: 女の腰上。画面右。男は写さない。話者なし。
- 第2コマ（下の小）: 女の顔。話者は女。
```

**原作** は本文の行番号。`L開始–L終了`。飛びは `L21–29, L33`。欠けたら未完成。この範囲を開き直して配置と読める事実を書く。

連作では `## この話の目的` の直後に `## ページ` 表を1つ。列：ページ／目的／骨格／読み順／原作。セリフ本文は表に書かない。骨格名はカタログどおり。続けて `## 発話割当`（[Output_Formats.md](Output_Formats.md)）。

コマ役割（任意、storyboard では必須）：ESTABLISH / ACTION / REACTION / DIALOGUE / EMOTION / INSERT / REVEAL / SHOWCASE / TRANSITION / PAUSE / CLIFF。

## 発話行

```markdown
**発話:** 話者 → 相手 ／ 関係
話者「セリフ」
```

- 区切りは全角 `→` と全角 `／`（U+FF0F）。
- 行：`^\*\*発話:\*\*\s*(.+?)\s*→\s*(.+?)\s*／\s*(.+)\s*$`
- 直後：`^(.+)「([^」]*)」\s*$`
- 内心：`^\*\*内心:\*\*\s*(.+?)` のあと（思考）。脚本の思考は「」にしない（プロンプト側がくも形と「」にする）。
- 同一ページで発話と思考を混ぜない。「」は発話だけ。

## コマ割り（仕事で選ぶ。記号を回さない）

カタログ外の名前を作らない。等分の縦3（上／中／下が同じ高さ）は置かない。

選ぶ順：

1. そのページで一番見せたいコマ（SHOWCASE）を先に決める
2. それが最大になる骨格をカタログから取る
3. 残りを小さいコマへ逆算する
4. 直前ページと骨格名が同じなら、別の骨格に替える

| このページの仕事 | 骨格 | 読み順 |
|---|---|---|
| 見せ場が上、受け・オチが下 | 縦2（上大） | 上から下 |
| 溜めが上、見せ場が下 | 縦2（下大） | 上から下 |
| 場所の引きと会話とオチ顔 | 上横長＋右下大＋左下インセット | 上→右下→左下 |
| 手順3拍、同一話者の3連 | 上大＋下2 | 上→右下→左下 |
| 3拍で中が核 | 縦3（中大） | 上から下 |
| 4ビート。下にアクションと反応 | 2×2（下段大小） | 右上→左上→右下→左下 |
| 右を見せ場、左は溜め、下は着地 | 左2＋右縦長＋下横長 | 左上→左中→右縦長→下 |
| 会話の切り返し（大小なし。連続させない。同一人物の同じ画角4連には使わない） | 2×2 | 右上→左上→右下→左下 |
| 縦の落下・追走だけ | 縦4 | 最上段→最下段 |

1ページは2〜4コマ。1コマだけのページは挿絵であり、本契約の物語ページではない。5コマ以上はページを分ける。

隣接ページは骨格名を変える。カメラだけ変えて同じ骨格を続けない。同じカメラ型を3ページ連続しない。

絶対位置の書き方（領域名は骨格と一致）：

- 縦2（上大）：第1コマ（上の大）／第2コマ（下の小）
- 縦2（下大）：第1コマ（上の小）／第2コマ（下の大）
- 上横長＋右下大＋左下インセット：第1コマ（上の横長）／第2コマ（右下の大）／第3コマ（左下のインセット）
- 上大＋下2：第1コマ（上の大）／第2コマ（右下）／第3コマ（左下）
- 縦3（中大）：第1コマ（上の小）／第2コマ（中の大）／第3コマ（下の小）
- 2×2（下段大小）：第1コマ（右上）／第2コマ（左上）／第3コマ（下段の大）／第4コマ（下段の小）
- 左2＋右縦長＋下横長：第1コマ（左上）／第2コマ（左中）／第3コマ（右の縦長）／第4コマ（下の横長）
- 縦4：第1コマ（最上段）から第4コマ（最下段）
- 2×2：第1コマ（右上）／第2コマ（左上）／第3コマ（右下）／第4コマ（左下）

「次のコマ」「最後」だけの相対語で終わらせない。見せ場のコマを他より広く。3〜4コマを等分にしない。

脚本は配置文まで。x,y は書かない。

## 無言ページを作らない

各ページは発話または内心を1つ以上持つ。無言のコマは、同じページの他コマに発話／思考があれば置ける。そのコマの配置に **話者なし** と書く。見る対象と、直前コマからの見える変化（手、物の状態、距離、光）を置く。変化のない空景は切る。見せ場・手順の絵は、同じページの他コマへ入れる。地の文を「」やナレにして無言を埋めない。ヒキで原作に「」が無いときだけ、思考の最短を置く。庭だけの無言ページは作らない。

## 発話のまとめ

体勢・位置が変わらない連続発話は新しいページにしない。同一ページのコマへ載せる。1台詞1ページにしない。

1コマのフキダシは1〜2。同一話者の3連は 上大＋下2 か 上横長＋右下大＋左下インセット の各コマへ1本ずつ。等分の縦3にしない。混ぜ話者の3本は縦2に載せ切れないので、同一話者側だけまとめるかページを分ける。思考と通常はページを分ける。

ページを分けるのは体勢が変わるとき、見せ場の特大、話末ヒキ。決め台詞でも体勢が同じなら、隣の同体勢の発話を他コマへ載せる。まとめたあと読める事実を薄くしない。顔の寄りは1ページ1つ。

引用数上限を理由にここで切らない。載せ切れない発話はページ分割する。

## 動作のコマ

1コマは1つの時点。構えと接触、振りかぶりと命中を同じコマにしない。状態の差で分ける。構え → 途中 → 接触。余波は次のコマか次ページ。再生（画面の中）と今の身体は別コマ。

## 読める事実

各コマに、観察可能な次を書く。**原作** 範囲の手・距離・光・髪・接触・小物を移す。「全身。指。」のようなラベルだけにしない。その文が原作に無くても前文脈から補う（[Principles.md](Principles.md)）。抽象（怒っている、エロい）で止めない。英語タグは脚本に書かない。人物は名前で繰り返す。「彼女」「彼」でコマをまたがない。

ページの先頭（1系統。以降のコマは差分だけ）:

- 今の服／裸。色名を含める。脱いだら更新する。空にしない。同じ服のあいだ色を変えない
- 場所と光。そのコマで残す物だけ。室内と屋外を混ぜない
- 行為があれば系統（跨ぎ／後ろから／対面）と誰が上。英語にしない
- 竿・結合が見えるコマだけ、見えると書く
- 体格差があれば錨（頭頂は誰のどこ）。均さない。ちびで代用しない

コマごと:

- 誰がどのコマにいるか。写さない人。各人の画面右／左、または上／下
- 状態（縮み／戻った背、着衣の層、裸、汗、息）
- 視点（誰の目か：客観／Aの肩越し／A主観／反応のB／カメラ目線。カメラ目線は見せ場だけ。角度はカメラ）
- 向き（こちら、相手、後ろ、振り向き）
- 視線の先（誰または何。次コマで対象を出すならここに書く）
- 位置と体勢（誰が上、膝の上、斜め後ろ、距離、体格差のどちらが小さい）
- 手・指・口・結合など核の位置
- 表情で読める関係（詰る、促す、観念する）
- 擬音は1ページ0〜1。台詞コマに置かない。かぎ括弧に入れない

**読める事実**はコマごとの箇条書きにしてよい。1コマ1主要情報は守る。周りの具体物は落とさない。

```markdown
- 今の服: 女は黒手袋。男は下半身裸。
- 体格差: 女の頭頂は男の肩。同じ身長にしない。
- 寝室。夜。ランプ。白いシーツが乱れている。
- 系統は手。女が上ではない。竿が見える。
- 視点は女の肩越し。女は画面右、男は左。女は男を見る。
- 第1コマ（上の大）: 女は斜め後ろ。男を見下ろす。右手が竿。男の腰。女の顔は出さない。手袋の革が光る。
- 第2コマ（下の小）: 女の顔はこちら。詰る目。口が開いている。手袋の先が画面下。視線は下の男。前髪が頰。
```

## 位置の軸

同一場面・同一体勢のあいだ、誰が画面のどちらにいるかを固定する。会話なら右／左。騎乗・挿入なら上／下。右／左は読者から見て。途中で入れ替えると、誰が誰を見ているか、誰が上が逆転する。変えるときは場所と二人の引きを挟む。体勢転換のページでは新しい軸を書き直す。読める事実と配置に、各人の右／左（または上／下）を毎回書く。

## 背景

毎コマを詳細にしない。場面の最初の引きで場所を出す。場所出しのコマにキャプション文字を要求しない。人物のいない引きは話者なし。会話・寄りは必要な物だけ。位置関係が消える前に引きを戻す。感情の顔は背景を簡略。全コマに教室全体を繰り返さない。場所は二人の距離と、話しやすさを変える。同じ台詞でも、広い場所と狭い場所のどちらがページの目的に合うかを選ぶ。

## 出現

同一人物が複数コマに出るときはコマごとに行を分ける。画角は全身／腰上／顔。同一コマの二人目も画角を付ける。脚だけ・手元だけの端役は出現に書かない（読める事実に残す）。

```markdown
**出現:**
- 第1コマ（上の大）: 女（腰上）
- 第2コマ（下の小）: 女（顔）
```

## 配置で書くこと

- 各コマに誰がいるか。誰を写さないか。各人の画面右／左、または上／下
- そのコマで最初に見てほしい対象は一つ。働きは動詞一つ。見える動作（読める事実）
- 話者の顔があるコマ。**発話** 欄の話者 → 相手と一致させる。顔の無いコマに発話を置かない。無言コマは「話者なし」と直前からの変化
- 再生・画面の声と今の人物は別コマ。配置と出現に「画面のX」「今のX」と書く。同一コマに同居させない
- 行為があるコマには、その人の**身体**を置く。顔カードを別コマに出しても、押し倒し・騎乗・跨ぎのコマから身体を外さない
- 視線の先。上コマは下へ送る。核心の絵と核心語は、反応が始まる位置へ。予告コマに正体を出さない。同一ページで答えが先に読める配置にしない
- 手前に肩・物を入れるときはそのコマに書く
- 窓の外の顔、後頭部、手元、脚
- ピンも数字も書かない

カメラの語：引き／腰上／寄り／顔／手元／窓の外の顔／後頭部／斜め横／見上げ／見下ろし／肩越し／手前。

見上げ・見下ろしに、力や弱さなどの固定の心理を割り当てない。高さ、奥を隠す、位置を整理する、など必要な情報から選ぶ。手前で隠すときは、読者に見せないものを先に決める。見づらいだけの構図にしない。

## 単調を避ける

- 隣接ページは骨格名を変える。カメラだけの差分で同じ骨格を続けない
- 同じカメラ型を3ページ連続しない
- コマごとの人物の組み合わせを変える。全コマ同じ二人の引きにしない
- 顔の寄りは1ページ1つ
- 行為の核は顔だけのコマに逃がさない
- カタログの骨格を話の中で混ぜる。等分の縦3で埋めない
- 会話は顔の切り返しだけにしない。場所の引き、話し手、反応、手元／物を混ぜる
- 2×2 に同一人物の同じ画角を4つ置かない。余った小コマに立ち絵を足さない
