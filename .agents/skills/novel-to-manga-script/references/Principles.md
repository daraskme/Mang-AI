# 変換の原則

原文の文章を保存しない。読者に与える効果を保存し、漫画のページへ載せ替える。

## 保存するもの／変えてよいもの

保存：因果、動機、感情変化、関係、伏線と回収、謎の開示順、作品固有の快感、象徴、決め台詞、クライマックスの意味。原作に書いてある外見。すでに確定した観察可能状態（今の服、場所、誰がいる、体勢の軸）。

変更可：語順、シーン順、説明の手段、地の文、モノローグ量、会話の**長さ**、場所の細部。接続のための短い橋。その一文に無い観察可能事実の**文脈補完**（下節）。
原作の「」の話者と宛先は変えない。発話の本数は落とさない。

禁止：原作にない重大事件、新しい人物、新しい決め台詞（ヒキの最短思考を除く）、キャラ人格の変更。

## 文脈からの補完

小説のその一文が、コマに必要な観察可能事実を言っていないときは、**同一場面の前文脈**と**すでに書いた脚本ページ**から足してよい。空欄のまま後工程に推測させない。前文脈に無い事実は作らない。

足してよい：今の服／裸（直前の層。脱いだら更新）、服の色（原作に無ければ一度決めて同じ服のあいだ変えない）、場所・時刻・光、誰がいる／写さない、体勢の軸（誰が上、右／左。転換するまで維持）、体格差の錨（頭頂は誰のどこ。指定体型を均さない）、行為の系統（跨ぎ、後ろから、対面。英語にしない）、竿・結合が見えるか、前文で確定した手の位置。

足さない：新しい出来事、新しい人物、新しい「」、地の文の心理を内心へコピーすること。一度決めた服の色をページごとに塗り替えること。

補った内容は **読める事実** に書く。変換ログへ `added_from_context`（求められたとき、または因果に触れたとき）。

忠実度を「文章一致率」にしない。

## 小説の要素 → 漫画の第一候補

| 小説 | 第一候補 |
|---|---|
| 外見・場所 | 初登場の全身／バストアップ、引きの第1コマ |
| 感情の説明 | 表情・姿勢・視線・手・間 |
| 関係 | 距離、呼び方、立ち位置、接触 |
| 性格説明 | 選択・癖・行動・台詞 |
| 状況説明 | ページで読める出来事 |
| 長い独白 | 短いモノローグ＋行動 |
| 世界観 | 必要になった瞬間に小分け |
| 伏線 | 小物、背景、視線、短い台詞 |
| 比喩 | 絵になる像は視覚へ。載せる価値は 05 §3-4。ページに意味を足さない装飾は置かない |
| 余韻 | 大きいコマ＋短いナレか思考 |
| 緊張 | コマ密度、コマの大小、情報の出す順 |
| 章末の文章ヒキ | 視覚REVEAL／反応顔／未完の行動 |

## 視覚優先

```text
絵だけで確実に読める
  → 行動・表情・小物
  → 短い台詞
  → 短いモノローグ／ナレーション
  → 長い説明は最後
今不要な設定 → DEFER
```

「絵で分かるはず」は、作画が人間で、関係が画面にすでに出ているときにだけ省略する。次が NAI など絵が崩れうる経路なら、関係・動機・促し・誰が外にいるかは文字を第一の読み取りにする。絵と台詞が同じ事実を短く重ねてよい（読めなくなる方が失敗）。

語り・呼び方・決め台詞が作品の核なら、長さを切っても本数は残す。

## 内面 → 観察可能

感情名を書かず、矛盾した行動で見せる。口にした内容、意識して隠す事情、本人も言葉にできない欲求を分ける。全部を内心にしない。台詞と身体が逆を向くときは、どちらを本音の手掛かりにするか決め、その不一致を作画や設定の矛盾と混ぜない。

原文：会いたいが、許せば自分が崩れる気がした。

脚本：ドアノブを握る。離す。連絡先を消しかけて止める。看護師に「……まだ」。

モノローグはゼロにしなくてよい。最も強い一文だけ残す。地の文をモノローグへコピーしない。

ト書きは描ける文にする。

悪い：胸に十年分の後悔が黒い雨のように降り続いていた。

よい：返事をしない。濡れた古い写真を握ったまま、目をそらす。

## 台詞

原作の「」は発話である。フキダシにする。地の文を「」にしない。内心は（思考）。ナレは『』で、発話の代わりにしない。擬音はかぎ括弧に入れない。

観察（視線がXで止まる、手が止まる、匂い、肩、距離）は読める事実。命令の「」や内心にしない。

話者ラベルの無い連続「」は、直前話者の続きか相手の応答かを、直後の地の文で決める。拒否・制止は行為を受けている側。根拠が無い相手への割り当てはしない。

**本数は残す。長さだけ切ってよい。** 長い発話は 主張 → 相手の反応 → 理由 → 結論 にページ分割する。切れ目は聞き手の理解が変わる位置。字数だけでフキダシを増やさない。短い返事にも承諾／保留／拒否／探りの仕事を付ける。短い連続発話で体勢・位置が同じなら、ページを増やさず [Page_Handoff_Contract.md](Page_Handoff_Contract.md) のまとめへ。1フキダシ最大3行。文脈に沿って圧縮してよい。ビートを1つにまとめて本数を減らすのは禁止。語尾・呼び方・間延びは声として残す。決め台詞・促し・詰り・告白は一字も落とさない。

各発話に、脚本の段階で次を書く。欠けたら未完成。欄の形は [Output_Formats.md](Output_Formats.md)。

- 話者（誰が言うか）
- 相手（誰に向かって言うか。独白なら「自分」）
- 関係（相手を動かす動詞。詰る、促す、拒む、探る。説明は関係ではない）

表情と場面はこの関係に合わせる。話者と宛先が絵と矛盾したら脚本が先。

既知の事実の繰り返しだけ切る。地の文をモノローグや発話へコピーするのは失敗。無言を埋めるために地の文を「」やナレにしない。

## 情報の予算

今の場面に不要な設定は DEFER。開いている原作範囲の観察（手、距離、光、髪、接触、小物）は読める事実へ移す。ページを薄くするために DEFER しない。第1話は百科より、主人公の魅力・危機・固有の見せ場。

関係のラベル（誰が夫で誰が客か、誰が促したか、誰が見ているか）は百科ではない。各ページに、誰が・どこで・何をして・なぜ今それが起きるか、を残す。発話があるときは **発話** 欄（話者 → 相手 ／ 関係）で運ぶ。

## ページは演出

読者が一度に見るのは1ページである。1コマ＝1つの主要情報／感情／アクション。1コマは1つの時点。構えと接触を同じコマにしない。一文一コマではない。一発話一ページでもない。体勢不変の連続発話のまとめと動作のコマは [Page_Handoff_Contract.md](Page_Handoff_Contract.md)。

重要度が高いほど面積を使う。低重要は圧縮。見せ場コマを先に決め、骨格は [Page_Handoff_Contract.md](Page_Handoff_Contract.md) のカタログ。隣接ページは骨格名を変える。コマ数の目安は [Pipeline.md](Pipeline.md)。変化の単位と核心の位置は [Beat_And_Panel.md](Beat_And_Panel.md)。

余白はコマの大小と白いコマ間で作る。V5画像の中に空白キャンバスとして描かせない。見せ場は次のコマまたは次ページまで隠してよい。

会話を顔の切り返しにしない。手、物、距離、入室、視線の先を挟む。見る人のコマの次に、見られている対象を出す。受け止めが核なら聞き手を描く。同一場面の左右／上下は固定する。

## 作画との境界

原作が持つ：必要な出来事、意図、伏線、絶対に見せる視覚、見せ場の意味、戦闘なら目的・ルール・逆転・決着・決め台詞。

裁量：中間動作、背景ディテール、連撃、指先。コマ数と各コマの誰／カメラは原作が持つ（Handoff）。確定した服の色と体格差の錨は裁量に逃がさない。ロック文とピン座標はプロンプト側。

本文では【必須】と【作画裁量】（必要なら【演出意図】）を分ける。細かく縛りすぎるのも、「ここから戦闘」の丸投げも失敗。

## heuristic（絶対命令にしない）

各話に始まり・変化・高まり・結果・次の欲求。掴みと見せ場とヒキ。ヒキは情報／危機／感情／選択／約束／反転を混ぜ、毎話を大事件にしない。ジャンルと演出で破ってよい。
