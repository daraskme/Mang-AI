# 変換例

地の文を内心へ移すな。情報の搬送手段を変えろ。

## 原文

真琴は教室に入った瞬間、何かがおかしいと感じた。いつもなら騒がしいクラスメイトが不自然なくらい静かだったからだ。机へ近づいて初めて、彼女は自分がみんなから避けられているのだと理解した。昨日の告白のことが、もう広まっているのだ。

## 悪い

真琴、教室に入る。

真琴（何かがおかしい。いつもなら騒がしいみんなが不自然なくらい静かだ）

真琴、机へ。

真琴（そうか。みんな私を避けているんだ。昨日の告白のことがもう広まっているんだ）

小説の地の文がモノローグになっただけ。絵が情報を担っていない。

## よい（再配分の考え方。出力形式ではない）

教室。

ガラッ。

真琴が入った瞬間、笑っていた数人が会話を止める。

視線だけ真琴へ。
一人が慌ててスマホを伏せる。

真琴、自分の席へ向かう。
隣の子が無言で椅子を少し遠ざける。

真琴、立ち止まる。

机の上に、小さくハートを書いた付箋。
「昨日、体育館裏」

真琴の顔から血の気が引く。

**発話:** 真琴 → クラス ／ 避けられたと悟る
真琴「……最悪」

- 不自然な静けさ → 会話が止まる
- 回避 → 椅子を遠ざける
- 告白が広まった → 付箋とスマホ
- 長い心理 → 「……最悪」

## 悪い（過圧縮）

真琴、教室。
席へ。
**発話:** 真琴 → クラス ／ 避けられたと悟る
真琴「……最悪」

絵が関係を描けなかったとき、読者は何が最悪なのか分からない。付箋も視線も、発話の本数も消えている。

関係のラベルが核なら、短い発話を残す。例：**発話:** 隣の子 → 真琴 ／ 知らせる。長さは切ってよい。本数は残す。地の文を「」にしない。

## 悪い（意味の変化を同一コマに詰める）

入室と「避けられている」の理解を1コマにする。動作は続いているが、期待が外れる瞬間が消える。入室／静けさに気づく／避けられたと分かる、は別の変化の単位（[Beat_And_Panel.md](Beat_And_Panel.md)）。

## 悪い（答えが同一ページの先に見える）

付箋を出すコマと、血の気が引く顔を同じページの右上と左下に置き、顔が先に読める。核心の絵は反応が始まる位置へ。先に読めるなら次ページへ送る。

## 悪い（観察を命令台詞にした）

原文：俺の目線は、その肩で止まる。

悪い：**内心:** 純（肩で止めろ）／純「肩で止めろ」

視線の停止は絵（目が肩で止まる）。命令でも独白でもない。読める事実へ。前後の因果が消えるなら、原作にある「」で橋を残す。新しい命令は足さない。

## 文脈補完

原文が「真琴は頷いた」だけでも、直前で制服・教室が確定していれば読める事実へ引き継ぐ。空欄にしない。前文に無い教室を新しく置かない。

## よい（page_script のページ）

隣接で骨格名を変え、コマの誰を変える。カメラだけの差分で同じ骨格を続けない。各ページは原作範囲を開き直して書く。

```markdown
## 発話割当
| 原作 | 話者 | 割当 |
|---|---|---|
| L9 | 真琴「……最悪」 | p02 |

### p01
**目的:** 入室で静けさに気づく。
**原作:** L1–2
**ページ:** 縦2（上大） ／ 読み順 上から下
**配置:**
- 第1コマ（上の大）: 入室の真琴。腰上。話者なし。
- 第2コマ（下の小）: 真琴の顔。話者なし。
**読める事実:**
- 今の服: 真琴は制服。
- 教室。昼。入った瞬間、笑っていた数人が会話を止める。
- 第1コマ（上の大）: 真琴は腰上。こちらではなく席の方。鞄の紐。
- 第2コマ（下の小）: 真琴の顔。視線だけが自分へ集まっているのに気づく。
**出現:**
- 第1コマ（上の大）: 真琴（腰上）
- 第2コマ（下の小）: 真琴（顔）

### p02
**目的:** 避けられたと悟る。
**原作:** L3–7
**ページ:** 上横長＋右下大＋左下インセット ／ 読み順 上→右下→左下
**配置:**
- 第1コマ（上の横長）: 机の付箋。顔は出さない。話者なし。
- 第2コマ（右下の大）: 真琴の顔。話者は真琴。
- 第3コマ（左下のインセット）: 伏せたスマホ。話者なし。
**読める事実:**
- 今の服: 真琴は制服。
- 同じ教室。机。隣の椅子が少し離れている。
- 第1コマ（上の横長）: ハートの付箋。「昨日、体育館裏」。顔は出さない。
- 第2コマ（右下の大）: 真琴の顔から血の気が引く。話者は真琴。
- 第3コマ（左下のインセット）: 伏せたスマホ。話者なし。
**出現:**
- 第1コマ（上の横長）: （なし。付箋）
- 第2コマ（右下の大）: 真琴（顔）
- 第3コマ（左下のインセット）: （なし。スマホ）
**発話:** 真琴 → クラス ／ 避けられたと悟る
真琴「……最悪」
```
