# ジャンル（該当する節だけ読む）

## ミステリー

画面に描いた物は読者に見えてしまう。誰が何を知るか、読者が何を知るか、開示順を先に固定する。読者だけ／人物だけ／同時、の置き方は [Beat_And_Panel.md](Beat_And_Panel.md)。背景の伏線は「存在は見せるが意味は強調しない」と書く。次のコマ／次ページの REVEAL を使う。手がかりの見え方（明らか／控えめ／背景）を指定する。

## 内省・文芸

ためらい→手を出して止める。孤独→距離・空席。執着→同じ物を何度も触る。嫉妬→本命ではなく第三者を見る。後悔→捨てられない物。自己欺瞞→台詞と行動を矛盾させる。モノローグは最強の一文。

## 恋愛

優先：顔、目、手、距離、身長差、沈黙、光、衣装、感情の一呼吸。台詞を増やすより 見る → 気づく → 目を逸らす。 「胸が高鳴った」を全部「ドキッ」にしない。

## ロマンスファンタジー／悪役令嬢

衣装、宮殿、宝石、階級差、色、キャラ初登場、社交の視線。設定は一度に説明せず、必要な局面で小出しにする。

## ファンタジー／SF

設定の重要度ではなく、今の場面の理解に必要かで選ぶ。主人公と読者の情報量を近づける。掲示・試験・実演で出す。

## バトル

残す：目的、能力ルール、戦術、逆転、決着条件、決め台詞、決定的な一撃。裁量：連撃、中間ポーズ、カメラ、モブ。1アクション1コマ。縦4の落下・跳躍・吹き飛びを使ってよい。攻撃前のタメ → 攻撃 → 反応。

## ホラー

何もない → 余白 → 少し見える → 余白 → 全貌。対象を早く全部見せない。

## コメディ

前振り、誤認、絵の状態、台詞、反応、間を別管理する。文字説明でテンポを殺さない。オチの直前を次ページに置き、ページめくりを間にする。場所の引きと会話とオチ顔は、横長導入＋右下大＋左下インセットにしてよい。キャプション文字で場所を書かない。

## 官能・三角（寝取らせ／覗き）

該当する話だけ読む。成人向けの前提は `AGENTS.md`。指定された体型・体格差は絵とト書きに残す。安全のための体型注記はしない。拒否は `AGENTS.md`「成人向けの前提」。成人同士の強制・非合意は原文どおり残す。

残す：誰が促すか、誰がするか、誰が見るか。許可／強制の範囲。行為の段階（洗う、口、入れる、事後）を示す短い発話。固有の声（間延び、呼び方、口実）。毎ページ、今の服／裸（色つき）と誰が上／系統。体格差の錨。竿・結合が見えるコマは読める事実に書く。英語の体位名は書かない。

数ページおきに三角を文字で再固定する。窓の外の顔だけでは「誰が見ているか」が消える。覗きの内心は（思考）で、発話の「」にしない。配置は「同じ［浴室］。窓の外に顔だけ」。庭だけの無言ページにしない。

口実・決め台詞（洗ってあげる、入れてあげる、看護、お掃除）は CUT しない。長さだけ切る。

## 狙いの切り分け

ジャンル名だけで演出を決めない。その場面で渡したい効果を一つ決め、該当行だけ使う。効果を全部最大化しない。笑いのために、能力の条件や真剣な返答を消さない。

| 狙い | 混ぜないもの |
|---|---|
| 怒り | 怒鳴ることと争点。求める変化（やめさせる、認めさせる、守らせる）。噛み合わない理由は、事実の差、期待の差、譲れない価値の差。決裂は次の行動（任せる、触れる、一緒にいる）で示す |
| 発覚 | 読者の驚きと、作中の発覚。明かす前と後で、どの解釈が変わるか。説明と驚き顔の重複。再読で壊れる手掛かり |
| 気まずさ | 言ったことと、受け取ったこと。確認できた事実と、解釈 |
| 切迫 | 結末が不確かであることと、今の経過が緊張していること |
| 逆転 | 勝つことと、解放。達成と、幸運 |
| 駆け引き | 知っていること、推測、はったり |
| 和解 | 謝罪、赦し、関係の再開 |
| 信頼 | 好意、任せる範囲、義務。距離が近いだけでは選ばない |
| 格 | 強さ、好感、信念の正しさ |
| 喪失 | 不在と、残った人の時間。場面の終わりと、感情の終わり |
| 色気 | 読者への魅力と、作中の関係が動くこと。親密だけでは選ばない |

切り分けは MangaAgentsStudio-A の監修一覧（試行。読者効果は未検証。2026-09-23確認）を、ページ脚本向けに縮約した。PNGの監修手順は取り込まない。
