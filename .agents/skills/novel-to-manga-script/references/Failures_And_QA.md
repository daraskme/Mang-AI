# 失敗と検査

検査は同じ作業内のチェックリスト。サブエージェントを立てない。* 付きは一つでもあれば未完成。症状表は ID への索引。採点ルーブリックは独立。

## 検査（正準）

### Story

- **Q-ST-01*** 犯人／伏線／能力ルールなど因果が壊れている
- **Q-ST-02*** キャラが原作と違う理由で動く
- **Q-ST-03*** 原作にない重大事件、新しい人物、新しい決め台詞を追加している（ヒキの最短思考を除く）
- **Q-ST-12*** 前文脈に無い観察可能事実を創作している（補完の範囲は [Principles.md](Principles.md)）
- **Q-ST-13*** 刺激のあと認識・選択の手がかりが無く、反応が唐突（[Beat_And_Panel.md](Beat_And_Panel.md)）
- **Q-ST-15*** 読者と人物の情報差が混線している（作者事情を読者既知にした、人物が知らないものを知っている顔で描いた）
- **Q-ST-16*** 時間が飛ぶページなのに、描く時点と、切替または戻りの手掛かりが無い（[Beat_And_Panel.md](Beat_And_Panel.md)）
- **Q-ST-17** 長い説明の前に、その理由を知りたくなる足場が無い。説明者の主張、観測できる結果、人物の仮説が一つの事実になっている
- **Q-ST-04*** 一話が説明だけで終わる
- **Q-ST-05*** 話末ヒキが無い
- **Q-ST-06*** 第1話で第1話ゲートが欠ける（主人公、欲望、問題、ジャンル約束、感情の種、次の問い）
- **Q-ST-07*** ヒキの前提を読者が知らない
- **Q-ST-08** 主人公の今の目的がある
- **Q-ST-09** 各話で状態が変わる。今回返す答えと持ち越す課題が分かれている
- **Q-ST-10** 伏線と「読者にまだ見せない情報」が分かれている
- **Q-ST-14** ページの目的が変化の動詞になっている（話題名だけになっていない）
- **Q-ST-11** 文言一致率を忠実度にしていない

### Visual

- **Q-VI-01*** 重要情報がページでは分からない（誰／どこ／何／なぜ。発話があるのに **発話** 欄が無い）
- **Q-VI-02*** 地の文がモノローグになっている
- **Q-VI-03*** 1コマに主要情報を複数詰めている
- **Q-VI-04*** 行為の核が顔だけのコマに逃げている
- **Q-VI-05*** 読める事実が身体・行為なのに、配置が全コマ顔だけ
- **Q-VI-06*** 行為があるコマに、その人の身体が無い
- **Q-VI-07*** 1コマに時間の違う2動作がある
- **Q-VI-21*** 動作が続いていても、期待が外れる／事情が分かる／方針が変わる瞬間が同一コマ
- **Q-VI-23*** 無言コマに、直前からの見える変化が無い
- **Q-VI-08*** 同一場面・同一体勢で、引きを挟まず左右または上下が逆転している
- **Q-VI-09** 会話が顔の切り返しだけになっていない
- **Q-VI-10** 見る人の次に、見られている対象がある
- **Q-VI-22** 受け止めが核なのに話し手の顔ばかりになっていない
- **Q-VI-11** 場面の最初で場所と位置が出ている
- **Q-VI-12** 全コマに詳細背景を要求していない
- **Q-VI-13** 必須情報が作画担当の見落としにくい位置にある
- **Q-VI-14** 読める事実が感情名だけで止まっていない（状態・視点・向き・視線の先・位置・体勢・衣装の色・手）
- **Q-VI-17*** `page_script` なのに今の服／裸が無い、色が無い、または同じ服の色がページで揺れる
- **Q-VI-18*** 騎乗・挿入なのに誰が上、または系統が無い
- **Q-VI-19** 竿・結合が見えるのに読める事実に無い
- **Q-VI-15** 向きが相手と合い、見るコマの次に対象がある
- **Q-VI-16** 初登場がページで分かる
- **Q-VI-20*** 再生の声と今の人物が同一コマ

### Page

- **Q-PG-01*** `page_script` なのに原作範囲・骨格名・読み順・各コマの絶対位置が無い
- **Q-PG-02*** 物語ページが1コマ、または5コマ以上
- **Q-PG-03*** 読み順が絶対位置と一致しない（相対語だけ）
- **Q-PG-04*** 核心（正体、オチ、答え、決めの絵・語）が、反応が始まる位置より先に同一ページで読めてしまわない
- **Q-PG-05*** 見せ場のコマが最大でない、または3〜4コマが等分

### Dialogue

- **Q-DI-01*** 決め台詞・促し・告白など、そのページの核の発話が落ちている
- **Q-DI-02*** 対象範囲の「」がいずれのページにも無い（長さの圧縮は可。本数は不可。発話割当の空行）
- **Q-DI-03*** 地の文が「」になっている
- **Q-DI-04*** 発話があるのに話者 → 相手 ／ 関係が無い
- **Q-DI-05*** ページと台詞が矛盾する（話者と宛先、表情）
- **Q-DI-06*** 物語ページで発話も思考も無い
- **Q-DI-07*** 体勢も位置も変わらない連続発話を、見せ場・体勢転換・話末ヒキを除き1発話1ページにしている
- **Q-DI-08** 1フキダシ3行以内。口調が残っている。切れ目は聞き手の理解変化
- **Q-DI-18** 短い返事に承諾／保留／拒否／探りの仕事がある
- **Q-DI-09** V5の引用上限を理由に発話を削っていない
- **Q-DI-10** 同一ページで発話と思考を混ぜていない
- **Q-DI-11** 体勢不変の連続発話は同一ページに2本以上（1コマあたり1〜2）
- **Q-DI-12*** 顔の無いコマに発話を置いている
- **Q-DI-13*** 無言コマの配置に話者なしが無い
- **Q-DI-14** 擬音が台詞コマにある、または1ページに2つ以上
- **Q-DI-15*** 観察の地の文（視線が止まる、手が止まる、匂い、肩）を命令の「」や内心にした
- **Q-DI-16*** 話者ラベルの無い「」を、直後の文と矛盾する相手へ割った
- **Q-DI-17*** 発話が `guidelines/02-narrative-craft.md` §4-10 と一致しない。状況・役割の説明、依頼の言い直し、行為者の取り違えがある。接続の形だけでは不合格にしない

### Production

- **Q-PR-01*** `page_script` にページ欄（原作・骨格名・読み順・配置）、出現、または発話割当が無い
- **Q-PR-02*** 隣接ページが同じ骨格名（カメラが違っても）
- **Q-PR-03*** 同じカメラ型が3ページ連続
- **Q-PR-08*** 骨格名がカタログ外
- **Q-PR-04*** 実現不能な矛盾指示
- **Q-PR-05*** 読める事実が原作範囲の観察（手・距離・光・髪・接触）を落とし、ラベルだけになっている
- **Q-PR-06** 顔寄りが1ページ1つ
- **Q-PR-07** 必須と裁量がある。全指先を縛っていない。戦闘を丸投げしていない
