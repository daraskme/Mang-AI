# 出力形式

## 1. 本文ファイル

- プレーンテキスト（`.txt`）
- **先頭の注意書き**＋小説本文＋挿絵マーカーのみ
- 見出し `#`、強調 `**`、水平線 `---`、箇条書き記号を出さない（区切りは `※※※` を使う）
- 三点リーダは `……`、ダッシュは `――`（偶数個）
- 空行は `guidelines/01-writing-rules.md` に従い、4行以上連続させない

## 2. 冒頭注意書き（必須・読者向け認識確認）

年齢確認・安全語・中断条件などの**認識合わせは物語の地の文や会話に埋め込まない**。ファイル先頭に、次の定型で置く。

```
※※※
この話はフィクションです。実在の人物・団体・事件とは関係ありません。
登場人物はすべて成人です。
※※※
```

規則：

1. 本文ファイルの**最初の行**から注意書きを始める（前置きの地の文を置かない）。
2. 開閉とも `※※※` のみの行とする（`---` はマークダウン水平線と誤検出されうるので使わない）。
3. 囲みの内側に最低限次を含める。
   - フィクションである旨
   - 実在の人物・団体と無関係である旨
   - 登場人物はすべて成人である旨
4. 注意書きに合意メタ（「このシーンは合意済みです」等）を足さない。年齢の数値列挙、作中に無い安全語・停止手順の説明は注意書きにも物語にも書かない。
5. 閉じの `※※※` のあと空行を1行置き、小説本文を始める。
6. PDF化（`illust-novel-pdf`）でもこのブロックを削除せず先頭に残す。

## 3. 物語本文に入れないもの

| 入れない | 代わり |
|---|---|
| 受付での年齢確認・成人証明の描写 | 注意書きの「すべて成人」 |
| 作中に無い安全語の説明・唱和・「アンバーで止める」等 | 画像と依頼の流れだけ書く。安全語は作品設定にあるときだけ |
| 作中に無い中断条件の読み上げ・契約条項の朗読 | 店の空気や関係の導入は物語として簡潔に |
| 読者向けメタ（「このシーンは合意済みです」） | 書かない。拒否・強制は描かれたとおり |

世界観として店が「大人向け」である程度の匂わせは可。手続きの実況や安全運用マニュアルの再現はしない。

## 4. 推奨パス

| 用途 | パス例 |
|---|---|
| リポジトリ内の短編 | `work/drafts/illust-r18-<slug>.txt` |
| 受け渡し | `user-provided/out/<slug>.txt` |
| 長編1話 | `work/drafts/episode<NNN>.txt`（長編は scene-card の R18境界が正本。注意書きは短編既定） |

`<slug>` は日付またはユーザー指定タイトルの安全な短縮名。

## 5. 本文の骨格例

```
※※※
この話はフィクションです。実在の人物・団体・事件とは関係ありません。
登場人物はすべて成人です。
※※※

（導入の地の文。場所・関係・欲求。年齢証明や安全語の説明は書かない）

［挿絵：01.png］

（この絵の状況に対応する地の文・会話）

［挿絵：02.png］

（行為の進行）

……

（事後と関係の変化。マーカー後にも余韻の本文）
```

## 6. 報告用メタ（本文ファイルの外）

チャットまたは別メモでよい項目：

- 採用／不採用一覧
- 体格差の扱い
- 設計上の成人根拠・許可／強制の範囲（内部確定の要約）
- 仮置き設定
- `validate-episode` 修正モードの結果（正本は同Skill。コマンド一覧はここへ再掲しない）

設計メモを本文 `.txt` に混在させない。

## 7. 検査

正本は `validate-episode`。単独短編は本文保存後に修正モードを必須とし、長編経路は `write-episode` が同Skillを呼ぶ。本ファイルはマーカーと注意書きの体裁だけを定める。

挿絵マーカー内のファイル名英字は `check.sh` の半角英単語警告の対象になりうる。意図的残置として裁定する。
