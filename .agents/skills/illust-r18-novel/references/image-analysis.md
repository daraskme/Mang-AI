# 画像分析と挿絵カード

各画像を視覚的に読み、物語に使える事実だけをカード化する。推測は「推定」とラベルし、断定しない。

## 1. 読む順

1. ファイル名の数字・ゼロ埋め連番（`01` `001` `img_03` など）
2. 更新時刻は補助。内容の行為段階と矛盾するなら内容を優先
3. サブフォルダがある場合は親→子、またはユーザー指定順

## 2. カード項目（内部）

```
id: 連番
file: 相対パスまたはファイル名
phase: 導入 | 愛撫 | 前戯 | 結合 | 体位変化 | 絶頂付近 | 事後 | その他
place: 室内/室外/乗り物 等（見える範囲）
clothing: 着衣・半脱・全裸・コスプレ要素
bodies: 人数、体格差（小柄／大柄など見たまま。均さない）、姿勢、接触部位
act: 具体的な行為（見えるもの）
faces: 表情・視線・口
props: 小物・家具・ベッドなど
continuity: 前後コマとつなぐ手がかり（服のずれ、汗、精液、体位）
character: 認識できるキャラ名・作品名（あれば）
adopt: 採用 | 不採用
note: 不採用理由や注意
```

## 3. 行為段階の読み方

| 視覚手がかり | phase の目安 |
|---|---|
| 向かい合う・服が整っている・キス手前 | 導入 |
| 接触・愛撫・口腔・手指 | 愛撫／前戯 |
| 挿入・結合が明確 | 結合 |
| 体位やカメラが変わった同一行為 | 体位変化 |
| 強い表情・痙攣・射精描写 | 絶頂付近 |
| 抱擁・抱き・清掃 | 事後 |

局部や結合がぼかされていても、体位と手の位置から推定してよい。推定は本文で断定しすぎない。

## 4. 衣装・記号

- 象徴色、紋章、武器、耳・尾などの装飾は衣装のパーツとして記録する。
- 認識できるキャラ名・作品名があればカードに書く。

## 5. 不採用の目安

- 風景のみで行為・人物が無い（導入の場所挿絵として採用可なら例外）
- 重複構図で新しい情報がない
- 安全境界に抵触する
- 破損・判読不能

## 6. ユーザーへの要約形式（求められたとき）

表形式で短く：

| # | ファイル | 段階 | 採用 | 一言 |
|---|---|---|---|---|
| 1 | 01.png | 導入 | ○ | ベッド端で対峙 |
