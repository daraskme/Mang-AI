# 挿絵の抜粋・順序・配置

## 1. 抜粋の方針

挿絵は「全部載せる」ではなく、**物語の山を支える枚**を残す。

残す優先度：

1. 状況が初めて分かる導入（場所・関係・衣装）
2. 行為段階が一段進む転換
3. 感情または主導権の変化が見える表情・体位
4. 絶頂付近と事後の回収

落としてよい：

- 同一体位の連写の中間
- 情報の増えないアングル差のみ
- 本文で言葉にした方が速い説明的カット

ユーザーが「全枚使用」と明示した場合は全採用し、間の橋渡し文量を調整する。

## 2. 順序

1. ファイル名の自然順（数値順）を初期仮説にする。
2. phase が逆行している（事後→結合など）場合は内容順に並べ替え、報告で理由を一文書く。
3. 同一phaseの連続は、接触の強さ・カメラの寄りで並べる。

## 3. 配置マーカー

本文中の挿絵位置は次の1行マーカーとする（マークダウン不可、半角装飾不可）。

```
［挿絵：01.png］
```

- フォルダが深い場合は、リポジトリまたは指定ルートからの相対パス：`［挿絵：user-provided/set-a/01.png］`
- マーカーの直後に空行を1行置き、地の文または会話を続ける
- マーカーだけの連続行を作らない（必ず前後に本文）
- 1枚の挿絵を本文中に二度出さない（回想で触れる場合はマーカーを再掲せず言葉で触れる）

## 4. 橋渡しビート

画像Aと画像Bのあいだで、服・体位・場所が飛ぶときは、**最小限の動作文**でつなぐ。

- やってよい：体位を変えるための数動作、場所の移動の一文、呼吸や視線のつなぎ
- やってはいけない：画像に無い新しい行為の追加、別相手の登場、設定破壊、年齢確認や安全語の説明シーンの挿入

## 5. 挿絵と描写の対応

- マーカー直下〜次マーカー直前の本文は、その挿絵の状況を主に描く
- 画像の体位・接触・表情を否定する描写をしない
- 画像に無い全身の詳細は、視点人物の知覚の範囲で補う
