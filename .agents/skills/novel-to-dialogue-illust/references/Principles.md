# 1枚絵の原則

原文の文章を保存しない。その瞬間に読者へ渡す効果を、絵とフキダシへ載せ替える。

対象は **コマ割りなしのフルカラー1枚** である。日本漫画のページ（2〜4コマ）ではない。無言の挿絵でもない。

## この形式

参照イメージ（依頼がフォルダや画像を示したとき）に共通する文法。既定の `artist:` にはしない。

- 人物が画面の大半を占める。行為の核が中央〜手前
- 背景は白または簡略。フキダシを置く空きが上左右に残る
- 話者（多くは行為を主導する側）の顔が見える。相手は全身でも、胴・手元・結合だけの切り取りでもよい
- フキダシは余白に置く。絵の顔や結合の上に重ねない
- 発話は今この行為をからかう、指示する、反応する一言。前情の説明やプロットは載せない
- 擬音の描き文字は作画裁量。発話欄に入れない（プロンプト側は日本語擬音を置かない）

場所が核（教室で見られている、など）のときだけ、必要な物を残して背景を足す。それ以外は簡略が既定。

## 動き

静止の記念写真にしない。行為がある1枚は、腰・手・髪・衣服・体液のどれかが**途中**である。着地し切ったポーズ、握って止まった手は失敗。1枚は1時点のままなので、構えと放出を同じ絵にしない。「途中」を凍結する。

## 行為＋射精差分

依頼が行為＋射精の2枚セットなら、軸（誰が上、画面右／左）は維持する。隣接1枚で体勢を変えよ、の例外。

射精差分は、行為1枚に精液を足した静止画ではない。原文のその瞬間から、次を変える。欠けたら未完成。

- 表情：目、口、頬、視線。行為の余裕・詰りが、射精時も同じ顔なら失敗。話者が原文で絶頂するなら顔を崩す。まだ余裕なら命令顔へ寄せ、絶頂顔にはしない。相手も文脈があれば射精顔・反りへ
- 動き：手の往復、腰の振り、髪、スカート、射精の飛沫が途中。止まって見せない
- 体液：飛んでいる途中、溢れる途中。手袋や結合に溜まった跡だけにしない

新しい体勢、新しい「」、軸の左右入れ替えは差分に使わない。

射精が原文・脚本に無い性的場面は1枚で止める。対にするために射精を足さない。

## 保存するもの／変えてよいもの

保存：その瞬間の関係、行為の系統、決め台詞の意味、原作にある外見、今の服、体格差、誰が上／右。

変更可：語順、発話の**長さ**、どの一言を残すか、相手の切り取り、場所の細部。前文脈からの観察可能事実の補完。

禁止：原作にない重大事件、新しい人物、新しい決め台詞、キャラ人格の変更、コマ割り、1枚に2時点。

## 漫画ページとの差

| | 本形式 | 漫画ページ |
|---|---|---|
| 単位 | 1生成＝1枚＝1時点 | 1生成＝1ページ＝2〜4コマ |
| 発話 | 1枚に1〜2。核だけ残す | 本数は残し、長さだけ切る |
| 背景 | 簡略が既定 | 場面の最初の引きで場所を出す |
| 相手 | 切り取り可 | コマの仕事で全身／顔を分ける |

連続する会話を全部載せたい、手順を3拍で見せたい、ヒキを次コマに残したい、は漫画側。本Skillへ流さない。

## 文脈からの補完

その一文が、1枚に必要な観察可能事実を言っていないときは、**同一場面の前文脈**から足してよい。空欄のまま後工程に推測させない。前文脈に無い事実は作らない。

足してよい：今の服／裸と色、場所の簡略、誰がいる／写さない、体勢の軸、体格差の錨、行為の系統、竿・結合が見えるか、手の位置、原文にある表情と動きの途中。

足さない：新しい出来事、新しい「」、地の文の心理を発話へコピーすること。

## 小説の要素 → 1枚の第一候補

| 小説 | 第一候補 |
|---|---|
| 行為の転換（触れる、挿入、射精） | その時点の全身／腰上＋核の手元 |
| からかい・指示・反応の「」 | フキダシ。長さだけ切る |
| 表情・見下ろし・見られ羞恥 | 顔を残す。カメラは誰の目か |
| 体格差 | 頭頂の錨を読める事実へ。均さない |
| 長い独白 | 最も強い1文だけ。残りはDEFER |
| 擬音の地の文 | 作画裁量。発話にしない |
| 前情・移動・設定 | CUT または DEFER |

## 発話の選び方

原作の「」は発話である。フキダシにする。地の文を「」にしない。内心は思考フキダシだが、同一1枚で発話と混ぜない。既定は発話。

1枚に残すのは、絵を見ながら意味が通る1〜2である。優先：

1. 決め台詞、促し、詰り、今の行為へのコメント
2. 話者の声（語尾・呼び方・間延び）が残る短い文
3. 関係が絵だけだと崩れるとき（誰が主導か）

落とす：前情の要約、知っている同士の設定説明、次の行為の予告、同じ意味の繰り返し、依頼の体位名や役割の実況。

字数の正本は `nai-v5-prompt-designer` の R-TXT-08（目安8〜24字、最大40字前後）。本Skillは切って収める。語尾は残す。ビートを1つにまとめて核の発話を消すのは禁止。誰に何を言うかは `guidelines/02-narrative-craft.md` §4-10。状況の説明と依頼の言い直しは採用しない。切ったあと行為者が入れ替わっていたら、その切れ方も採用しない。「ながら」「たまま」「て」は形だけでは落とさない。

各発話に次を書く。欠けたら未完成。

- 話者（誰が言うか）
- 相手（誰に向かって言うか。独白なら「自分」）
- 関係（からかう、指示する、観念する、など今の力関係）

## 視覚優先

```text
絵だけで確実に読める
  → 行動・表情・手・距離
  → 短い台詞（1〜2）
  → 思考は発話と混ぜないときだけ
今不要な設定 → DEFER
```

NAI など絵が崩れうる経路なら、関係・促しは文字を第一の読み取りにする。絵と台詞が同じ事実を短く重ねてよい。

## 作画との境界

原作が持つ：凍結する時点、誰がいる、今の服、行為の系統、体格差、残す発話、余白の方角。

裁量：指先、髪のなびき、汗の量、擬音の描き文字、ハートなどの装飾。ロック文とピン座標はプロンプト側。
