# 1枚絵受け渡し契約

`contract: illust-handoff-v2`

1枚絵ブリーフの欄の正本。ロック文とピンの x,y は書かない。1生成＝コマ割りなしの1枚。縦スクロールWEBTOON連作の画像化はしない。

相互にファイルパスで参照しない。本ファイルを改めたら `contract` の版を上げ、参照側の版と揃える。

## 所有

脚本が書く：この1枚の仕事、凍結する時点、誰がどこにいるか、余白の方角、今の服／裸、誰の目か、視線の先、各人の右／左または上／下、行為の系統（日本語）、竿・結合が見えるか、動きの途中、表情、射精差分なら行為1枚からの差、話者、発話1〜2、色（必要なとき）。

脚本が書かない：ロック文、ピンの x,y、英語タグ、フキダシのしっぽ位置、Text mode、Artist、Quality Tags、`2koma` / `manga`。擬音の日本語本文。

## 1枚の欄（欠けたら未完成）

```markdown
### イラスト1
**目的:** 跨ぎながら、出し方を指示する
**凍結:** 女が男の上に跨ぎ、腰を落としている途中。1時点。
**場所:** 白地。ベッドの端だけ。
**配置:**
- 女は画面右、腰上、こちらを見る。話者。
- 男は画面左下、胸から下。顔は出さない。話者なし。
**余白:** 右上と左上
**動き:** 腰は止めていない。足が竿を挟んで小さく動く途中。銀髪が肩に落ちる。
**表情:** 女は目を細めて余裕の笑み。口は半開き。男は顔を赤くして喘ぐ。
**読める事実:**
- 今の服: 女は紺のトップスと白スカート。男は下半身裸。
- 体格差: 女の頭頂は跨いでも画面上。均さない。
- 系統は跨ぎ。女が上。竿が見える。
- 視点は客観。女は男を見下ろす。
- 女は右手を男の腹へ。
**出現:**
- 女（腰上）
- 男（下半身。顔なし）
**発話:** 女 → 男 ／ 指示する
女「まだ出したらだめ」
**発話:** 女 → 男 ／ 追い打ち
女「顔に足す？　それとも中？」
```

連作では `## 外見固定` を1つ。髪目、服の色、体格差の錨。ページ表は置かない。

## 発話行

```markdown
**発話:** 話者 → 相手 ／ 関係
話者「セリフ」
```

- 区切りは全角 `→` と全角 `／`（U+FF0F）。
- 行：`^\*\*発話:\*\*\s*(.+?)\s*→\s*(.+?)\s*／\s*(.+)\s*$`
- 直後：`^(.+)「([^」]*)」\s*$`
- 内心：`^\*\*内心:\*\*\s*(.+?)` のあと（思考）。脚本の思考は「」にしない（プロンプト側がくも形と「」にする）。
- 同一1枚で発話と思考を混ぜない。既定は発話。1枚の発話は1〜2。

字数はプロンプト側 R-TXT-08 に収まる長さへ、ここで切る。

## 配置の型（仕事で選ぶ）

| この1枚の仕事 | 配置 |
|---|---|
| 女が行為しながら話す | 女は中央〜右、腰上〜全身。相手は左または手前に切り取り。余白は上左右 |
| 女が跨いで見下ろす | 女は上、男は下。余白は上左右 |
| 顔と手元が核 | 女は寄り〜腰上。手元は画面下。余白は左右上 |
| 相手の反応も顔で要る | 二人とも顔を出す。左右を固定。余白は上 |

絶対位置の書き方：画面右／左、上／下、腰上／全身／寄り／下半身。相対語「隣」「奥」だけで終わらせない。ピンも数字も書かない。

インセット（結合の寄りを隅に足す）は、その寄りが発話の意味に必須なときだけ。コマ割り漫画にしない。二重の出し方はプロンプト側の `multiple views`（単一イラストに限る）。

## 余白

各1枚にフキダシ用の空きを1つ以上書く。人物と背景で画面を埋めない。顔・結合・手元の上を余白に指定しない。

## 読める事実

観察可能な次を書く。その文が原作に無くても前文脈から補う（[Principles.md](Principles.md)）。抽象（エロい、怒っている）で止めない。英語タグは書かない。人物は名前で繰り返す。

- 今の服／裸。色名を含める。空にしない
- 場所。簡略が既定。室内と屋外を混ぜない
- 行為があれば系統（跨ぎ／後ろから／手）と誰が上
- 竿・結合が見えるときだけ、見えると書く
- 体格差があれば錨（頭頂は誰のどこ）。均さない。ちびで代用しない
- 視点（客観／肩越し／主観／カメラ目線。カメラ目線は見せ場だけ）
- 向き、視線の先、手の位置

## 動き・表情・差分

行為がある1枚は次を欄として書く。欠けたら未完成。定義は [Principles.md](Principles.md)。

```markdown
**動き:** 黒手袋が上下の途中。ツインテールが肩で揺れる。腰は止まっていない。
**表情:** 女は目を細めてニヤリ。男は口を開けて喘ぐ。
```

- **動き:** 腰・手・髪・衣服・体液のどれが途中か。着地し切ったポーズ、握って止まった手は不可
- **表情:** 目、口、頬、視線。感情名（エロい、怒っている）で止めない

行為＋射精の2枚目は **差分** を足す。精液だけ書いて表情と動きが行為1枚と同じなら未完成。

```markdown
**差分:** 余裕の笑みが命令顔へ。キスの唾液の糸。精液が手袋へ噴く途中。男の腰が反る。
```

## 出現

画角は全身／腰上／顔／下半身。顔を出さない相手は「顔なし」と書く。脚だけ・手元だけの端役は出現に書かない（読める事実に残す）。

```markdown
**出現:**
- 女（腰上）
- 男（下半身。顔なし）
```

## 配置で書くこと

- 誰がいるか。誰を写さないか。各人の画面右／左、または上／下
- 見える動作（読める事実）
- 話者の顔があること。**発話** 欄の話者と一致させる。顔の無い切り取りに発話を置かない。無言の相手は「話者なし」
- 行為があるなら、その人の**身体**を置く。顔だけの1枚に行為を逃がさない
- 手前に肩・物を入れるときは書く
