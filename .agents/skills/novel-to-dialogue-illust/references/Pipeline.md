# 解析から1枚まで

小説をいきなりブリーフにしない。構造 → 凍結点 → 再配分 → 1枚。

## ターゲット

```text
format: dialogue_illust
fidelity: strict | balanced | bold
```

枚数はユーザー指定があるときだけ使う。未指定は対象範囲の核を1枚。1話を網羅する枚数へ換算しない。

## 構造（まだ書かない）

抜くもの：誰がいる、関係、今の目的、行為の段階、決め台詞、原作にある外見、確定した服・色・場所・軸。

## 凍結点

候補は、状態が変わる1拍。触れる、体勢が変わる、射精する、台詞の意味が絵に乗る、など。同じ体勢の連続発話は1候補にまとめる。

各候補に内部で持ってよい。出力にYAMLを常時出さない。

```text
beat_id / source_span
visual_anchor（誰が何をしている1時点）
dialogue_candidates（長さは切ってよい。話者・相手・関係）
must_preserve / cut_candidate
```

採用：絵が区別できる、かつ残す発話がある。両方無い拍は DEFER。ユーザーが箇所を指定していればそれを核にする。

複数枚のとき、隣接する1枚は体勢かカメラを変える。同じ跨ぎのまま台詞だけ変えて枚数を稼がない。例外：依頼の行為＋射精差分。軸は維持し、表情・動き・体液を原文どおり変える（[Principles.md](Principles.md)）。精液だけ足して同じ顔・同じ止まりにしない。

## 再配分

VISUAL / ACTION / EXPRESSION / PROP / DIALOGUE / MONOLOGUE / SFX / CUT / DEFER。主搬送を一つ決める。1枚の発話スロットは1〜2。溢れた DIALOGUE は次の1枚か DEFER。SFX は作画裁量へ。MONOLOGUE は発話が空のときだけ、思考として1つ。

## 1枚が読めるか

出す直前に次が残っているか見る。欠けたら未完成。

- 誰がいるか。写さない人
- 1時点の何をしているか
- なぜ今それが起きるか（発話の関係で足りる）
- 話者の顔が見えるか
- フキダシ余白の方角
- 発話1〜2と話者 → 相手 ／ 関係
- 読める事実（今の服と色、系統、軸、体格差の錨、竿・結合が見えるか、動きの途中、表情）
- 射精差分なら、行為1枚からの差（表情・動き・体液。精液だけではない）

保存したあと、確認ゲート（SKILL.md）で止める。

## 変換ログ（内部）

大胆に動かしたら残す。利用者へは求められたとき、または因果に触れたとき。

```text
source / action（defer|merge|cut|visualized|added_from_context） / reason / preserved_information
```
