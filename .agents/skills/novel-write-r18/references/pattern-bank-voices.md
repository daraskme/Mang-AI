系統の正本は `pattern-bank-buildup.md` 冒頭。A系の声の実作は style-corpus の STYLE-NOTES §4。B系は style-corpus-b の STYLE-NOTES §4。本ファイルは6タイプの段階表と特殊レイヤー。固有表現は流用しない。

## 11. キャラタイプ別voice card（6タイプ）

崩壊の設計はこの6タイプから1つ選んで貫く。フェーズの進行に迷ったらここへ戻る。

### 11-A. 高慢令嬢型「ですわ」体

| Phase | 状態 | 型 |
|---|---|---|
| 1 | フル装備 | 「お味も、なかなか……♡」 |
| 2 | 語尾維持＋♡ | 「すぐに反応してしまいますのね」 |
| 3 | 母音伸長混入 | 「ぜんぶぅ……ちょうだいぃ♡♡」 |
| 4 | 濁点崩壊 | 「ん゛んんっ♡♡　すごぉい……っ♡」 |
| 5 | 復活・甘え | 「まだ、足りませんわ」 |

ポイント：フェーズ4でも自称（わたくし）を捨てない。フェーズ5は♡を消して濃密な甘えに着地。

### 11-B. 天真爛漫型・カジュアル

| Phase | 状態 | 型 |
|---|---|---|
| 1 | 余裕・軽口 | 「今日もおつかれさま♡」 |
| 2 | 軽口＋♡ | 「はっやーい♡」 |
| 3 | 抗議＋崩れ | 「ちょっ……ちょっと、もうイッたから……っ！」 |
| 4 | 濁音化 | 「お゛、あ゛っ、あぁぁ゛ぁっっ♡♡♡」 |
| 5 | 子供っぽい甘え | 「もぉ……いきなり、すごすぎぃ……♡」 |

ポイント：フェーズ4で一人称が抜け落ちる。事後は軽口へ戻る。

### 11-C. 内気型・単音節

| Phase | 状態 | 型 |
|---|---|---|
| 1 | 単音節 | 「……あったかい」 |
| 2 | 喘ぎ断片 | 「ひゃっ……く、ふっ……」 |
| 3 | 戸惑い疑問形 | 「……これで、いいの……？」 |
| 4 | 全崩壊 | 「やぁぁんっ♡　イっちゃう、イっちゃうっ♡♡♡」 |
| 5 | ぼそぼそ甘え | 「……うふふ……美味しい、かも……」 |

ポイント：フェーズ1はほぼ単語1〜2文字。フェーズ4で一気に崩す落差が命。事後は「最低・でも許す」式の照れ隠しに収束させると安定する。

### 11-D. クール／敬語型「〜です」断定

| Phase | 状態 | 型 |
|---|---|---|
| 1 | 職務口調 | 「失礼します。必要なことなので」 |
| 2 | 敬語＋甘え萌芽 | 「気持ち良く、なって……ください……」 |
| 3 | 敬語ゆらぎ | 「もっと強くしていいですよ……んっ……強く……して」 |
| 4 | 独立叫び型崩壊 | 「お゛ぉッ♡♡♡　欲しい♡」 |
| 5 | 敬語復活・短句甘え | 「……気持ちよかったです」 |

ポイント：敬語の骨格を保ったまま内容だけが従属・献身に振り切れる崩し方も選択肢になる（敬語を必ず崩す必要はない）。

### 11-E. お姉さん主導型・包摂

| Phase | 状態 | 型 |
|---|---|---|
| 1 | 包む宣言 | 「大丈夫よ……今日は私が全部リードするから」 |
| 2 | 合理化口実 | 「これは……実験だから」 |
| 3 | 主導しつつ崩れ | 「ふふ、ほら……可愛い……♡♡」 |
| 4 | 包み込みつつ濁点 | 「んあぁっ♡♡♡　奥に、当たってる……♡♡」 |
| 5 | 世話焼き回復 | 「ふふ……全部綺麗にしてあげる……♡」 |

ポイント：フェーズ1〜5で主導の芯（「私が」）を維持する。フェーズ4で受けに回っても包む側の口調が崩れない。

### 11-F. 嫌悪反転型

| Phase | 状態 | 型 |
|---|---|---|
| 1 | 建前の拒絶語彙 | 「近づかないで……どういうこと？」 |
| 2 | 動揺・身体の裏切り | 「なんで……身体が勝手に……」 |
| 3 | 拒絶＋♡同時並行 | 「こんなの、嫌なのに……どうして、熱い……♡」 |
| 4 | 拒絶語彙消失 | 「お゛ッ♡　い゛い゛ッ♡　もっと♡♡♡」 |
| 5 | 依存・所有 | 「……好き♡　もう逃がしませんからっ♡」 |

ポイント：フェーズ3で拒絶語彙と♡を同じ台詞内に混在させるのが核。フェーズ4で拒絶語彙が消える瞬間を意識的に演出する。拒絶は建前でも本気でもよい。実は合意だったと読み替えない（`safety-and-inputs.md` §2）。

### 11-G. 視点人物（攻める側／受ける側）の声

**攻める側**：

| 種別 | 型 | 備考 |
|---|---|---|
| 喘ぎ短句 | 「っ……く、あ……っ」 | 句読点・三点リーダで途切れさせる。低く短く、台詞量を絞る |
| 嘆き内心 | 「（これは……死ぬ）」 | 括弧書きで地の文と分離 |
| 宣言 | 「……出す。中に、出すぞ」 | 短句・終止形 |
| 名前呼び | 「○○……っ」 | ♡を付けない |

**受ける側**：

| 種別 | 型 | 備考 |
|---|---|---|
| 抵抗台詞 | 「だ、だから……っ、これ、絶対おかしいって……！」 | 文末の三点リーダ＋促音 |
| 罪悪感 | 括弧書き内省「（本当に、俺は最低だ）」 | 自責を行為と並走させる |
| 喘ぎ短句 | 「だめ、出――っ！」 | ダッシュで途切れさせる |
| 反転後 | 「……全部、受け止めて」 | 名前呼び＋指示形。♡は付けない |

## 12. 特殊レイヤー固有パターン

### 12-A. 衣装・着衣プレイ

- 衣装は脱がせきらず、ずらし・部分的露出で行為を継続することが多い。
- **衣装が汚れていく経過**を毎ビート確認する：「白い長手袋が、水面のようにすべる」「白いものが、黒い布地を汚す」「肉と布と液の三重の感触」。
- 布越しの摩擦音（「ぬちゅっ……くちゅっ……」）、無摩擦の異化（「サテンが滑り、摩擦がないのに確実に刺激が伝わる」）を素材ごとに言及する。
- 使う衣装は依頼・画像・設定どおり。学校制服は成人のコスプレとして書いてよい。通学・放課後などの子供のシチュへ接続しない（`safety-and-inputs.md` §1）。

### 12-B. 体格差・包摂

- 体格差は数値または動作で具体化する（「頭ひとつ分の差」「片腕で抱え上げられる」）。指定された小柄・大柄を残す。平均へ均さない。年齢は書かない。
- 包摂動作の連鎖（抱き上げる→胸に埋もれる→腕・脚で固定）と、耳元の囁きを演出として頻用する。
- 深度言及（「最奥に届く」）は体格差の物理的合理性とセットで書く。
- **縮小プレイ**（依頼または scene-card にあるとき）：身体は成人のまま小さくなる。服が余る、抱き上げられる、スカートの内側に隠れる、太腿で腰を固定できる。性器の機能は成人のまま。子供の顔・声・赤ちゃん扱いにしない。A系の実例は [066](style-corpus/extracted/066.txt)–[068](style-corpus/extracted/068.txt)。

### 12-C. 寝取り・見せつけ（第三者同席）

- 第三者の絶望表情を視覚で挟む。
- 受け手が第三者を睨みながら（または見せつけながら）行為を継続する。
- 比較台詞で反転を確定する（§7-C）。
- 罪悪感は視点人物の括弧書き内省で表現する。
- 第三者を含む全員が成人で、場面の枠組み（関係設計）はscene-cardが所有する。B系の実例は [15.txt](style-corpus-b/extracted/15.txt)。
