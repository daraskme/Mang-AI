# オノマトペ・喘ぎセリフ運用規範

R18本文の擬音・喘ぎを書く段階で読む。配置の考え方は各モードのreference、構造実例は pattern-bank 三分冊の該当分冊を併読する。

基本原則：

- オノマトペは地の文の動作描写と必ず連動させる。記号の羅列にしない。
- ♡の配置：A系は [STYLE-NOTES §3](style-corpus/STYLE-NOTES.md)（頂点の擬音独立行へ♡可）。B系は受け側の台詞内のみで、地の文の擬音行には付けない。
- 繰り返しでリズムと持続感を作り、同じ音の過剰反復は同系統の別の音で変化をつける。
- 音の種類と強度はシーンの進行（フェーズ1→5）と同期させる。

## 1. 擬音の4つの配置パターン

### A. 独立強調行（ビートの頂点）

擬音だけを単独行に置き、前後を空行で挟む。句点か感嘆符で締める。

```
ぢゅぽっ。

びゅるっ……びゅっ、びゅるるっ……！

どぷっ！どぷどぷっ！びゅるるるるるっ！！
```

### B. 散文織り込み型（導入・緩急）

擬音を文頭または文中に置き、後続の感覚描写へ滑らかに接続する。

```
ぬるりとした熱が、布越しに先端を包んだ。
ぴとっ……ぬるりとした感触と、くすぐったさが同時に押し寄せる。
```

### C. リズム連鎖型（持続・反復）

同系統の音を2〜3連で配置し、持続感を作る。

```
ちろ……ちろ……ぬるっ……。
くちゅくちゅ、じゅぷ、じゅぷ、じゅぷっ……！
```

### D. 衝撃音型（突入・絶頂）

ダッシュか感嘆符で終止。同音リフレインで衝撃を刻む。

```
ずんっ、ずんっ、ずんっ――！
びゅぐぅううぅッッ！
```

強い噴出感を出す系統では、カタカナ＋濁点＋長音＋連続感嘆符の合成（「びゅぐぅううぅッッ！」）で歪曲・噴出感を増幅できる。抑制的な系統では平仮名と促音中心に留める。1シーン内でどちらの傾向かを揃える。

## 2. 行為別オノマトペ語彙

### 口腔奉仕

| 強度 | パターン |
|---|---|
| 弱（舐め始め） | ぴとっ／ちろ／ぬるり／れろっ |
| 中（咥え込み） | ちゅぷ／じゅる／じゅるるっ／くちゅ |
| 強（深咥え・吸引） | ぢゅぽっ／ぢゅるるっ／じゅぽじゅぽ |
| 喉奥 | んぐっ／じゅぽっ／じゅるるるるるるるっ |

濁点（ぢ）と長音（るるる）を少しずつ増やすことで強度上昇を視覚化する。

### 挿入・律動

| 強度 | パターン |
|---|---|
| 弱（挿入開始） | ぬちゅっ／ぬぷ／ずぷっ／ぬりゅっ |
| 中（律動） | ぬちゅっ、ぬちゅっ／くちゅっ、ぱちゅっ／ずちゅっ |
| 強（激しい律動） | ぱんっ、ぱんっ／ずんっ、ずんっ／ぐちゅっ、ぬちゅっ |
| 深奥突き | ずんっずんっ／ぐじゅぼッ／ぬちゃぬちゃぬちゃっ |

挿入の瞬間の擬音は独立行にせず散文織り込みにして、受け手の台詞や反応で時間を伸ばす。

### 愛撫・キス

| 強度 | パターン |
|---|---|
| 弱（軽い接触） | ぴと／ちゅっ／ぬる |
| 中（舐め・吸い） | ちゅぷっ／れろっ／ぬちゅ／くちゅ |
| 強（濃厚） | じゅるっ／ぬちゅぅっ／ちゅぱ／れろれろ |

### 射精

| 段階 | パターン |
|---|---|
| 予兆 | どくん／ぴくっ／びくぅっ／びくびくんっ |
| 本体（抑制系） | びゅるっ／びゅっ／びゅるるっ |
| 本体（噴出系） | どぷっ！どぷどぷっ！／びゅるるるるるっ！！／びゅぐぅううぅッッ！ |
| 持続 | どくっ、どくどくどくっ |
| 着弾後 | とぷとぷ／ごくっ（飲み込み）／ずるり（溢れ） |

### 身体反応・その他

```
きゅぅぅっ（収縮）／ぎゅん（驚き締め）／ぬちゃぬちゃ（愛液）
ひくひく（痙攣）／びくんっ、びくんっ（絶頂痙攣）
むにゅ／ぷにゅ／たぷん（胸）／ぐにゅっ（揉み）／くにゅっ（乳首）／ぷるんっ（解放）
くちゅ……くちゅ……（緩い手淫）／じゅぷじゅぷじゅぷっ！（速度上昇）
ぱちゅん、ぱちゅん（乳房の上下）／じじぃぃ……（ファスナー）／びりりりりっ！（布を裂く）
```

## 3. ♡エスカレーション5段階

♡を使う作品でのみ適用する。フェーズを飛び級しない。

| フェーズ | 進行 | ♡の使い方 | 台詞の型 |
|---|---|---|---|
| 1 導入 | 余裕・挑発 | なし〜文末1個 | 語尾が完全に保たれた挑発・世話焼き |
| 2 展開 | 快感の自覚 | 句末に♡1個 | 「敏感なのね……♡」実況・軽口 |
| 3 高潮 | 制御の揺らぎ | ♡♡二連 | 母音伸長混入。「だめぇ……そんなに、されたら♡♡」 |
| 4 絶頂 | 理性崩壊 | ♡♡♡三連＋濁点 | 「ん゛んんっ♡♡♡」。語彙が音に近づく |
| 5 余韻 | 蕩け・甘え | ♡1個に戻すか無し | 余韻台詞で着地。「まだ、足りませんわ」 |

配置の基本ルール：

- A系の♡は STYLE-NOTES §3。B系は**受け側の台詞内のみ**（攻める側と地の文の擬音行には付けない。例外は攻める側が甘い口調のキャラのフェーズ5で1個まで）。
- **濁点（゛）はフェーズ4限定**。「ん゛」「あ゛」「お゛」の子音単体から、「お゛な゛か゛」のような音節単位まで深さの段階がある。フェーズ1〜3で使うと絶頂のインパクトが薄れる。
- ♡♡♡の三連は絶頂瞬間のみ。連打しない。
- フェーズ5は♡を1個に戻すか、無しにして余韻台詞で着地する。
- ♡（白ハート）は愛らしさ・清らかさ、♥（黒ハート）は直情・俗っぽさの質感を持つ。キャラ設計で選び、1シーン・1キャラ内では統一する。

### 「！？」×♡の複合技法（困惑と快感の同時表現）

「！」（衝撃）と「？」（困惑）を重ねた「！？」に♡を組み合わせると、「望んでいない／驚いている／でも感じている」という三重の感情を、地の文の解説なしで記号列だけで伝えられる。

```
「んっ……！？♡」

「あっ、あぁっ……！？♡　ちょ、ちょっ、なにして……！？♡」
```

- 文中に割り込ませると、言い切ろうとした言葉を身体の反応が遮る様子を表現できる。
- フェーズ1〜2は単発「！？」＋♡1個に留め、フェーズ3以降で「！？！？」＋♡♡♡の強調形を解禁する。
- 受け側の台詞専用（困惑は快感に振り回される側の特権的表現）。
- 多用すると効果が均一化する。「！？」なしの落ち着いた台詞と交互に配置して緩急を作る。
- 拒絶語彙と組み合わせると、「なぜこんな言葉を口にしながら身体は悦んでいるのか」という当人の困惑まで一台詞で表現できる。拒絶は建前でも本気でもよく、実は合意だったと読み替えない（`safety-and-inputs.md` §2）。

## 4. セリフと擬音の融合

台詞の中に擬音を溶かし込む：

```
「んっ♡……じゅる、ぢゅるるっ……♡」
```

快感で言葉が音に崩れていく過程を描く：

```
「もっと♡　もっ、ろ……♡♡」
```

地の文で擬音を挟み、直後に台詞を置くと残響が重なる：

```
　ぢゅぽっ、ぢゅぽっ、じゅるるるっ……

「ふぅ……♡　少し、我慢が……足りませんわね」
```

## 5. 行末記号の使い分け

| 記号 | 使用場面 |
|---|---|
| 。 | 静的な擬音・終止（「ごくっ。」「ぱくり。」） |
| …… | 連鎖・余韻・息切れ |
| っ | 衝撃音の語尾（「ぱんっ」「ずんっ」） |
| ！ | 強い衝撃・破裂 |
| ！！ | 噴出・絶頂（噴出系で多用） |
| ―― | 連続・加速・劇的休止（「ずんっ、ずんっ、ずんっ――！」） |
| 〜／～ | 持続・甘え・長母音 |
| ッッ | カタカナ促音重ね（噴出感の増幅） |

- ダッシュは必ず「――」（U+2015偶数個）。「——」「──」「ーー」を使わない。
- 同じ行に句点と感嘆符を混ぜない（「。！」としない）。
- 三点リーダは「……」偶数個。閉じカギ直前に句読点を置かない。
