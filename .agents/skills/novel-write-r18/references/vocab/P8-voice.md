# P8. 声の表現（地の文の名詞）

**直接表現**: 喘ぎ声（1-2）、声（1-2）

※このカテゴリーは**地の文で声を指す名詞表現**のみを扱う。喘ぎの音声（「あっ」「ん゛」等）と崩壊は `novel-write-r18` の onomatopoeia を正本とする。

## コア語彙（声の名詞）

| 言い換え | レベル | ニュアンス |
|---|---|---|
| 嬌声（きょうせい） | 1-2 | 甘く高い声 |
| 啼き声 | 1-2 | 鳴くような声 |
| 鳴き声 | 1-2 | 成人の甘い声の比喩。児童連想には使わない |
| 吐息 | 1-2 | 息の表現 |
| 息継ぎ | 1-2 | 途切れる呼吸 |
| 嗚咽 | 1-2 | 咽び泣く声（咽び泣き（むせびなき）とも） |
| 咽び泣き（むせびなき） | 1-2 | 嗚咽の和語 |
| うめき | 2-3 | 低い呻き |
| 呻き | 2-3 | 苦悶の声 |
| 喘鳴（ぜんめい） | 2-3 | 苦しげな呼吸音 |
| 絶叫 | 2-3 | 叫び声 |
| 嬌音 | 2-3 | 色っぽい声・響き |

## 対応修飾語（声・響きを修飾する表現）

| 修飾語 | レベル | ニュアンス |
|---|---|---|
| 甘く掠れた | 1-2 | 甘いかすれ声 |
| 甘く溶けるような | 1-2 | 甘美な声 |
| 切ない | 1-2 | 哀願するような |
| 鼻にかかった | 1-2 | 甘ったるい |
| 艶やかな | 1-2 | 色っぽい響き |
| 裏返った | 2-3 | 高くひっくり返る |
| 掠れた | 2-3 | かすれた |
| 喉を震わせる | 2-3 | 震える声 |
| 抑えきれない | 2-3 | 我慢できない |
| 高く跳ねる | 2-3 | 跳ね上がる声 |
| 低く漏れる | 2-3 | 低く抑えた声 |
| 理性を失った | 3-4 | 狂乱の声 |

## 文例
- 「抑えきれない|嬌声《きょうせい》が、甘く部屋に漏れた」
- 「掠れた吐息が、彼の耳元で切なく震えた」
