# P11. 体液摂取

**直接表現**: 飲む（1-2）、舐める（1-2）

## コア語彙

| 言い換え | レベル | ニュアンス |
|---|---|---|
| 啜り上げる | 2-3 | 音を立てて吸う |
| 喉を鳴らして飲む | 3-4 | 夢中で飲む |
| 喉奥で受け止める | 3-4 | 深く飲み込む |
| 飲み干す | 2-3 | 全て飲む |
| 残らず啜る（すする） | 3-4 | 一滴残さず |
| 最後の雫まで舐め取る | 3-4 | 完全に舐め取る |
| 啜る（すする）ように飲む | 3-4 | 音を立てて飲む |

## 対応修飾語

| 修飾語 | レベル | ニュアンス |
|---|---|---|
| 貪欲に | 2-3 | 積極的 |
| だらしなく | 3-4 | 淫らに |
| 音を立てて | 2-3 | 吸引音 |
| 喉を鳴らして | 3-4 | 飲む音 |
| 口いっぱいに | 2-3 | 満口での飲み込み |

## 文例
- 「彼女は彼の|精《せい》を、喉を鳴らして飲み干した」
- 「残らず|啜《すす》り上げて、舌で唇を舐めた」
