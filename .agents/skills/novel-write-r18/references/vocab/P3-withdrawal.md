# P3. 引き抜く・離れる動作

**直接表現**: 抜く（1-2）、抜ける（1-2）、引き抜く（1-3）

## コア語彙

| 言い換え | レベル | ニュアンス |
|---|---|---|
| 抜き去る | 2-3 | 完全に抜く |
| 滑り出る | 1-2 | 自然に抜ける |
| 引き離す | 1-2 | 焦らすように |
| 離れる | 1-2 | 余韻を残して |
| 抜け出す | 2-3 | 濡れた状態で |

## 対応修飾語

| 修飾語 | レベル | ニュアンス |
|---|---|---|
| ゆっくりと | 1-2 | 焦らすように |
| 名残惜しげに | 1-2 | 余韻を残して |
| ずるりと | 2-3 | 摩擦を伴って |
| 惜しむように | 2-3 | 焦らし |
| ぬるりと | 2-3 | 濡れた感触 |
| 乱暴に | 3-4 | 無造作な引き抜き |
| 名残を残すように | 1-2 | 焦らし・余韻 |
| ぬるりと音を立てて | 2-3 | 濡れた感触の強調 |
| 締め付けに抗うように | 2-3 | 膣圧との抵抗感 |
| 一気に | 3-4 | 急激な離脱 |
| 精液を引きずるように | 3-4 | 中出し後の引き抜き |
| ねじるように | 3-4 | 捻りながらの抜去 |

## 文例
- 「名残惜しげにずるりと抜くと、彼女の内側がそれを惜しむように締め付けた」
- 「ゆっくりと引き離すと、白濁が糸を引いて滴った」
