# P1. 挿入・送り込む動作

**直接表現**: 入れる（1-2）、挿入する（2-3）、挿す（1-2）

## コア語彙

| 言い換え | レベル | ニュアンス |
|---|---|---|
| 沈める | 1-2 | ゆっくり深く |
| 沈み込む | 1-2 | 自動詞形 |
| 埋没（まいぼつ）させる | 2-3 | 完全に埋める |
| 埋め尽くす | 2-3 | 余すところなく |
| 深々と差し込む | 2-3 | 深く挿入 |
| 捩じ込む（ねじこむ） | 3-4 | 強引にねじ入れる |
| 打ち込む | 2-3 | 勢いよく |
| 貫く | 2-3 | 突き通すニュアンス |
| ぶち込む | 3-4 | 乱暴な挿入 |
| めり込ませる | 3-4 | 強引に食い込ませる |

|---|---|---|

| 無理やり | 3-4 | 強制的 |

## 文例
- 「彼の熱を、|秘裂《ひれつ》に当て、ゆっくりと沈めていく」
- 「深々と差し込まれた一撃に、彼女は背を反らせた」
