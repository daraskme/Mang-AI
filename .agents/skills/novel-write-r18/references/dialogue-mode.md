# 会話主体モード

会話、呼吸、擬音、短いト書きを中心に、官能をセリフと間で成立させるハイコンテクスト演出。漫画原作（コミカライズ）・ASMR的没入感を意識しつつ、小説本文の体裁を保つ。音声台本のト書きや話者ラベル（「M：」等）へは変換しない。

共通体系は `shared-craft.md`、擬音・♡・淫語の語彙は `onomatopoeia.md`、実例は pattern-bank 三分冊（buildup／climax／voices）を正本とする。本ファイルは会話主体固有の運用だけを扱う。

## 1. 行の作り方

- 地の文もセリフと同じ短さに刻むのを基本とする（1文＝1行が目安。喘ぎ・短い呻きは「んっ……」だけの行も可）。
- 長めの説明が必要なら行為開始前に3〜5行のブロックとして隔離し、行為中には挟まない。
- 話者交代時の改行は絶対に省略しない。
- 地の文は次の5役割に限定する。どれでもない地の文は削る候補。
  1. ト書き（動作・表情・音を1行）
  2. リアクションの結果報告（過程を書かず結果だけ。「彼女の膝が、崩れ落ちた。」）
  3. 内心短評（視点人物の内心を1行）
  4. 最小情景（場面転換直後の1〜2行のみ）
  5. 擬音の独立強調行

## 2. 発話タグなしの話者判別

「〜と言った」型の狭義タグは最小限（目安：セリフ30個に1回以下）にし、次の四装置を併用する。無意味な動作で飾るくらいなら透明な「言った」を使う。

| 装置 | 内容 | 例 |
|---|---|---|
| 役割語の排他設計 | 一人称・語尾・禁則語・呼びかけ語を二者で完全に分ける | 攻める側「〜だろ」／受け側「〜です」「〜っ」 |
| 前置き一行アンカー | 動作・態度の一行を体言止めで止めてセリフに直結 | 「耳元に唇を寄せて。」 |
| 応答の連鎖 | 問い→応え、要求→拒否／許諾の因果で交互発話を自明にする | 「まだ足りない？」「――足りない、です」 |
| 事後の体言止めト書き | セリフの後に動作で回収 | 「震える声で、そう漏らした。」 |

## 3. 崩壊時も話者判別を維持する（本モードの核心）

フェーズが進み台詞が♡と喘ぎに埋まるほど役割語が効かなくなる。次の代替装置で判別を保つ。

- **残存アンカー**：役割語が崩れても最後まで残す語を各キャラに1つ決める（攻める側は呼びかけ、受け側は母音伸長の型など）。
- **音量・音高の非対称**：攻める側は低く短い呻き（「く……っ」）で台詞が減り、受け側は高く長い喘ぎで台詞が増える。両者を同じ密度・同じ崩れ方で書くと判別不能になる。
- **地の文1行での再アンカー**：ラリーが4連を超えたら、ト書きまたは結果報告を1行挟んで追跡をリセットする。「彼女の腰が、逃げるように跳ねる。」の直後の台詞は自動的に相手のものとして読める。
- **禁則語の解禁を一線の指標にする**：受け側が絶対に言わない語を決めておき、絶頂フェーズでその語が初めて出た瞬間を「一線」の演出に使う。呼び捨てへの変化なども同様に使える。

## 4. ラリーと間の設計

- 基本はセリフ1〜2連＋ト書き1行の交互。
- 絶頂直前・行為の切り替わり目だけ3〜6連の台詞連打を許容する（加速の演出）。それ以外で連打すると間延びする。
- ラリーの終端（絶頂・一段落）には必ずト書きか結果報告を1行置き、次のビートへの区切りを作る。
- 空行は間の演出として緩急で使う：ラリー中は詰め、ビート切替で1〜2行、絶頂直前のタメだけ2〜3行に増やし、直後は逆に詰めて解放の落差を作る。4行以上は連続させない（機械検査対象）。空行数の固定段階表は作らない。

## 5. 淫語のカテゴリ設計

淫語は目的別に4カテゴリで設計し、フェーズに応じて選ぶ。1シーンに全部詰め込まない。

| カテゴリ | 機能 | フェーズ |
|---|---|---|
| 実況型 | 今起きていることを言語化して興奮を共有（「入ってる……奥まで」） | 序盤から使える |
| 比較・煽り型 | 相手を挑発し主導権を揺さぶる（「こんなに濡れてるくせに」） | 序盤〜中盤の余裕がある側 |
| 承認・自己開示型 | 快感を認める発話（「気持ちいい……すごく」） | 高潮以降で解禁 |
| 命令・懇願型 | 主導権の所在を言葉で明示（「もっと」「ちょうだい」） | 高潮以降で解禁。序盤でいきなり懇願させない |

- 攻める側は断定・命令形、受け側は実況・懇願形という非対称を基本にする（話者判別と連動）。実況を相手へ向けるなら相手への声として書く。独白指定ならその形式。体位名や役割の説明にはしない（`guidelines/02-narrative-craft.md` §4-10）。
- 「！？」×♡の複合技法は本モードの重点技法。困惑と快感の同時進行を記号列で伝える（運用規則は `onomatopoeia.md` §♡体系）。

## 6. ASMR的な音の演出

没入感は固定数の囁きではなく**距離の変化**で作る：遠い（会話）→近い（吐息が触れる）→密着（囁きが直接届く）の3段階。

- 距離は前置きアンカーで示す（「耳元で。」「息がかかる距離で。」）。
- 声量の低さは語尾や句読点の密度で示す（「……近い、よ」）。「（囁くように）」等の演出指定は書かない。
- 吐息・呼吸音は独立行の擬音として扱える（「はぁ……」「ふ、っ……」）。話者と原因が分かる位置に置く。
- 台詞内の二人称の呼びかけ（「きみ」「あなた」＋観察の同居）で地の文を削れる。
- 使いすぎると冗長になる。1シーンで2〜3箇所、ここぞという場面に絞る。

## 7. コマ割り演出のパーツ（漫画原作志向）

見せ場を漫画の1コマとして想像できるか（表情・構図が浮かぶか）を常に自問する。

| パーツ | 使い方 | 頻度 |
|---|---|---|
| ダッシュの見得 | 「――」を一線を越える直前・決め台詞の直前に置く | 1シーン2〜3回 |
| 効果音の単独行 | 擬音を空行で挟んで1コマにする | 見せ場のみ |
| 三連反復 | 同型の短文・擬音の三連でリズムを刻む。タメ長め・決着一撃短め | 持続描写 |
| 表情の記号化 | 「ぎゅっと目を閉じて」――心理を言語化せず表情で見せる | 常用 |
| セリフ分割 | 1語を数行に割る（「い」「く」「――っ」） | 絶頂の瞬間のみ |

- 台詞が説明する内容と、絵として見える内容を重複させない。
- シーン末の引きはscene-cardから受け取り、文体Skillが独自に追加しない。同じ型の引きを連発しない。

## 8. 確認

- 任意の3連続セリフを抜き出して、タグなしで話者が確定するか。
- 崩壊が進んだ場面でも、残存アンカーまたは音量非対称で話者が判別できるか。
- 台詞だけでなく位置、許可／強制、結果が分かるか。地の文に3文以上の段落がないか。
- ♡・崩壊・淫語カテゴリがフェーズと整合しているか。
- 記号と短文が均一なリズムになっていないか。空行の緩急が機能しているか。
- 漫画・ASMR志向でも小説本文の体裁を保っているか。
