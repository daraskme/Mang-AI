# R18場面の共通描写体系

3モード共通の正本。基礎の視点、正書法、段落規則は `AGENTS.md` とguidelinesを正本とする。擬音・喘ぎの語彙は `onomatopoeia.md`。A系の本文は `style-corpus/`、B系の本文は `style-corpus-b/`、技法ラベルは pattern-bank の該当節。

各体系は「薄い・駆け足・ぼんやり」を防ぐための設計既定である。数合わせのノルマにはしないが、外すときは場面上の理由を持って外す。

## 1. ビート構造と密度

場面を人物の経験として書く。身体部位や動作の一覧ではなく、次の連鎖を基本単位（ビート）とする。

```
動作または発話（1〜2文）
→ 視点人物が拾う感覚（擬音・五感）
→ 反応（身体反応または台詞）
→ 心理・判断（1文）
→ 次の動作へ
```

ビートの分量は場面の位置で変える。

| 位置 | 密度の目安 | 重点 |
|---|---|---|
| 序盤ビート | 5〜8行相当 | 環境＋接触＋短い台詞。場・温度・関係の緊張を設営する |
| 中盤ビート | 3〜5行相当 | 動作＋擬音＋反応の積み上げ |
| クライマックス | 2〜3行相当 | 擬音・台詞・身体反応を短く強く。要約や事後説明で流さない |
| 事後ビート | 8〜15行相当 | 環境描写＋応酬＋落とし。性急に切り上げない |

- 毎回この順を機械的に明示する必要はない。反復を避け、読者が位置と因果を失う箇所を補う。
- クライマックスは「体験として」描く。「二人は果てた」のような要約で飛ばさない。

## 2. 感覚描写の五層

温度・質感・音・香り・視覚の5層から、各ビートに3層前後を織り込み、視覚偏重を避ける。

| 感覚 | 描写の方向 |
|---|---|
| 温度 | 火照り、吐息の熱、空気の冷たさとの対比、体温が移る感覚 |
| 質感 | ぬめり、圧、布や肌の手触り、粘度、硬さと柔らかさの対比 |
| 音 | 粘音、衣擦れ、呼吸、静寂を破る音。羞恥や高揚の装置として使う |
| 香り | 汗、香水、体臭、部屋の匂い。理性を揺らす引き金にする |
| 視覚 | 光と影、汗、糸を引く液体、表情、視線の交錯 |

技法：

- **対比を作る**：冷たい空気×熱い吐息、硬さ×柔らかさ、清潔な衣装×淫靡な動作。
- **体内感覚を含める**：「腹の奥で何かが張り詰める」「背筋に電流が走る」など、外から見えない感覚が没入を作る。
- **感覚を理解へ変換する**：感覚を列挙して終わらせず、視点人物の判断か次の動作へ接続する。
- **体格差の包摂感は多層化する**：抱え込まれる（温度＋質感＋拘束感）、覆い被さられる（重量＋視野喪失＋密着）のように複数層を同時に使う。

## 3. 強度の設計

強度は前のビートとの差で作る。

- 距離、速度、圧、温度、声量、語彙、主導権のうち、その場で変わったものを描く。
- 同じ反応を強い形容詞へ置換するだけで繰り返さない。
- 高揚が続く場面にも、観察、確認、停止、言い直しなど異なる拍を置く。
- 記号（♡等）・擬音・崩壊の各段階体系はこの「差」を表記に落とすための道具であり、段階を飛び級すると以降の伸びしろが消える。

## 4. 台詞崩壊グラデーション

キャラクターの口調が快楽で段階的に崩れる過程を、そのキャラ固有の声の崩れとして書く。代表的な段階設計とキャラタイプ別の実例は `pattern-bank-voices.md` §11 voice card を参照。

崩壊の文法パターン：

| パターン | 例 |
|---|---|
| 途中切断 | 「待ちなさ……あっ」／言い切る前に身体の反応が言葉を遮る |
| 動詞未完了 | 「イって……しま、う……っ」 |
| ひらがな化 | 漢字語彙がひらがなへ崩れる（格式の崩壊を視覚化） |
| カタカナ化 | 「中」→「ナカ」（異化効果。乱用しない） |
| 母音伸長 | 「だめぇ」「ぜんぶぅ」（1台詞に1〜2箇所。文芸主体ではさらに抑える） |
| 濁点化 | 「ん゛」「あ゛」等。絶頂フェーズ限定 |
| 実況化 | 「入ってる……」「熱いの、いっぱい……」。今起きていることの言語化 |

運用規則：

- **崩壊は段階的**。序盤でいきなり全崩壊させない。中盤までは語尾の維持に努め、絶頂で一気に崩す。
- **崩壊しても残す1点（残存アンカー）** を決める。自称（「わたくし」）、呼びかけ（相手の名前）、母音伸長の癖など、その人物である証拠を最後まで残す。
- 崩れは一方向に進めず、取り繕い、沈黙、言い直しを混ぜると理性の残存が書ける。
- 事後は元の口調へ戻すか、戻り方の不完全さで余韻を作る。

## 5. 感情アーキテクチャ

心理を行為と並走させる。行為だけが進んで内面が消えるのは典型的な失敗。

**攻める側の心理層の例**：
```
驚き・困惑 → 受容 → 快感の自覚 → 征服欲の芽生え → 主導権の奪取 → 達成感
```
- 建前（教育・奉仕・儀式・研究など）と生々しい欲望の二重構造を描く。
- 「これは夢か現実か」という認知的揺らぎを入れると没入感が増す。

**受ける側の心理層の例**：
```
戸惑い → 抵抗感 → 罪悪感 → 反応の自覚 → 受容 → 悦びへの反転
```
- 「最低だ」「逃げなきゃ」という内省を行為と並走させる。
- 終盤に小さな反転（所有欲・嗜虐・積極性の芽生え）を1つ入れると単調な受け身にならない。

**受け側（喘ぐ側）の感情アークの例**：
```
余裕 → 予想外の快感への動揺 → 言葉での抵抗 → 身体の裏切り → 自覚 → 求める側への反転 → 事後の甘え
```

**パワーダイナミクス**：

- 場面開始時と終了時で主導権の所在を変える。「教える側が教わる側になる」「余裕が崩れる」等の反転が最大の読みどころ。
- 反転の瞬間は短文宣言（§7）で一文に刻むと決まる。

## 6. 直接表現と文学的表現の配分

目安は直接60：文学40。投稿先とジャンルで70:30〜40:60に振る（ノクターン系男性向けは直接寄り、女性向け・文芸調は文学寄り）。

| 用途 | 使う表現 |
|---|---|
| 行為の進行・身体反応 | 直接語彙。何が起きているか読者に確定させる |
| 感情の解釈・転換点 | 文学的表現。「恍惚でも慈しみでもない。征服の悦びだった」 |
| 絶頂・射精などの頂点 | 直接語彙＋感覚の結合。「熱い飛沫が奥へ叩き込まれ、腰が跳ねた」 |

禁止パターン：

- 全編を婉曲表現で覆い隠す（AIの典型的失敗。「花弁」「蜜」だけで行為全体を描かない）。
- 直接語彙を感情・文脈なく羅列する（臨床的な部位名の連続で人物の経験が消える）。
- 同じ意味を比喩、感覚、感情名で三重に説明する。

言い換えの正本は [vocab-remap.md](vocab-remap.md)。必要なカテゴリだけ読む。語感はモードに合わせ、汚系は明示時だけ。台詞の口癖は回さない。

推奨パターン：

- 直接語彙を感情・状況と結合させる。「精液が出た」ではなく「白濁が、熱となって解き放たれた」。
- 内壁の擬人化（「吸い付く」「絞り上げる」「迎え入れる」）で受け手側の反応を能動化する。
- 行為の儀式化・フレーム化（「儀式のような静けさ」「これは研究だから」）で背徳や高貴さと接続する。

## 7. 短文宣言と対比構造

**短文宣言**：転換点をダッシュ＋短文で刻み、説明を加えず読者に衝撃を委ねる。

```
　――その一言が、引き金だった。
```

- 段落の頭または末尾に置く。多用すると効果が死ぬ（1場面2〜3回まで）。
- 直前に長めの文で圧を溜めると、溜め→解放の落差が生きる。

**対比構造**：場面の軸になる対比を1つ以上仕込む。

- 高貴な外見×淫らな行為／理性×本能／教える側×教わる側の逆転
- 清潔×淫靡／日常の記号×非日常の行為
- 体格差（数値や動作で具体化する。「片腕で抱え上げられるほど軽い」）
- ここでの対比は、場面が実際に転じる軸である。同じ感覚を「AではなくB」で言い直すだけの文は足さない（`guidelines/02-narrative-craft.md` §2-8）。

## 8. 射精描写の3要素

**予兆 → 擬音 → 着弾感覚** を必ず揃える。予兆を省いて突然射精しない。

標準形は5層に拡張できる：予兆（体内感覚2〜3文）→短い宣言台詞→受け手の反応台詞（合意なら許諾でも可）→擬音独立行→着弾感覚（方向・温度・深度・量・受け手の反応）。強制場面で許諾台詞を足さない。

- 突発型では予兆を1文に圧縮し、受け手の反応のグラデーションで時間軸を伸ばす。
- 着弾感覚は地の文で受け止める。擬音だけで終わらせない。
- 具体的な擬音の系統は `onomatopoeia.md`、構造実例は `pattern-bank-climax.md` §6 射精3要素を参照。

## 9. 事後の人間性回復

絶頂後はscene-cardの終了状態に合わせて「人」に戻す。照れ・甘え・ユーモア・罪悪感は関係の変化に合うとき使う。強制場面を甘えへ均さない。

型の例（scene-cardの終了状態に合うものを選ぶ）：

- 種明かし型（張っていた建前や仕掛けを明かす）
- 合理化型（冒頭の合理化口実と対応した言い訳で閉じる）
- 世話焼き型（後始末・清拭・抱擁・髪を撫でる）
- ユーモア型（緊張の直後に軽口で平常へ戻す）
- 次への含意型（「次は……」で余韻と引きを残す）

事後は8〜15行相当を割き、性急に場面を切らない。環境描写→内心→応酬→落とし、の流れが安定する。

## 10. 核イメージと比喩

- 場面を束ねる比喩は、核一つを序盤・中盤・終盤で状態変化させるのを既定にする。補助は必要なときだけ足す。これは密度の設計既定であり、作品全体の比喩本数の例外規定ではない。地の文の骨格は `guidelines/02-narrative-craft.md` §2-8。採否は `guidelines/05-ai-guardrails.md` §3-4、過密は §3-5 の系統5。事後も同じ採否に戻る。
- 比喩は視点人物の生活、職業、文化、記憶から選ぶ。人物の経験から離れた大仰な像（宇宙・銀河・神話）を自動採用しない。
- 一つのビートで、動作を隠す比喩と感情を言い直す比喩を重ねない。本数の上限は割当にしない。
- 代表的な方向の例：熱・融解／絹・蜜／水位と決壊／燠火／布・衣服の剥離／楽器の調律／内壁の擬人化／包摂（体格差）。
- 指が沈む、腰が跳ねる、内壁が絞る等の身体の動きは、部位が主語でも物理描写として書ける。会話と事後で「目が言った」「仕事の顔で」型が誰の行為かを隠すときだけ、05 §3-5 で直す。慣用や実際の動作まで人物主語へ戻さない。

## 11. 合理化口実とシーン継続装置

**合理化口実（事前装填）**：行為の前段で「研究だから」「練習に付き合うだけ」「これは治療だから」等の合理化フックを1つ用意すると、後にそれが崩れる瞬間が読みどころになる。口実はscene-cardまたは関係設定から取る。

**シーン継続装置**：回復魔法・薬・契約などの設定上の仕掛けで連戦・体位転換の口実を作る。作品の正典にある装置だけを使い、Skill都合で新設しない。装置の名称表記（ルビ）は作品の正本に従う（`guidelines/01-writing-rules.md` §8）。

## 12. 声と許可／強制の可読性

- 高揚しても character-sheet の声を残す。語尾の崩れや発話の短縮は、人物固有の癖と状況から生じさせる。短縮の直前に `guidelines/02-narrative-craft.md` §4-10。独白が指定されていればその形式。状況の説明と依頼の言い直しを足さない。短縮で行為者・態・否定・命令の強さを変えない。地の文が依頼の文言を返すときは同 §6。
- 合意確認を説明台詞の義務にしない。拒絶や沈黙を肯定へ読み替えない。強制・非合意は依頼と文脈どおりに描く。
- 「嫌悪→反転」は、拒絶が建前でも本気でも、言葉と身体の乖離を地の文で描く。実は合意だったと上書きしない（`safety-and-inputs.md` §2）。

## 13. 場面の終端

余韻、会話、距離、関係変化、日常への復帰はscene-cardの終了状態に合わせる。場面後は一般文体へ戻し、R18場面だけで使った記号、語彙、段落密度を後続場面へ漏らさない。
