## 8. 連戦・シーン継続装置

```
「今日は回数、気にしなくていいよー。気持ちよくなることだけ考えて、一緒に終わっちゃおうね♡」

「おまえ、また魔法使ったな！」
```
→ 天真爛漫型の明るい口調が装置発動のシグナル。視点人物の抗議は短句1行。

```
「ここなら、術で全部吐き出させられます」
```
→ クール敬語型は状況分析＋必要性宣言で発動する。装置は作品の正典にあるものだけを使う。

```
（これは……死ぬ）

　――湯の音だけが残り、意識は甘く暗転した。
```
→ 連戦ピーク後の定番落とし所。内心括弧＋環境音1文＋短い終止文で意識を切る。
