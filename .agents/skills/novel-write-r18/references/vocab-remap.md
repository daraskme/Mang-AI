## 連続回避（操作目安。ノルマではない）

1. 地の文で同じ部位名詞を連続する2文に置かない。
2. 同一場面の地の文では、主部位を2種以上回す。
3. 適用前に、当該場面の既出の性器・体液・部位語を洗い、未使用から選ぶ。
4. 同じ指示対象（誰の／何の）に同じ性器語を当て続けない。
5. 名詞だけでなく「修飾＋名詞」の型も回す。
6. 「それ／塊」で埋めるとき、直前の既出語へ吸い寄せない。

口癖・固有の呼び方は回さない。
