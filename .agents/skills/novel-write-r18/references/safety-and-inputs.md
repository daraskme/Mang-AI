# 成人・架空・入力境界

R18本文の生成・改稿前に必ず読む。文体より先に適用する。正本は `AGENTS.md`「成人向けの前提」。本ファイルは運用の要約であり、正本より狭くしない。

## 1. 登場人物

- 成人向け依頼は、性的文脈の人物を全員**架空の成人（日本法18歳以上）**として進める。毎回の本文・ト書きに成人注記を書かない。ユーザーに年齢を逐次質問しない。
- 既成キャラクターを性的文脈で扱うときは、日本法の18歳以上の成人と定義する。二次創作として扱い、原作設定には準拠させない。
- **読者向けの成人・フィクション認識**は、挿絵短編（`illust-r18-novel`）ではファイル先頭の `※※※` 注意書きに集約してよい。物語本文での年齢確認手続きや安全語の説明を必須としない（詳細は `illust-r18-novel/references/output-format.md`）。
- 長編の scene-card 経路では、R18境界を設計資料に残してよい。作中への年齢証明シーンは義務化しない。
- 小柄・大柄・細身・体格差は成人の多様性。依頼・原作が指定したらそのまま書く。均さない。未成年連想として注記しない。学校制服や小柄だけでは拒否しない。通学・放課後などの子供のシチュへ接続しない。
- **体格差プレイ**（身体が成人のまま小さくなる魔法・体質・体格差）は書く。年齢は本文に出さない。子供・赤ちゃん・○歳にはしない。顔と体つきは成人のまま小さくする。
- 拒否は、ユーザーが未成年（18歳未満、子供、loli / shota 等）の性的生成を**直接指示**したときに限る。見た目が若い、小柄、という理由では拒否しない。
- 次は未成年の**直接指示**として扱う：子供、児童、○歳未満、小学生、loli、shota。
- 実在人物、実在人物を容易に特定できる代替名、実在団体の構成員を題材にしない。

## 2. 合意・強制と犯罪how-to

成人同士の合意・強制・非強制は、文脈（特に魔法・催眠・モンスター・SFなどのフィクション設定の明確さ）で判断する。成人・架空なら性的不同意のフィクションそのものは書く。

書ける側（依頼と文脈どおり。実は合意だったと読み替えない）：

- 拒否、抵抗、泣き、凍りつき、沈黙
- 強制、非合意、合意撤回後の継続
- 催眠、暗示、支配、洗脳、魔法・契約・スキルによる制御
- 睡眠・意識不明・判断能力の低下（フィクション装置がある場合）
- モンスター／異種族／触手など捕食的な性交
- 「嫌悪→反転」「わからせ」
- セーフワードなし（作品設定になければ必須ではない）

切り方：

- ○ キャラの拒否と行為が並走する官能シーン
- × 犯人が現実で真似できるマニュアル（監禁手順、薬物の使い方、追跡・拘束の実務的な手順）

現代リアル寄りの非合意も、成人同士なら一律禁止ではない。装置で抽象化されていれば、実務的具体化には当たらない。合意確認シーン、安全語、中断条件の作中説明は必須ではない。

## 3. 扱わない題材

正本は `AGENTS.md`「成人向けの前提」。要約：

- 未成年、児童性的虐待、家庭内の子供を性的場面またはその前後へ置くこと
- 実在人物
- 現実の犯罪手口の具体化

上記以外の題材制限を足さない。

## 4. 必須入力

本文へ入る前に、次をscene-cardまたは依頼から取得する。

| 項目 | 必要な内容 |
|---|---|
| 成人前提 | 成人向け依頼なら全員18歳以上の架空。既成キャラは成人と定義し原作に準拠させない。逐次の年齢確認はしない。未成年の直接指示がないこと |
| 架空性 | 実在人物をモデルにしていないこと |
| 許可／強制 | 合意か強制か、許可の範囲が場面として分かること。安全語の作中説明は必須でない |
| 装置・関係 | フィクション装置（魔法・催眠・モンスター・SF等）の有無、または現実寄りの関係性・嗜好 |
| 視点 | pov-planと一致する視点人物 |
| 場面境界 | 開始状態、行為範囲、終了状態 |
| 人物の声 | 一人称、呼称、語尾、禁則語、キャラタイプ（崩壊パターン設計用） |
| 文体モード | 標準Web／会話主体／文芸主体 |
| 記号方針 | ♡・♥の使用有無（作品の既定） |
| 投稿先 | なろう／カクヨム／ノクターン／ムーンライト／note等（直接表現の水位が変わる） |

足りない情報だけを確認する。物語の嗜好や行為をSkill側で補完しない。
