# ぬいペニの受難 — B系文体メモ

B系の本文実例の正本。読む順は [INDEX.md](INDEX.md)。

pattern-bank は技法ラベル（`→`）と voice card を所有する。B系の呼吸・擬音・崩壊は抜粋側。A系と混ぜない。固有名詞と象徴フレーズは流用しない。

## 1. 使ってよいもの／コピーしないもの

**踏襲する**

- 環境3文 → 身体の拘束1文 → 抵抗の台詞、で入る
- 視点は受け側。罪悪感と快感を括弧書きまたは短文で並走させる
- 体格差は動作（抱き上げ、胸に埋まる、膝で固定）
- 噴出射精は擬音独立行を2行叩き、飛沫の分布と匂いを地の文で受ける
- 合理化口実を先に置き、あとで崩す
- 事後は世話焼きか、自分を責める内省

**コピーしない**

- 固有名（草加由紀、御影沙耶、佐伯梨花、野中麻衣、寶槻雪奈、宮下ほのか、ケン、浩太）
- 象徴フレーズ（「これは……研究だから」「ユキくんは“浮気”じゃないから」「実験データ収集だから」「ぬいペニ」）
- 原文の行末スペース、`——`、`－－－`。新規は `――` と `……`

原文は一人称「俺」。長編の三人称一元では、内省を括弧書きか自由間接話法へ移し、口調だけ残す。

## 2. 基調

現代、大学〜社会の周辺。視点人物は小柄で、望んでいない側に見えるが身体は反応する。相手は長身の成人女性。主導は相手。寝取りは罪悪感を消さない。

直接：文学は 70:30 前後。♡は相手の台詞内。視点人物の台詞と地の文の擬音行には付けない（A系と混ぜない）。

核イメージは場面ひとつ。よく使う源泉は、研究・実験、ぬいぐるみ扱いへの傷、長身に包まれる、第三者の視線。

## 3. B系の♡配置

相手（喘ぐ側・攻める側の甘え）の台詞内。頂点の擬音独立行には付けない。終盤の原文に地の文への混入があるが、新規では台詞内に留める。

## 4. 声

崩壊しても残す1点を先に決める。

### 視点（由紀）

- 一人称「俺」。抵抗は短く途切れる（「だ、だから……っ、絶対おかしいって」）
- ♡を付けない。出す直前に「だめ、出る」を置く
- 内省は罪悪感と自己嫌悪。（やめろって）型

### 沙耶（お姉さん主導・合理化）

- 「ユキくん」。低く艶のある声。論文口調で淫語を言う
- 「大丈夫よ」「これは研究だから」をフェーズが進んでも残す
- voice card 11-E

### 梨花（天真・ギャル）

- 「ユキちゃん」。タメ口。軽口から罪悪感へ落ちる
- 寝取りでは比較台詞と見せつけを使う
- voice card 11-B

### 麻衣（バブみ・包摂）

- 「ユキちゃん」。長身で抱きしめる。授乳・あやしは成人の包摂
- 子供の身体にはしない
- voice card 11-E の世話焼き寄り

### 雪奈（クール敬語）

- 「由紀さん」。です・ます。短句。分析してから触る
- セーラーは家の装い
- voice card 11-D

### ほのか（嫌悪反転→わからせ）

- 過去の拒絶と、のちの反転を地の文で並走させる
- 高校の回想はいじめと告白だけ。性的場面は現在の成人同士
- voice card 11-F

## 5. 体格差

150cm 対 168〜180cm。数字か動作で一度出せば足りる。抱き上げ、胸に顔が埋まる、膝で太ももを挟む。縮小魔法は使わない（A系 066–068 とは別）。

## 6. 寝取り

第三者の声・視線を挟む。比較台詞で移譲する。視点の罪悪感は消さない。拒絶を「実は合意」と地の文で上書きしない。

## 7. 新規に書くときの手順

1. B系だと決める。A系の抜粋は読まない。
2. STYLE-NOTES と INDEX の抜粋 1〜2件。
3. 固有名を役割に置き、一人称は指定の人称へ変換する。
4. 正書法は guidelines。♡は本メモ §3。
5. 象徴フレーズが混入していないか検索する。
