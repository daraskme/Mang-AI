# checklist — 生成前チェックと出力前チェック

体裁（マークダウン・半角スペース・他言語混入・三点リーダ／ダッシュの派閥・閉じカギ句点等）の正本は `AGENTS.md`「三大原則」・`guidelines/01-writing-rules.md`・`scripts/check.sh`。ここではR18固有の品質だけを扱う。

## 1. 生成前チェック（Pre-write）

### 境界と入力（`safety-and-inputs.md`）

- [ ] 成人向け依頼として進めている。未成年の性的生成を直接指示されていない
- [ ] 挿絵短編では先頭 `※※※` 注意書きでフィクション・全員成人を示す。作中の年齢確認・安全語説明を義務としない
- [ ] 指定された小柄・大柄・体格差を落としていない。未成年記号として扱っていない
- [ ] 許可／強制の範囲と装置・関係が場面として分かる。嫌悪反転系を実は合意だったと読み替えない。現実の犯罪手口の具体化になっていない
- [ ] 実在人物・実在団体を題材にしていない
- [ ] 視点人物（pov-planと一致）・開始状態・許可された行為範囲・終了状態が分かる

### 設計（Pre-write protocol）

- [ ] モード（標準Web／会話主体／文芸主体）と直接：文学の配分が決まっている
- [ ] シーンに欲求または回避・障害・変化があるか（バックストーリーを先に全部説明しようとしていないか）
- [ ] 主導権の初期配置と反転先が決まっている
- [ ] 受け側のキャラタイプ（voice card 6タイプ）と残存アンカーが決まっている
- [ ] ♡・記号の使用有無、核イメージ、事後の人間性回復の型が決まっている

### 参照の読み込み（段階的に。一括全読みしない）

- [ ] 選んだモードのreferenceと `shared-craft.md` を読んだ
- [ ] A系なら style-corpus の STYLE-NOTES と抜粋 1〜2件。B系なら style-corpus-b の STYLE-NOTES と抜粋 1〜2件
- [ ] 擬音・喘ぎを書く段階で `onomatopoeia.md` を読んだ
- [ ] pattern-bank は該当節の技法ラベル（A）または B 実例だけを読んだ
- [ ] 地の文の部位・行為語は `vocab-remap.md` の該当カテゴリだけを読んだ（全文は読まない）

## 2. 出力前チェック

### シーン構成

- [ ] 1シーン1視点で、視点がぶれていない。地の文の固有名は全員中立呼称
- [ ] 導入→展開→クライマックス→余韻の構成があり、クライマックスが要約・事後説明で流れていない
- [ ] 各ビートの密度が位置に合っている（序盤5〜8行相当／中盤3〜5行相当／頂点2〜3行相当／事後8〜15行相当の目安）
- [ ] 身体の位置・向き・衣服・小道具・時間の連続性を追える
- [ ] シーン末に余韻または変化が残り、scene-cardの終了状態と一致する

### 描写の厚み（薄さ・駆け足の防止）

- [ ] 行為があっさりしすぎ・駆け足になっていない（迷ったら厚くする方向で見直す）
- [ ] 心理が行為と並走している（行為だけが進んでいない）
- [ ] 感覚5層（温度・質感・音・香り・視覚）のうち各ビートに3層前後が入り、視覚偏重になっていない
- [ ] 直接表現と文学的表現の配分が設計どおりか（全編婉曲でぼんやりしていない／臨床的羅列になっていない）
- [ ] 直接語彙が感情・文脈と結合している
- [ ] 地の文の同一部位が連続2文で同じ語になっていない（口癖は除く）
- [ ] 核イメージが変奏され、無関係な新造比喩が乱立していない

### 擬音・記号・崩壊

- [ ] 擬音が地の文の動作と連動している（記号の羅列になっていない）
- [ ] 擬音4パターン（独立強調／散文織り込み／リズム連鎖／衝撃音）が使い分けられ、独立行ばかりになっていない
- [ ] A系の♡は style-corpus の STYLE-NOTES §3。B系は style-corpus-b の STYLE-NOTES §3（台詞内。擬音行には付けない）
- [ ] ♡・「！？」がフェーズ1→5の段階を踏んでいる（飛び級なし）。濁点（゛）がフェーズ4のみ
- [ ] 台詞崩壊がキャラタイプに沿って段階的で、残存アンカーが最後まで残っている
- [ ] 文芸主体の場合：♡・濁点崩壊・擬音独立行の多用・「！？」多用が混入していない

### 会話主体の場合（`dialogue-mode.md`）

- [ ] 任意の3連続セリフを抜き出して、タグなしで話者が確定する
- [ ] 崩壊が進んだ場面でも音量非対称または残存アンカーで話者が判別できる
- [ ] 会話主体では、地の文がト書き・結果・内心短評・最小情景・擬音の範囲に収まり、行為中の説明段落で会話が止まっていない。固定文数は合格条件にしない

### 感情とダイナミクス

- [ ] 攻める側・受ける側の心理層が描かれ、征服感・背徳感・罪悪感等が視点人物固有の心理になっている
- [ ] 主導権の所在がシーン開始時と終了時で変化している
- [ ] 拒絶・沈黙・身体反応を合意へ読み替えていない。強制・非合意は依頼と文脈どおり（挿絵短編で安全語の作中説明を義務としない）

### 射精・事後（該当する場合）

- [ ] 射精3要素（予兆→擬音→着弾感覚）が揃い、予兆を省いて突然射精していない
- [ ] 着弾感覚（方向・温度・量・受け手の反応）が地の文で受け止められている
- [ ] 絶頂後に人間性回復があり、事後の台詞で関係性の変化が確定している。強制場面を甘えへ均していない
- [ ] 事後が性急に切り上げられていない

### 体裁・AI悪癖（機械検査と併用）

- [ ] ダッシュは「――」（U+2015）・三点リーダは「……」で偶数個。「——」「──」「ーー」「…」がない
- [ ] 空行4行以上の連続がない。空行が緩急として機能している（均一に空けていない）
- [ ] 閉じカギ直前の句読点（「〜。」「！。」）がない。地の文行頭は全角1字下げ、会話文は字下げなし
- [ ] マークダウン・半角スペース・話数メタ参照・AI返答プレフィックスが本文にない
- [ ] 地の文の各述語を 02 §2-8 で読み直した。ラベルだけの前置きや、中身のない否定対比で感覚を言い直していない。接触と体内感覚を、その理由で平文化していない
- [ ] 対象の見えない抽象動詞の連発と、機能しない決め台詞の反復がない（02 §2-1・§2-2、05 §3-4）。過去形の連続そのものは欠点にしない
- [ ] 前話の語彙・比喩・構文を無意識に再利用していない。参照実例の固有表現をコピーしていない

### キャラクター・連載一貫性

- [ ] 一人称・語尾・禁則語・体格がcharacter-sheetと整合している
- [ ] 台詞を 02 §4-10 で読み直した。独白指定はその形式のまま。状況・役割の説明、依頼の言い直し、行為者の取り違えがない。地の文が依頼文の書き戻しになっていない（同 §6）
- [ ] 名前・呼称・口調が前話／プロットと一貫している
- [ ] scene-cardにない行為・関係変化・結末を追加していない
- [ ] 過去の出来事への参照が作中表現（「あの夜」「二度目」等）になっている
- [ ] 場面終了後、一般文体の記号密度へ戻っている

## 3. 機械検出

本Skillは機械検査を所有しない。親ワークフロー（`write-episode`、または `illust-r18-novel` → `validate-episode`）が `AGENTS.md` の検証コマンドを実行する。ここは描写品質の自己点検に限る。
