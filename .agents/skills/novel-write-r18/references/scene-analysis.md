# scene-analysis — R18シーン分析・強化フレームワーク

既存R18シーンの分析と改善提案を**明示的に求められた場合のみ**使う。リポジトリの執筆ワークフロー内では、検査・改稿ループの統括は `validate-episode` が所有する（本フレームはその中のR18固有観点として使える）。

フェーズ1と2は、別指示がない限り1回の応答でまとめて実行する。分析対象の許可／強制の範囲・展開・結末は固定し、変更が必要ならplot／scene-card側の判断として返す。

## フェーズ1：詳細分析

### 1-1. シーン概要

- **要約**：何が起きているか・どのような行為が描かれているか
- **位置づけ**：物語全体でこのシーンが持つ意味・役割（関係の進展・転換点など）
- **現在の強み**：効果的に機能している要素

### 1-2. 5観点分析

#### A. 心理描写

- 現状：内面描写の量／行為中の心境変化／征服感・背徳感・欲望・罪悪感／視点人物固有の心理の浸透度
- 評価：「何を感じているか」が伝わるか。優しさだけでなく生々しい欲望も描けているか。心理が行為と並走しているか
- 改善の余地：追加すべき心理層／反転点の演出／自由間接話法・内心括弧の活用

#### B. 感覚・身体描写

- 現状：感覚5層（温度・質感・音・香り・視覚）の活用度／体内感覚・対比の有無／直接語彙と文学的語彙の配分／内壁の擬人化・包摂感の多層化
- 評価：読者が「体感」できるか。各ビートに3層前後あるか。婉曲に偏って場面がぼんやりしていないか（AIはこの傾向が強い）
- 改善の余地：不足している感覚層／直接語彙を追加すべき箇所

#### C. 雰囲気・演出

- 現状：空気感／環境描写／擬音の配置パターン（4型の使い分け）／♡エスカレーションの段階遵守／短文宣言の効果／言葉と沈黙のバランス
- 評価：没入できるか。擬音がビートの頂点を際立たせているか。記号密度がシーン進行と同期しているか。フェーズ5で余韻に着地しているか
- 改善の余地：擬音パターンの多様化／フェーズの段階調整／間（空行の緩急）の設計

#### D. キャラクター性と関係性

**この観点の分析前に、character-sheetまたは会話履歴のキャラ情報を必ず確認する。**

- 現状：行為中も個性が保たれているか／台詞崩壊グラデーションの設計（voice card 6タイプ）／残存アンカー／パワーダイナミクスの初期配置と反転
- 評価：「このキャラクターだからこその描写」になっているか。単なる行為ではなく二人の物語になっているか。崩壊が段階的か（飛び級なし）
- 改善の余地：個性的な台詞・反応の追加／崩壊パターンの調整／反転の強化

#### E. 構成・テンポ

- 現状：導入→展開→クライマックス→余韻の構成／緩急／ビート密度（序盤5〜8行相当／中盤3〜5行相当／頂点2〜3行相当／事後8〜15行相当）
- 評価：山場に十分な分量が割かれているか。射精3要素が揃っているか。事後の人間性回復が描かれているか
- 改善の余地：テンポ調整箇所／追加・削減すべき部分

### 1-3. 総合評価とブラッシュアップ必要性判断

- シーンの完成度／最も効果的な要素／最も改善が必要な要素

**判断の前提**：初稿・AI生成の官能シーンは「あっさりしすぎ」の傾向が強い。「不要」のハードルは高く設定し、迷った場合は「必要」または「部分的に必要」と判断する。

「必要」と判断すべきケース（いずれかに該当）：

- 行為描写があっさり・駆け足になっている
- 心理描写が薄く感情移入しにくい／感覚描写が単調または不足
- 婉曲ばかりで直接表現が不足している
- キャラの個性が活かされていない／崩壊が飛び級している
- 射精3要素のどれかが欠けている／事後の人間性回復がない
- もっと厚みを出せる余地がある

最終判断を「必要／不要／部分的に必要」で明記し、理由を説明する。「不要」ならフェーズ2をスキップして報告する。

## フェーズ2：改善案の提案

「必要」「部分的に必要」の場合のみ。優先改善ポイントを最大10個（優先度：高・中・低）提示し、各案に次を含める。

1. **改善種別**：［心理描写追加］［感覚描写追加］［情緒描写追加］［台詞追加・修正］［擬音追加・修正］［記号フェーズ調整］［射精3要素補完］［事後処理追加］［表現修正］［構成調整］
2. **対象箇所**：どの場面のどの箇所か
3. **対応観点**：A〜Eのどれか
4. **現在の文章**：［表現修正］の場合は省略せず完全な形で記載
5. **改善案**：追加・修正後の具体的な文章例（完全な形で）
6. **期待される効果**と**注意点**

## フェーズ3：ユーザーとの確認

採用／不採用／修正後採用の3択で確定する。修正後採用の場合は方針を確認する。

## フェーズ4：本文への反映

- 確定した改善案を既存の文脈に自然に溶け込むよう反映する。
- 保存パス指定があれば書き込み、なければ応答内に出力する。
- 反映後、`checklist.md` §2で自己検証し、大きく変更した場合は差分の要約を3〜5行で報告する。
- リポジトリ内の話に対する反映では、機械検査と台帳更新を親ワークフロー（`validate-episode`）へ引き継ぐ。

## 分析時の原則

- **厚みを優先する**：「現状で十分」と安易に判断しない。迷ったら追加・強化の方向で提案する。
- **骨格を維持する**：行為の流れ・展開・結末は変えず、描写の厚み増しに集中する。
- **キャラらしさを最優先**：どんな追加もキャラ設定との整合を確認し、voice cardのタイプに応じて崩壊を使い分ける。
- **系統の一貫性**：A系（婉曲多め）とB系（直接多め）を1シーン内で混ぜない。POV・直接表現比率をシーン全体で揃える。
- **境界の再確認**：分析・反映の前に `safety-and-inputs.md` の成人・架空・犯罪how-to境界を満たしているか確認し、満たさない本文には文体改善を行わずユーザーへ返す。
