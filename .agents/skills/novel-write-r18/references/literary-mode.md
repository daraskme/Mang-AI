# 文芸主体モード

地の文へ視点人物の心理を浸透させ、身体感覚と生活の文脈を一つの散文として書く、3モードの中でもっとも硬派なモード。♡・♥・濁点崩壊・「！？」多用のような記号強調は使わず、昂りも困惑もすべて語彙と文構造で書く。note・文庫調・同人書き下ろし・女性向け官能の読み味。

共通体系は `shared-craft.md` を正本とする。本ファイルは文芸主体固有の文法を扱う。

## 1. 自由間接話法による心理浸透

三人称一元の地の文に、視点人物の内心の声をカギ括弧なし・内心括弧なしで混ぜ込む。文芸官能の心理密度はこの技法で作る。

```
　もう何年も、こんなふうに名前を呼ばれていない。
　その声に、心のどこかが反応するのを感じた。今さら、そんなはずはない。そう思うそばから、耳の奥がまだ、あの声を探している。
```

効果的な使いどころ：

- **禁止の自己命令と、その即座の破れ**：「見てはいけない」→直後に破らせる。
- **時間の歪み**：「どれくらい経ったのか、分からなかった」。
- **疑問形の自問**：「いつから自分は、こんな声を出す女だったのか」。
- **合理化・言い訳の独白**：崩れていく過程そのものを書く。文の唐突な切断で認識のずれを見せる。

禁止パターン：

- 「〜と思った」「〜と感じた」の連発（自由間接話法はこれを消すための技法）。
- 内心を（　）で括る記法。地の文に溶かすこと。
- 作者の倫理判断や相手の内面を地の文へ混ぜること。
- 心理が深いことと、長い内省で動作を止めることの同一視。心理は行為と並走させ、現在の選択へ戻す。

## 2. 官能語彙の階調

直接:文芸＝40:60〜50:50を目安にする（Web男性向けより文芸寄り）。投稿先・トーンで調整してよい。

| 階調 | 用途 | 語彙の方向 |
|---|---|---|
| 漢語隠語 | 行為の進行・身体の描写 | 秘裂・蜜・媚肉・剛直・怒張・白濁・柔肉 など |
| 和語・生理の直接語 | 身体反応の解像度 | 濡れる・疼く・ひくつく・締めつける・こぼれる・滴る・脈打つ |
| 文芸的表現 | 感情の解釈・転換点 | 「身体の芯が火照りを孕む」「理性の輪郭が溶けていく」 |

運用規則：

- 1シーンの中で軸をぶらさない。漢語隠語を軸に選んだら、カタカナ俗語・伏字を地の文に混ぜない（台詞内の高揚した局面でのみ俗語を許容）。
- 直接語彙は感情・状況と結合させる。「愛液が溢れた」（事実の羅列）ではなく「自分でも信じられないほどの蜜が溢れて、内腿を伝った。こんな感覚は、忘れていたはずなのに」。
- **全編婉曲の禁止**：花弁・蜜壺だけで行為全体を覆うのは典型的な失敗。挿入・絶頂は直接語彙で芯を通す。
- 婉曲名詞を増やすより、動詞、温度、圧、重心で官能を作る。

## 3. 昂りの語り口（記号ではなく語彙で書く）

♡・♥・濁点崩壊・三連記号・「！？」の多用は使わない。仮名の密度・母音の伸び・句読点・語の残存率で昂りを描く。

| 段階の目安 | 表記の特徴 | 例 |
|---|---|---|
| 抑制 | 声を殺す。地の文で処理し、台詞にしない | 「……っ」／地の文「喉の奥で声が潰れた」 |
| 動揺 | 短い母音が漏れる。すぐ言葉で打ち消す | 「あ……っ、待って……」 |
| 混濁 | 言葉と息が混ざる。文が途中で切れる | 「そこ、は……あぁ……っ、待って、待っ……」 |
| 解放 | 語彙が実感の言語化に転じ、取り繕いが脱落する | 「いい……いいの……」 |

運用の要点：

- 一方通行で崩さない。解放に触れた直後に「口を手で塞いだ」等で抑制へ引き戻すと、理性の残存が書ける。
- 喘ぎの半分は地の文で書く（「声にならない声が漏れた」）。台詞行の連打をしない。
- 母音伸長は1台詞に1〜2箇所まで。それ以上はWeb調に転ぶ。

## 4. 身体の裏切りと成熟した身体

意志と身体反応の乖離は、**身体側を主語**にして書く：

```
NG：彼女は感じてしまった。
OK：腰が、意志を置き去りにして、小さく揺れた。
OK：閉じようとした膝から、力が抜けていく。
```

身体は生活者の身体として書く。小柄・大柄は多様性。指定があれば従う。年齢の数値を冒頭に置く義務はない（`AGENTS.md`「成人向けの前提」）。

- 柔らかさ・重み・生活の疲れなど、その人物の身体を肯定的な官能として書いてよい。
- 生活で鍛えられた手際、疲れの残る肩、髪をまとめ直す仕草など、生活者の所作で人物を立てる。
- 経験の痕跡を核にしてよい：「知っているはずの快楽」と「知らなかった快楽」の対比。

## 5. 文の呼吸

数値規定は設けない。**感覚を積む長文と、心理を落とす短文を交互に置く**という原則だけを意識する。

```
　手のひらは、これまで知っていたどの手よりもひとまわり大きかった。布越しの熱が肌に染みて、自分の呼吸が浅くなっていくのが聞こえる。
　いけない、と思う。
　思うそばから、背筋が小さく撓んだ。
```

長文で感覚を積み、短文で心理を落とし、直後に身体の裏切りを1文置く。この落差が官能散文の緩急の正体。

擬音は独立行ではなく**文の中に住まわせる**ことを基本とする：

```
　律動のたびに、くちゅ、くちゅ、と規則正しい水音が立って、それが自分の身体の立てている音だと思うと、耳を塞ぎたくなった。
```

音を羞恥や高揚の装置として使う。すべてのビートに擬音を入れる必要はない。一線を越える瞬間や絶頂の瞬間だけ独立させると効果が際立つ（多用しないこと自体が効果の条件）。

## 6. 短文宣言と決壊の一文

一線を越える瞬間・関係が変質する瞬間は、ダッシュ＋短文で刻む。

```
　――彼女は、目を閉じた。
```

- 1場面1〜2回に絞る。直前は長めの文で圧を溜める。
- 決壊の一文は「何が失われたか／変わったか」を書く。「気持ちよかった」ではなく「戻れなくなった」を書く。

## 7. 生活・関係性のディテールと官能の接続

官能の背徳・親密さは生活の記号の上に成立する。1シーン2〜3個の生活ディテールを官能の文脈に置き直す。

| 生活記号 | 官能接続の型 |
|---|---|
| 身につけているもの（指輪・時計・香水） | 行為の最中に視界に入る／外す・外さないの逡巡 |
| 生活の時間圧 | 「あと一時間で」等、日常が官能を急かす・中断させる |
| 部屋・寝具・匂い | 生活の痕跡が身体の記憶と結びつく |
| 季節・天候 | 湿度・気温の変化を官能の通奏低音にする |
| 過去の記憶 | 出会った頃の記憶が、今の行為に重なる |

- 生活記号は先に無色のまま提示し、官能パートで意味を反転させる。
- 定型セットとして必須化しない。現在の場面に意味を与えるものだけを使う。
- 子供の存在を性的文脈・性的比喩に用いない。

## 8. 比喩の組み立て（核イメージの変奏）

核イメージを1つ＋補助1〜2つに絞り、選んだ核を状態変化させて変奏する。

例（核＝燠火）：序盤「灰をかぶった燠のように、身体は長いこと静かだった」→中盤「掘り起こされた燠が、息を吹きかけられて赤らむように」→終盤「火は、消し方を忘れるほど育ってしまった」。

- 生活と地続きの比喩を選ぶ（台所・季節・布・水）。神話・宝石・宇宙は文芸官能では浮く。
- 比喩は視点人物の語彙から出す。1ビートに比喩は1つまで。
- 禁止比喩：「星が弾ける」系の絶頂常套句、「壊れてしまう」の乱用（使うなら1作品1回）、「まるで〜かのように」の連打（隠喩と動詞で書く）、婉曲名詞の乱造（花園・泉など）。

## 9. 台詞

- 台詞は少なく、重く。地の文の海に台詞が島として浮かぶ密度を基本とする。
- 台詞の前後に動作・沈黙・視線を挟み、所作で話者と温度を示す。
- **言わないことが台詞**：言葉を飲み込む・目を伏せる・一拍遅れて答える。沈黙と間を書く。
- 関係や状況を台詞で説明させない。情報は地の文と断片で出す。
- 許可か強制か、誰が何をしているかは明瞭にする。合意確認の説明台詞は義務にしない。

## 10. 確認

- 自由間接話法が交合パートにも並走しているか（行為だけが進んでいないか）。
- 「〜と思った」「〜と感じた」が残っていないか。
- ♡・濁点崩壊・擬音独立行の多用・「！？」多用が混入していないか。
- 全編婉曲になっていないか（挿入・絶頂に直接語彙の芯があるか）。語彙の階調がぶれていないか。
- 核イメージが変奏されており、無関係な新造比喩が乱立していないか。
- 生活ディテールが官能に接続されているか。短文宣言が1〜2回に収まっているか。
- 記号を抑えた代わりに抽象語や同義反復が増えていないか。
