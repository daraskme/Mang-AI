# 悪役令嬢モノ — R18文体メモ

A系の本文実例の正本。規則ではなく実例で固定する。読む順は [INDEX.md](INDEX.md)。

pattern-bank は技法ラベル（`→`）と voice card を所有する。A系の呼吸・擬音・崩壊・♡は抜粋側。B系の本文は [style-corpus-b](../style-corpus-b/INDEX.md)。固有名詞、象徴フレーズ、段落の逐語コピーはしない。

## 1. 使ってよいもの／コピーしないもの

**踏襲する**

- ビート：動作 → 視点が拾う感覚（擬音含む）→ 声または身体反応 → 一行の解釈 → 次の動作
- 短文の解釈（「音が、いやらしい。」「それはもはや、“責め”だった。」）
- 擬音の独立行と、同種音の濁点・長音の段階上げ
- 三人の口調の芯と、崩れ方の差
- 高貴な場（香、天蓋、絹、政務）と行為の対比
- 射精の予兆 → 擬音 → 着弾（温度・量・受けの処理）
- 事後に「人」へ戻す（儀礼、自嘲、翌朝の甘え）

**コピーしない**

- 固有名（ヴァリス、レイナ、ミリア、フェリル、アルヴェリア、ヴァルディーン絹 等）
- 象徴フレーズ（「十年、待ちましたわ」「お口だけは、すこしだけ……自信がございますの」「ここで……処理していってくださいな」「いってらっしゃいませ、殿下」）
- 原文のダッシュ混在（`──` `——`）。新規本文は `――`（U+2015×2）と `……`
- 原文の字下げゆらぎ。新規本文は `guidelines/01-writing-rules.md` に従う

## 2. 基調

宮廷ファンタジーの標準Web官能。視点は原則三人称一元で、観察する側（多くは王子）が「技術」「構図」「計算」を読んでしまう。行為の羅列より、**誰が主導し、何を誇示し、どこで崩れるか** が場面の核。

直接語彙と文学語彙は層で変わる。

| 層 | 直接：文学 | ♡ | 擬音 |
|---|---|---|---|
| A 本編 | 55:45 前後 | 使う。受けの台詞と、頂点の擬音行 | 独立行が多い |
| B 文芸着衣 | 40:60 前後 | ほぼ使わないか文末1個 | 散文へ溶かす |
| C 衣装プレイ | 70:30 前後 | 密度が高い | 独立行＋リズム連鎖 |
| D 体格差 | 70:30 前後 | C に近い | 独立行＋包摂の動作 |

指定がなければ A。文芸主体モードなら B。衣装・ロールプレイの依頼なら C。縮小・抱き上げ・隠れて届く距離は D。A と C を1場面で混ぜない（儀礼の計算と、コスプレの軽さが相殺する）。

核イメージは場面につき一つ。よく使う源泉は、十年の準備、儀礼、香、絹、手袋、訓練、性教育という建前。宇宙・神話の大仰な像は使わない。

## 3. A系の♡配置（本節が正本）

頂点の擬音独立行へ ♡ を付ける。

```
　ちゅっ……♡
```

受けの台詞内にも付ける。攻める側の台詞と、擬音以外の地の文には付けない。濁点は絶頂付近に限る。段階を飛び級しない。B系の♡は style-corpus-b の STYLE-NOTES §3。

## 4. 三人の声

崩壊しても残す1点を先に決める。

### レイナ（高慢令嬢・「ですわ」）

- 自称は「わたくし」。語尾「ですわ／ますわ」。呼称は「殿下」から名へ落ちることがある。
- 序盤は計算と誇示。奉仕を戦い方として選ぶ。
- 中盤は語尾を残したまま実況化する（「入って……きてますの」）。
- 絶頂でひらがな化・母音伸長・濁点。残存アンカーは「わたくし」か「ですわ」。
- 事後は語尾が戻る。甘えは翌朝（006）か、儀礼の笑顔（008）で出す。

### ミリア（天真・聖女）

- 「あたし」「ヴァリスくん」。無邪気な悪戯が先、羞恥は後。
- 回復魔法・麻痺など、設定上の装置で連戦する。装置は作品にあるものだけ使う。
- 誘い受け（012）：抵抗の声と、脚が開く地の文を並走させる。抵抗を「実は合意」と地の文で上書きしない。
- わからせ（035）：カジュアル口調のまま連続絶頂で崩す。残存アンカーは名前呼び。

### フェリル（内気→ジト目）

- 「わたし」。短句。「……あったかい」（042）。
- 026 は一人称原文。新規の三人称場面では、知覚と自嘲を三人称へ移し、口調だけ残す。
- 積極化するときは証明要求（「じゃあ、証明して。身体で」041）や拗ね（064）で出す。甘えた崩壊一色にしない。
- セーラー服等の衣装は、064 のとおり羞恥とジト目で書く。通学・放課後へ接続しない。

### 観察する側（ヴァリス）

- 喘ぎは短く低い（「っ……く、あ……っ」）。♡を付けない。
- 内心は技術・構図・罪悪感。括弧書きか、短文の解釈。
- 出す直前に宣言するか、限界の知覚を1文置く。突然射精しない。

## 5. ビートと擬音

口腔の骨格ラベルは pattern-bank 2-A。実例は **001**。挿入の初手は独立行にせず散文へ織る（**042**、**017**）。同じ擬音を4行連打しない。

## 6. 射精と事後

3要素のラベルは pattern-bank §6。この作品の着地点は次。scene-card の終了状態に合うものを選ぶ。

- 儀礼復帰：008「いってらっしゃいませ」型。行為を日常の礼に畳む
- 自嘲・賢者：026。視点が自分を見る
- 翌朝の甘え：006。政務の椅子に令嬢が貼り付く
- 関係の確定：041 の口淫のあと、言葉で契約する

強制・わからせを、事後に甘いイチャイチャへ均さない。035 のあとは足が動かない側の処理を残す。

## 7. 合理化と装置

本編は「性教育」「訓練」「模型で練習した」を事前に置く。崩れるのはその建前であって、人物の芯ではない。

連戦は神聖魔法の回復・麻痺など、正典にある装置だけ使う。Skill 都合で新しい魔法を足さない。

縮小の魔法は体格差プレイの装置として使ってよい。身体は成人のまま小さくする。

## 8. 体格差プレイ

定義：身体は成人のまま、小さくなる（魔法・体質・元からの体格差）。年齢は書かない。

書くこと（動作で差を出す）

- 服が余る、手足が短くなる、抱き上げられる
- 胸に顔が埋まる、膝の上に乗る、太腿で腰を固定できる
- スカートの内側に隠れる、第三者の前でも裾の陰に収まる
- 小さな手、届く角度、挿入の深度は体格差の物理で書く
- 小さくなっても性器は成人のまま機能する（068「おちんぽばかり、大きいまま」）

読まないこと

- 原文 066–068 そのもの（抜粋を使う）
- 顔や声を子供にする、赤ちゃん扱い、○歳を出す

層は C に近い（♡多め、直接多め）。声は相手のキャラタイプを維持する（066＝ミリアの包摂、067＝レイナのですわ、068＝フェリルのジト目）。

手本：抱き上げ・フトモモは **066**、スカート内・隠れて後背は **067**、組み伏せ・膝上・騎乗は **068**。

## 9. 新規に書くときの手順

1. 層（A／B／C／D）と受け側の声を1つ決める。
2. `STYLE-NOTES.md` の該当節と、INDEX の「先に読む」1〜2件だけ読む。
3. 抜粋の固有名を役割に置き換えて呼吸だけ借りる。
4. 正書法は guidelines。♡の置き方だけはこのメモ §3。
5. 書き終わったら、抜粋の象徴フレーズが混入していないかだけ検索する。
