# pattern-bank 1/3 buildup — 場の設営〜挿入（系統と技法ラベル）

系統（A／B）と使用原則の正本。A系の本文は [style-corpus](style-corpus/INDEX.md)。B系の本文は [style-corpus-b](style-corpus-b/INDEX.md)。本ファイルは技法ラベル。固有表現は流用しない。

**全文通読はしない。** 対象シーンタイプの節と、必要な voice card だけを読む。実例内の登場人物はすべて架空の成人。

## 系統

| 系統 | 本文の正本 | ジャンル | POV |
|---|---|---|---|
| **A** | [style-corpus](style-corpus/INDEX.md) | 宮廷ファンタジー | 三人称一元 |
| **B** | [style-corpus-b](style-corpus-b/INDEX.md) | 現代・年上主導 | 一人称原文。使う時は三人称一元へ変換 |

A系の声は style-corpus の STYLE-NOTES §4。B系の声は style-corpus-b の STYLE-NOTES §4。

1シーン内でAとBを混ぜない。指定がなければA。現代・一人称受けならB。

## 使い方

1. A系：style-corpus の STYLE-NOTES と抜粋 1〜2件。本ファイルは該当節の `→` だけ。
2. B系：style-corpus-b の STYLE-NOTES と抜粋 1〜2件。本ファイルは該当節の `→` だけ。一人称は三人称一元へ変換する。A系の抜粋は読まない。
3. 声の崩壊に迷ったら `pattern-bank-voices.md` §11。
4. コピー禁止。配置と呼吸だけ踏襲する。

分冊：本ファイル（§1〜4）／`pattern-bank-climax.md`（§5〜10）／`pattern-bank-voices.md`（§11〜12）。

## 1. オープニング呼吸 — 場の設営と緊張

### 1-A. 儀礼の場の設営（A系）

読む：[extracted/001.txt](style-corpus/extracted/001.txt) 冒頭（扉・香・夜具）。

→ 空間の香り→温度→視線の順で五感を3層投入してから一拍置き、台詞へ。♡はまだ付けないか文末1個。

### 1-B. 視認する沈黙（A系）

```
　視点人物Vは報告書を閉じ、そっとペンを置いた。
　机越しに彼女を見る。汗を含んだ赤の闘衣、浮かび上がる輪郭。脚線の滑らかさ。

　そのまま立ち上がり、扉の前へと向かった。
```
→ 内心台詞を出さず、視線の対象と動作で「衝動が決壊した瞬間」を提示する台詞ゼロのオープニング。

### 1-C. 夜の室内の冒頭（B系）

読む：[extracted/01.txt](style-corpus-b/extracted/01.txt) 冒頭。

→ 環境3文→身体の拘束1文→抵抗の台詞→反応1文。三人称一元へ変換して使う。

## 2. 口腔奉仕 — 計算性と崩壊の混在

### 2-A. 計算された奉仕（A系・基本骨格）

読む：[extracted/001.txt](style-corpus/extracted/001.txt) 口腔。

→ 擬音独立行（♡可）→受けの短句→触覚2文→擬音→解釈短文。短文と長文を交互に置く。

### 2-B. 擬音の濃度上昇（A系）

読む：001 の口腔中盤。

→ 同種の擬音の濁点（ぢ）と長音（るるる）を少しずつ増やす。中盤の単独行は4〜5文間隔。

### 2-C. パイズリ＋フェラ統合（A系）

読む：[extracted/021.txt](style-corpus/extracted/021.txt)。

→ 擬音を散文に織り込み、行為のリズムと同期させる。短文ビート反復で律動を作る。

### 2-D. 即席の奉仕（B系・敬語型）

読む：[extracted/11.txt](style-corpus-b/extracted/11.txt)、わからせ側は [23.txt](style-corpus-b/extracted/23.txt)。

→ 敬語型は短句の宣言で行為に入る。状態擬音の単独行が好相性。

## 3. クンニリングス

### 3-A. 真正面の舌責め（A系）

読む：[extracted/016.txt](style-corpus/extracted/016.txt)、連続絶頂は [035.txt](style-corpus/extracted/035.txt)。

→ 動作の方向と抑制を直接書く（上から下へ、腰が逃げそうになるのを耐える）。

### 3-B. 身体の裏切りを暴く（B系）

読む：[extracted/13.txt](style-corpus-b/extracted/13.txt)。

→ 抵抗台詞→地の文で身体の反応を暴く→擬音→罪悪感。拒絶は建前でも本気でもよい。実は合意だったと読み替えない。

## 4. 挿入の初手 — 圧と粘度の言語化

### 4-A. 初夜（A系）

読む：[extracted/032.txt](style-corpus/extracted/032.txt)。儀礼の初手は 001 後半。

→ 内壁の迎え入れを短文連で書く。擬音は独立行にしない。

### 4-B. 騎乗位の主導（A系）

読む：[extracted/017.txt](style-corpus/extracted/017.txt)、着衣は [042.txt](style-corpus/extracted/042.txt)。

→ 挿入瞬間の擬音は散文織り込み。受けの台詞は実況化。

### 4-C. 体格差の包摂（B系）

読む：[extracted/03.txt](style-corpus-b/extracted/03.txt)、長身の包摂は [07.txt](style-corpus-b/extracted/07.txt)。

→ 体格差を数値または動作で具体化し、包摂感（温度＋質感＋拘束感）を三層化する。A系の縮小魔法は [066.txt](style-corpus/extracted/066.txt)。
