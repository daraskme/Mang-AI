# アーク境界監査

## 0. 読み込み範囲を決める

アーク境界の監査は、通常話の段階読み込みとは目的が違う。ここで探すのは1話の中の誤りではなく、**話をまたいで蓄積したずれ**（人物像の漂流、呼称の揺れ、伏線の散逸、時系列の矛盾）である。話ごとに小さく読むと、まさにこの種のずれが見えない。

まず総量を測る。

```bash
bash scripts/chars.sh work/drafts/*.txt
python3 scripts/state_check.py
```

### 全話横断モード（既定）

**空白除外の総文字数が30万字以下なら、全話の本文と台帳を一度に読み込んで横断照合する。** 日本語は1文字あたり概ね1トークン強で、この規模なら台帳、設計資料、推論の余地を含めても現行のコンテキスト長に収まる。分割して読むと横断的なずれを見落とすため、収まる限りは分割しない。

読み込む順序は次のとおり。

1. `work/plot.md` 全文（伏線台帳、キャラアーク表、章一覧）
2. `work/pov-plan.md` 全文（視点割当と情報格差マトリクス）
3. 全キャラシート
4. `world-bible/core/` と `world-bible/log/canon-log.md`
5. 全話の `work/drafts/episode*.txt`（話数順）
6. `work/continuity/episodes/*.md`（話数順）

### アーク単位モード

総文字数が30万字を超える場合は、次の範囲に絞る。単純な直近N話ではなく、**問いから逆算して**必要な話を選ぶ。

- 対象アークの全話
- 伏線台帳で「設置済み・未回収」の伏線について、その設置話
- 監査対象の人物が大きく変化した話（キャラアーク表の中継点）
- 前回の監査記録 `work/continuity/checkpoints/`

この場合、範囲外の話を読んでいないことを監査結果へ明記する。読んでいない範囲について「矛盾なし」と書かない。

## 正典

- 年齢、外見、能力、階級、呼称に矛盾がないか
- 日付、移動時間、負傷回復、季節が成立するか
- 所持品、衣服、武器、金銭、同行者の位置が連続しているか

## キャラクター

- 主要人物ごとに、アーク開始時から価値判断または関係が変化したか
- 変化が台詞で宣言されるだけでなく、選択として現れたか
- 全員が同じ語彙、比喩、結論へ収束していないか

## 構造

- 主筋と副筋のどちらも停滞していないか
- 設置した伏線に回収予定があるか
- 同じ機能の場面、同じ対立、同じ慰めを反復していないか
- 読者への約束を小口で返済しているか

## 文体

- 全話横断モードでは、話をまたいで頻出する書き出し、文末、身体反応、比喩を集計する。アーク単位モードでは直近5話で集計する
- 視点人物ごとの地の文の声が、pov-plan の書き分けサマリから漂流していないか
- `python3 scripts/cliche_check.py <話>` のリズム参考値（文長CV・同一文末連続・長断定連続）を話ごとに出し、平坦化が進行していないか推移で見る。クラスタ警告は話をまたぐ機能反復（毎話同じ身体反応・所作・締め）として集計する
- 抽象動詞で感情や場面転換を処理していないか
- 説明密度と会話密度が単調になっていないか
- 人間らしさを誤字ではなく、人物固有の偏りと具体性で作れているか

## 出力

監査結果は `work/continuity/checkpoints/arc-<ID>.md` に保存する。

- 実施したモード（全話横断／アーク単位）と、実際に読んだ話の範囲
- 継続してよい点
- 次アークで解消する問題
- 正典の矛盾
- 未回収伏線
- 反復表現
- 次アークまたは次の監査まで追跡する指標
