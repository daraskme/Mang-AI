# 小説・台詞の文体診断

文章の出自ではなく、読者が困る箇所と改稿の必要性を判断する。診断だけの依頼では原文を変更しない。問題がない箇所を数合わせで挙げない。

## 資料とモード

- **通常診断**：単発の質問・局所・一話を対象に、下記手順で確認する。
- **Full Detect**：全編・アーク・話またぎの反復が対象のとき、[detection-checklist.md](references/detection-checklist.md)を使う。対象全体を読めないときは確認範囲を明示する。
- **外部・総合レビュー**：リポジトリ外の作品や、構造・人物・生活まで含む依頼では[external-review.md](references/external-review.md)。
- **改稿への引継ぎ**：必要時のみ[handoff-contract.md](references/handoff-contract.md)。小さな直接修正に大きな引継ぎ票を作らない。

共通の正本は、同梱またはプロジェクトの`guidelines/02-narrative-craft.md` §2-8（地の文の骨格）と §4-10（台詞）、`guidelines/05-ai-guardrails.md` §3-4・§3-5（表現の採否。書き換えの不変は §3-4）。作品ルートまたは添付資料から探す。未提供なら下記の中核基準で進める。他のSkillやscriptsの存在を前提にしない。

## 中核基準

- 原文・ユーザー指定・作品正典を、一般的な文体の好みより優先する。
- 事実として必要な行為者・対象と、意図的な心理の余白を分ける。
- 能動・受身・使役・授受を区別し、述語の主語を全て同じ行為者へまとめない。
- 文体の所見には該当箇所と読者への具体的な影響を添える。単語、頻度、型の存在だけで欠点にしない。
- 比喩・反復・短い応答・感情語・過去形・完全な文にも機能がある。全て削る／崩す基準を設けない。
- AI生成確率、著者断定、モデルの内部原因、投稿量からの推測を出さない。

## 手順

1. **範囲と目的を固定する。** 本文、台詞、絵、設定、あらすじのうち何があるか確認する。不足情報を新造しない。依頼が局所なら全話監査へ拡大しない。
2. **意味の誤りを先に見る。** 台詞ごとに話者・相手・各動詞の行為者と対象・発話目的を確認する。完成した表現から読める関係と、元の場面を比較する。必要な省略対象が場面から解けない場合は具体的な別解を示す。
3. **説明口調を切り分ける。** 修正のための役割説明や執筆依頼が台詞へ混入していないか見る。説明・確認・独り言・皮肉などとして人物が言う理由があれば残せる。全ての台詞を一意の説明文へ還元しない。
4. **声・反復・装飾を見る。** 人物間の均一化、同じ意味の二重説明、場面と関係のない比喩、同じ締めの密集を確認する。地の文では、概念が意志を持って動く文、ラベルだけの前置き、中身のない否定対比、何も指さない質感語が、誰の行為かを隠していないかを見る。判定は 02 §2-8 と 05 §3-5。語の存在だけでは欠点にしない。初見の語句にも意味と文脈から対応し、禁止語リストだけで診断しない。
5. **必要な周辺事実を照合する。** 提供された正典・視点・時系列との矛盾に気づいたら文体所見とは分けて報告する。利用可能なvalidate-episode等があれば接続し、無ければ現在の担当で必要な確認を行う。
6. **誤検出を除く。** 意図された反復、慣用、幻想設定、作中引用、乾いた文体、人物の嘘・誤認を確認する。文脈は固定の前後二行ではなく、読者に提示済みの場面から取る。
7. **重要度を付ける。** 高＝意味の反転・行為者の誤り・重大な欠落。中＝説明過多・反復・声の均一化が読み味を損なう。低＝好みや局所的な表記。同じ原因の指摘をまとめる。根拠が不足するものは要確認とする。

表記・文字種を検査する既存スクリプトがある場合は、実装と使い方を確認して結果を利用する。無い場合は目視で確認し、実行済みと報告しない。機械警告の種類だけで改稿優先度を決めない。

## 出力

- 診断範囲と主な結果を短く示す。
- 主要所見を必要な件数だけ「箇所／何が読めるか／場面との不一致または読者影響／重要度／修正方針」で示す。
- 問題がない自然な省略や、残すべき声があれば短く示す。
- 改稿依頼がある場合は、対象・不変条件・重要所見をhumanize-ai-writingへ渡す。同Skillが利用できない場合も、修正を依頼済みなら上記の不変条件を保って続ける。

全文監査を依頼された場合は対象範囲の全台詞を確認する。局所診断では当該箇所と解釈に必要な文脈でよい。重大な所見の根拠と、誤検出の可能性を確認できたら終了する。0〜100の疑似確率や定型的な「AIらしさ」の総合点は出さない。
