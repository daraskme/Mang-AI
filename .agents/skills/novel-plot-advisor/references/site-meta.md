# 投稿サイト比較の検証フレーム

小説家になろう、カクヨム、アルファポリスの仕様・読者構成・ランキング傾向は変化する。このファイルは固定データ表ではなく、相談時に比較を作り直すための手順を正本とする。

## 1. 根拠の区分

- **公式**：ヘルプ、ランキングページ、利用規約、コンテスト要項、運営発表
- **観測**：取得日を明記したランキング標本
- **第三者実測**：分析サービスや作者の継続測定
- **仮説**：非公開アルゴリズム、読者行動、書籍化との因果についての推定

重要な意思決定では公式情報を最優先し、観測・実測・仮説を混同しない。

## 2. 比較前に確認する項目

各サイトについて、相談時点の次を調べる。

1. 対象ジャンルと作品長のランキング区分
2. ランキングに公式明記された評価指標
3. タイトル、あらすじ、タグ、R18、生成AI利用表示の仕様
4. 収益化・出版申請・スカウト・コンテストの条件
5. 対象ジャンルの最新ランキング構成と更新中／完結の比率
6. 新作が発見される導線
7. 複数投稿・応募中作品に関する制約

数値には出典URL、公開日または取得日、標本数を付ける。過去のPV規模、利用者属性、ボーダー、換金単価、出版申請閾値を現在値として再利用しない。

## 3. サイトごとの確認先

### 小説家になろう

- 公式ランキング・ヘルプで、評価方式、期間、ジャンル区分を確認する
- 最新ランキングを短編／長編、男性向け／女性向けの企画目的に沿って標本化する
- コンテスト、外部賞、R18系列、複数応募の条件は当該公式要項で確認する

「なろうは男性向け」「日間は特定型だけ」等の通説を前提にせず、対象時点のランキングで検証する。

### カクヨム

- 公式ランキング、ヘルプ、お知らせ、当該コンテスト要項を確認する
- 第三者データは運営主体と取得日を明記する
- 過去の週間ボーダーや作者フォロワー数を、現在の撤退基準へ使わない

### アルファポリス

- 公式ヘルプで24hポイント、HOTランキング、投稿インセンティブ、出版申請の現行条件を確認する
- Webコンテンツ大賞は開催回ごとの応募条件・選考方式を確認する
- 女性向け／男性向けの強弱は、対象ジャンルの最新ランキング標本で検証する

収益や出版可能性を「確実」と表現しない。

## 4. 選定マトリクス

相談では、作品ごとに以下を比較する。

| 軸 | 確認する問い |
|---|---|
| 読者適合 | 最新ランキングに近い読後体験・尺の作品が存在するか |
| 発見導線 | 新着、ランキング、フォロー、企画、検索のどれが入口になるか |
| 継続可能性 | 推奨更新頻度を品質と生活の範囲で維持できるか |
| 収益・出版 | 現行条件が目的に合うか。選考・換金を保証と誤解していないか |
| 作品制約 | R18、生成AI、独占、重複投稿、応募中制約に適合するか |
| 検証容易性 | 公開後に何を測れば仮説を更新できるか |

第一候補を一つに決め打ちせず、候補ごとの利点・代償・未確認事項を示す。複数サイト展開の順序も固定せず、規約、既存読者、改稿コスト、応募条件から決める。

## 5. 序盤・文字数・更新頻度

「3話切り」「1話2,000〜3,000字」「毎日更新」等は、ジャンルと時点に依存する運用仮説である。最新上位群と対象作品の読了データを見て調整する。

- 報酬駆動型：早期の小さな前進が有効になりやすい
- ミステリー／ホラー：問い、危険、違和感の強化が報酬になり得る
- 文芸／没入型：声、情緒、具体的な変化で継続理由を作る
- 短編：完結条件と一覧表示区分を公式で確認する

作品目的と読者への約束を優先し、固定話数・固定字数を合否基準にしない。
