# テンプレ類型カタログ（2026年7月調査時点）

各型を「快感原理（読者が期待する感情）／観測されたビート／序盤の約束／失敗リスク／調査時点の現況」で整理する。**主力・飽和・縮小などの表示は2026年7月の歴史的仮説であり、現在判定ではない。** 投稿先選定や市場性の判断では、経過期間にかかわらず最新ランキングと公式情報を確認する。ビートや地雷は必須条件・禁止事項ではなく、対象読者と作品意図を確かめる比較材料として使う。

## 0. 調査時点の市場仮説（現在値として使わない）

- 2026年7月の観測では、なろう総合日間に女性向け異世界恋愛の短編が多く、累計上位には長編異世界転生が見られた。期間、ランキング区分、ジャンルで構成が異なる可能性を示す標本であり、「完全に分離」「支配」と一般化しない。
- 投稿先ごとの読者適合について複数の通説があるが、性別、尺、収益目的だけで主戦場を決めない。`site-meta.md` の手順で、最新の公式仕様と対象ジャンルの標本を取り直す。
- **テンプレは読者との契約**。タイトル・あらすじで約束した型から序盤で逸れると切られる。「ずらし」は契約違反にならない範囲で行う（§3）。

## 1. 男性向け類型

### 現代ダンジョン×配信【2026-07観測：頻出】
- 快感原理：数字（再生数・ランキング・ステータス）と観客のリアクションで主人公の価値がリアルタイムに可視化される。「無自覚にすごい」を他人の目が代弁する。
- 観測されたビート：①平凡な立場の提示 → ②配信中の異常値発生 → ③コメント欄・切り抜き・SNSの反応 → ④数字の初動 → ⑤本人との温度差 → ⑥外部勢力の接触。採用順や有無は企画の因果で決める。
- 序盤の約束：「この配信がバズる瞬間を一緒に見る」。一般的な短い連載話なら、序盤数話で数字の小さな変化を見せると約束が伝わりやすい。
- 地雷：配信画面・コメントの再現が長すぎて話が進まない／視聴者リアクションが単調（「すげえ」の連呼）／主人公の実力の種明かしを引っ張りすぎる。
- 現況（2026-07観測）：複数サイトの標本で頻出。書籍化等との因果や現在の適地は別途確認する。

### 悪役貴族・悪役転生（男性向け）【2026-07観測：頻出】
- 快感原理：断罪される側の知識を持って運命に抗う戦略性＋「悪役なのに慕われる」ギャップ。女性向け悪役令嬢の男性向け翻案。
- 観測されたビート：破滅する未来の認知、回避行動、原作側との接触、評価の変化、運命の分岐。必要なものだけ選ぶ。
- 序盤の約束：「破滅フラグを踏み折る快感」＋「悪役ムーブが結果的に人望を集める勘違いコメディ」のどちらを主にするか早期に明示。
- 地雷：原作ゲーム設定の説明が長い／破滅回避の緊張が序盤で消える。
- 現況（2026-07観測）：調査標本で頻出した型の一つ。

### 追放ざまぁ・「もう遅い」【2026-07観測：競合作が多い】
- 快感原理：正当評価の回復。理不尽に切り捨てられた自分の価値を、追放した側の没落と新天地での評価が同時に証明する。
- 観測されたビート：追放、新天地での価値の兆し、古巣への影響、再接触、評価の決着。理由の数や順序は固定しない。
- 序盤の約束：第1話内に「報われる予感の灯り」。追放シーン自体を長く書かない（reader-promise-framework §2）。
- 地雷：追放パートの引き延ばし／悪役の暴言の同義反復／ざまぁ到達前の読者疲弊。古参読者ほど「より練度の高いざまぁ」を要求するため、生半可な後出しでは満足しない。
- 現況（2026-07観測）：類似入口の作品が多かった。採用時は、読者への返済方法と人物固有の因果を比較する。

### スローライフ・領地経営・辺境開拓【2026-07観測：複数サイトで確認】
- 快感原理：ストレスからの解放と、コツコツ積み上げが正当に報われる箱庭感。戦闘の勝利より「生活が良くなる」実感。
- 観測されたビート：都会・組織からの離脱、拠点の確保、生産・改良、外部評価、共同体の変化。
- 序盤の約束：「ここでは頑張りがちゃんと報われる」。数字（収穫量・人口・売上）の微増を定期的に見せる。
- 地雷：本当に何も起きない（起伏ゼロ）／内政の数値説明が講義化する。
- 現況（2026-07観測）：複数サイトで確認した。現在のサイト適合は最新標本で再検証する。

### 無自覚最強・勘違い系【2026-07観測：継続出現】
- 快感原理：情報の非対称。読者だけが主人公の異常性を知っており、周囲の過大/過小評価との温度差がコメディと爽快感を生む。
- 観測されたビート：本人基準では普通の行動、周囲との評価差、誤解の波及、本人側の日常。反応役の多用で水増ししない。
- 地雷：温度差の演出が1パターン化（毎回同じ驚き方）／無自覚が不自然になるレベルの鈍感。
- 現況（2026-07観測）：単独型と複合型の両方を確認した。

### VRMMO・ゲーム世界【2026-07観測：固定層仮説】
- 快感原理：システムの隙を突く攻略の知的快感＋ランキング・レアの収集欲。
- 地雷：ゲームシステム説明の講義化／現実パートの空洞化。
- 現況（2026-07観測）：固定読者層がいるという仮説。現在の規模と複合要素は再測定する。

### ハーレム×激重感情【2026-07カクヨム長編標本で観測】
- 快感原理：複数ヒロインの「重さ」が主人公の価値を証明する。ラブコメの糖度に執着・独占の緊張を混ぜる。
- 地雷：ヒロインの書き分け不足（口調・重さの質が同じ）。

## 2. 女性向け類型

### 婚約破棄×悪役令嬢×ざまぁ（短編）【2026-07観測：上位で頻出】
- 快感原理：理不尽に虐げられた側の無血の完全勝利。「虐げられ→静かに離脱→真価発揮→加害者が勝手に没落」を主人公の代償ゼロで完走する。
- 観測されたビート：理不尽の提示、離脱の選択、価値の可視化、加害側への結果、新天地での変化。主人公の反応や因果を固定台詞へ揃えない。
- 序盤の約束：タイトルの時点でざまぁ成立を保証する（因果関係型タイトル「〜と言われたので、〜しました」）。**結末の安全保障が購買理由**なので、あらすじで裏切らない。
- 失敗リスクの仮説：入口で約束した解放や正当評価が長く返らない／主人公の責任と被害の整理が曖昧で、狙った読後感とずれる。主人公を無謬にすることや対立者への共感を禁止しない。
- 現況（2026-07観測）：なろう日間の対象標本で頻出した。市場全体の最大規模や参入障壁は、この標本だけから断定しない。

### 白い結婚・離縁・やり直し（二度目の人生）【2026-07観測：頻出】
- 快感原理：損切りの爽快感と「本当の価値をわかってくれる人」への乗り換え。ざまぁの亜種だが、復讐より「私はもう自由」の解放感が主成分。
- 観測されたビート：冷遇された関係、離脱の決断、残された側の認識変化、新たな関係、過去との決別。
- 失敗リスクの仮説：損切りと解放を約束した作品で、未練の反復だけが続いて状態が動かない。葛藤や未練そのものは禁止しない。
- 現況（2026-07観測）：対象の日間上位で複数のバリエーションを確認した。

### 悪役令嬢（長編・変化球）【2026-07観測】
- 快感原理：断罪回避の戦略性＋「本来敵のはずの人々に愛される」逆転。長編では internal な成長と関係構築が主成分になる。
- 現況（2026-07観測）：職業、子育て、経営、ループ等との複合例を確認した。書籍化との因果や現在の標準要素は別途検証する。
- 地雷：乙女ゲーム設定の説明過多／ヒロイン（原作主人公）を安易な悪役にする使い古し。

### 溺愛・執着【2026-07観測：継続出現】
- 快感原理：無条件の全肯定。「選ばれ、守られ、疑われない」安心感。ヒーローの感情の重さがヒロインの価値の証明。
- 観測されたビート：傷や欠落の提示、相手からの発見、関係を揺らす誤解、言葉と行動による承認、外部対立への応答。人物の主体性と安全性を企画ごとに確認する。
- 地雷：ヒーローの執着が恐怖に振れすぎる（女性向けR18を除く一般作では「重いが安全」のライン管理が命）。

### 聖女・追放聖女【2026-07観測：継続出現】
- 快感原理：女性向けざまぁ＋「本物は私だった」の証明。追放ざまぁの女性向け翻案で、癒し・加護など非戦闘の力が価値の源泉。
- 地雷：偽聖女側の描写が薄く勧善懲悪が単調化。

### 後宮・中華風【2026-07観測】
- 快感原理：閉鎖空間の権謀＋身分差の寵愛＋謎解き（「薬屋」効果で推理×後宮が伸長）。
- 現況（2026-07観測）：Webランキング全体を代表する裏付けは不足。媒体適合と複合要素を最新標本で確認する。

### もふもふ・ほのぼの・子育て【2026-07観測：固定層仮説】
- 快感原理：無害な癒しと家族的承認。「安心して戻れる場所」を約束する型。
- 地雷：事件性ゼロが続くと数字が伸びない。小さな困りごと→即解決のリズムを保つ。

## 3. テンプレ×ずらしの調合指針

1. 中心となる読後体験を特定する。既存類型から外す場合は、代わりに何を約束するか明示する。
2. 王道と差別化の比率を固定しない。タイトル、あらすじ、冒頭で同じ期待が伝わるかを基準にする。
3. 差別化要素は、入口で伝える必要があるか、読後に発見させる価値なのかを分ける。すべてをタイトルへ詰め込まない。
4. 掛け合わせ数ではなく、主従関係と読者が期待する報酬の整合で判断する。
5. 競争が激しい型では、報酬の装置、人物関係、舞台、語り口のどこで比較可能な差を作るか決める。

## 4. 企画診断への適用

企画を受けたら：①近い類型は何か → ②期待される感情を言語化できるか → ③観測ビートのうち採用・不採用と代替報酬は何か → ④想定読者とのずれは何か → ⑤最新の現況と投稿先の適合を検証したか → ⑥固有の因果はどこか、の順で照合する。手順の詳細は consultation-playbook.md。
