# 会話と含意

会話主体モード、および混合モードの会話を組み立てるための参照。台詞を新しく書く・短くする直前は `guidelines/02-narrative-craft.md` §4-10。話者の口調と禁則は character-sheet、括弧と改行は `guidelines/01-writing-rules.md`。

## 1. 会話の機能

一つの応酬で、少なくとも何かを動かす。

- 要求を出す、拒む、条件を変える
- 情報を渡す、隠す、誤解する
- 距離を縮める、傷つける、立場を逆転する
- 次の行動を決める

既知情報の復唱が、確認・慰め・儀礼・挑発として機能するなら残す（02 §4-10、§5-1）。行動も関係も動かない同義反復だけを見直す。説明が必要なら、その人物が今ここで話す理由を作る。

## 2. 話者を判別させる

話者名を消すことを目標にしない。次を自然な順で使う。

1. character-sheetに定着した一人称、呼称、語彙、判断の癖
2. 質問と返答、反論と再反論などの応答連鎖
3. 話者の動作、視線、位置を示す短い地の文
4. 混乱が残る場合の「と彼は言った」等の透明な発話タグ

二人の短い応酬では流れを生かす。三人以上では、割り込み、話題転換、沈黙の後にアンカーを置く。無理に役割語や決め台詞を足して区別しない。

## 3. 事実は明瞭に、感情は含意で

ハイコンテクストは必要情報の欠落ではない。読者が場面を理解するための事実は示し、人物が言いたくない感情や意図を行動と選択に残す。

- 表向きの言葉と行動をずらす。
- 答えるべき問いに答えず、別の具体物へ触れる。
- 相手だけが意味を知る呼称や過去の約束を使う。ただし正典に存在する場合に限る。
- 沈黙の後に、状況を変える動作を置く。

「彼女は悲しんでいた」の代わりに必ず無言にする、といった置換規則にはしない。場面の意味が伝わる手段を選ぶ。

## 4. 言い切らせない

人物が途中で言葉を変える、飲み込む、相手に遮られることで、迷いと関係性を同時に見せられる。

- 言い直し：本音に近づく、または遠ざかる。
- 中断：身体反応や相手の行動が発話を止める。
- 後置：先に結論だけ言い、理由を相手の反応後に出す。

三点リーダやダッシュの多用で代用しない。句読法はguidelinesに従い、言葉が止まった原因を場面内に置く。

## 5. 地の文で接地する

会話主体でも、読者が次を見失わないだけの地の文を残す。

- 誰がどこにいて、何へ手を伸ばせるか
- 発話が相手の身体や行動をどう変えたか
- 物や環境が会話へ与える圧力
- 応酬の結果、何が決まったか

「頷いた」「首を振った」だけを交互に置かず、現在の目的に関係する動作を選ぶ。

## 6. 間と反復

連続する会話は詰める。空行は沈黙、話題の転換、認識、決定、余韻など、意味の境界にだけ使う。空行の数で感情の強度を機械的に表さない。

反復は、儀礼、安心、恐怖、口癖、天丼、意味の反転のいずれでも機能し得る。意味が毎回変わることを必須にしない（02 §5-1）。作品トーンと人物関係に必要なときだけ使う。

## 7. 会話主体の確認

- 台詞を読み返さなくても話者を追えるか。
- 台詞を抜き出したとき、要求、抵抗、変化があるか。
- 地の文を抜き出したとき、位置と結果が分かるか。
- 読者が知るべき事実まで省略していないか。
- 空行と短文が均一な型になっていないか。
