# 動作・戦闘・設定説明

戦闘、追跡、作業、魔法やゲームシステムの説明がある場面で読む。設定の正本はworld-bibleであり、本ファイルからルールを追加しない。

## 1. 動作を因果でつなぐ

動作列は、映像の細かな再生ではなく、視点人物が判断を更新する因果として書く。

1. 目標または脅威
2. 判断に必要な知覚
3. 選択
4. 実行
5. 結果と次の圧力

すべてを毎回明記する必要はない。位置関係や結果が曖昧になった箇所だけ補う。技名、身体部位、効果音の列挙で速度を作ろうとしない。

## 2. 戦闘の視点

視点人物が同時に把握できる情報量を越えない。

- ベテランは脅威を分類し、優先順位で見る。
- 未熟な人物は見落としや誤認をする。
- 負傷や疲労は、判断、速度、可動域に具体的な制限を与える。
- 仲間の内面は読まず、声、合図、動きから意図を取る。

結果が確定する前に勝敗を作者が説明しない。命中、失敗、代償を観測可能な変化として示す。

## 3. 設定を出すタイミング

読者が現在の選択を理解するために必要になった時点で出す。初出だから全仕様を説明する、という順序にはしない。

優先する情報は次のとおり。

1. その場で見える効果
2. 人物が取れる、または取れない行動
3. 直近の代償や危険
4. 後の判断に必要な制約

歴史、分類、例外の全体像は、現在の場面に必要な分だけに分ける。視点人物が知らない規則は説明しない。

## 4. 説明を行動へ統合する

- 使用：道具や能力を実際に使い、効果と制約を見せる。
- 誤解：人物の誤った前提が失敗を生み、正しい規則の一部が分かる。
- 交渉：規則の解釈が利害や条件を変える。
- 代償：便利さの直後に、消耗、時間、危険、社会的な結果を示す。
- 比較：視点人物が既知の仕組みとの差だけを捉える。

会話で説明する場合も、聞き手が知りたい理由、話し手が教える理由、説明後に変わる行動を置く。

## 5. 固有語

固有語はworld-bibleの表記をそのまま使う。読みや表記の規則は `guidelines/01-writing-rules.md` に従い、本Skill独自のルビ記法やUI記号を作らない。

初出では文脈だけで意味が取れるようにし、直後の同義語説明を重ねすぎない。覚える必要のない分類名は普通名詞で済ませる。

## 6. 確認

- 誰が何を見て判断したか追えるか。
- 動作の前後で位置、所持品、負傷が矛盾していないか。
- 説明を削ったとき現在の選択が理解不能になるか。ならない説明は後へ送れないか。
- 設定が選択、誤解、代償のどれかとして場面に働いているか。
- 技法のために正典外の能力、制約、専門語を追加していないか。
