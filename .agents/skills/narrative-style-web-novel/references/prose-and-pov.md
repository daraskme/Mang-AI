# 地の文と視点

地の文主体モード、および混合モードの地の文を組み立てるための参照。視点規則の正本は `guidelines/02-narrative-craft.md` とし、ここでは実現方法だけを扱う。

## 1. 視点フィルター

地の文は、中立カメラの記録ではなく視点人物が拾った世界である。同じ対象でも、次の順で人物差を作る。

1. 何に先に気づくか
2. 何と比較するか
3. 何を危険、有用、懐かしいと判断するか
4. その判断から何をするか

感情名を避けること自体を目的にしない。身体反応や行動だけで意味が曖昧になる場合は、視点人物が自覚できる範囲で感情を短く名指してよい。

## 2. 意味段落

一段落は、一つの知覚、判断、動作、話題を中心にまとめる。文数は固定しない。

- 速度を上げる：動作と結果を近づけ、短い段落を混ぜる。
- 余韻を置く：重要な認識または決定を独立段落にする。
- 情景を立てる：列挙ではなく、人物が次に取る行動に関係する細部を選ぶ。
- 内省を深める：現在の刺激から入り、記憶や判断を経て現在の選択へ戻す。

すべてを一文段落にする、段落ごとに同じ長さへ揃える、空行を機械的に挟む、といった均一化は避ける。

## 3. 他者の内面を越境しない

他人の気持ちは、視点人物が観測できるものと推測の形で書く。

- 越境：彼女は内心で勝利を確信した。
- 観測：彼女は返事を待たず、鞄の留め金を閉じた。
- 推測：勝ったつもりらしい、と彼には見えた。

「ように見えた」「らしい」は、推測であることが必要な場面だけに使う。断定を曖昧語へ置換する癖にはしない。

章末だけ全知語りへ切り替える例外はない。視点外の情報が必要なら、pov-planに沿った別場面を設計する。

## 4. 感覚と比喩

五感は全種類を埋めるチェック項目ではない。その人物が現在の目的に照らして拾う感覚を選ぶ。

- 戦闘中：距離、足場、音の方向、痛み、呼吸
- 交渉中：声の間、視線、手元、退路、周囲の反応
- 日常：手触り、匂い、温度、生活上の癖

比喩は視点人物の職業、文化、過去、価値観から選ぶ。比較対象を知らない人物に作者都合の比喩を使わせない。一つの像が効いている間は、別の像を重ねて同じ感情を言い直さない。

残すか削るかは `guidelines/05-ai-guardrails.md` §3-4・§3-5。直叙でも同じ事実が伝わる、という理由だけでは外さない。身体部位や無生物が主語であることだけでは戻さない。本数の上限は置かない。地の文を書き始める前の骨格は `guidelines/02-narrative-craft.md` §2-8。

## 5. 人物の声

台詞だけでなく、地の文の語彙選択と注意の向け方にもcharacter-sheetを反映する。ただし、一人称や口調をそのまま地の文へ貼り付けず、対人敬称も固有名へ付けない。地の文の固有名は `guidelines/02-narrative-craft.md` の中立呼称に固定する。

- 慎重な人物：可能性を分け、先に損失を測る。
- 実務家：物の状態、手順、使い道に気づく。
- 衝動的な人物：判断より身体が先に動き、後から理由を作る。

これらは例であり、人物像の正本ではない。シートにない性格や口癖は追加しない。
