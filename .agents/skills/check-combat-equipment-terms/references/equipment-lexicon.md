# 戦闘・装備用語の構造基準

この資料は、語を時代・地域を超えた唯一の正解へ固定する辞書ではない。本文中の物体、部位、状態、動作が同じ像を結ぶための監査基準である。作品固有の構造が正典に定義されている場合は正典を優先し、差が読者に伝わるようにする。

## 1. 共通原則

### 全体・部位・状態を分ける

- 全体名：剣、槍、弓、弩、鎧
- 部位名：柄、柄巻き、刀身、穂、弦、留め具、籠手
- 収納・保護具：鞘、柄袋、弓袋、矢筒
- 状態：抜いた、掛けた、収めた、張った、つがえた、破損した

部位の摩耗から人物の技能を読むなら、手が触れる部位、手入れが現れる部位、収納時だけ使う保護具を混同しない。収納具が付いたまま使用できるか、使用後に同じ状態へ戻したかも確認する。

### 形式が未確定なら形式依存語を使わない

同じ「剣」でも片刃・両刃、鍔の有無、柄構造は異なる。「刀身」「刃」「柄」のような共通部位で足りる場面へ、峰、棟、鎬、目釘などを飾りとして足さない。専門語は、人物の判断か動作を一段具体化するときだけ使う。

### 助数詞は本文の意味を優先する

史料・流派・地域で助数詞が複数ある物は多い。迷う場合は「一振りの剣」「一本の矢」「二人の射手」のように誤読の少ない形を選ぶ。独特な数え方を人物の声として使う場合は、地の文の物理像と混ぜない。

## 2. 刀剣と携行具

| 語 | 指すもの | 典型的な動作 | 誤用注意 |
|---|---|---|---|
| 柄 | 手で握る取っ手部分。文脈により柄全体または握りを指す | 握る、手を掛ける | 柄袋や鞘と交換しない |
| 柄巻き | 柄へ巻いた紐・革などの外装 | 摩耗する、巻き直す、締める | 剣をここから「抜く」「納める」と書かない |
| 柄袋 | 収納・携行時に柄へ被せる保護袋 | 被せる、外す、鍔元で結ぶ | 使用中の握りではない。掛けたまま柄を握らない |
| 鞘 | 刀身を収める容器 | 鞘から抜く、鞘へ納める | 柄を収める袋ではない |
| 鍔 | 柄と刀身の境の防護部 | 鍔へ指を掛ける、鍔元で結ぶ | 握りそのものではない |
| 刀身 | 柄以外の金属部全体 | 点検する、研ぐ、歪む | 刃先だけを指すとは限らない |
| 刃 | 切断に使う縁 | 欠ける、潰れる | 両刃か片刃かを正典と合わせる |
| 峰・棟 | 主に片刃刀剣の刃と反対側 | 打つ、傷を調べる | 両刃の一般剣へ自動適用しない |

技能を見抜く手掛かりは、柄巻きの締まりと摩耗、柄袋を外して納剣時だけ掛け直す習慣、刃・刀身の手入れ、鞘と吊り具の扱いなどに置ける。「柄袋が手に馴染んで艶を帯びる」を握りの使用痕として書くと、保護袋と柄を混同する。

「返す刀」は、第一動作から続けて刀を反転・転用する慣用表現として使える。実物の部位名ではない。

## 3. 弓・矢・弓袋

| 語 | 指すもの／状態 | 動作 | 誤用注意 |
|---|---|---|---|
| 弓 | 弓幹と弦からなる射具 | 張る、構える、引く | 収納中か使用可能状態かを区別する |
| 弦 | 矢へ力を渡す紐 | 張る、掛ける、引く、放す | 「弦を起こす」は機構を示さない |
| 矢 | 弦につがえて射る飛翔体 | つがえる、引き絞る、放つ | 弓と矢の助数詞を混ぜない |
| 矢筒 | 矢を携行する容器 | 矢を抜く、収める | 弓袋と交換しない |
| 弓袋 | 弓を収納・保護する袋 | 弓を出す、収める、口を結ぶ | 袋に収めたまま弦を操作・射撃しない |
| 空弦 | 矢をつがえずに弦を放つこと | 空弦を引く／放つ | 単なる弦のつま弾きや「空の弦」の意味ではない。弓を傷め得る |

弓は、弓袋から出し、作品設定上必要なら弦を掛け、矢をつがえて射る。弓袋の中へ手を入れて弦だけを弾く描写は、袋の構造を特別に定義しない限り成立しにくい。

弓を数えるなら「一張、二張」が誤読を生みにくい。「丁・挺」が使われる文脈もあるため、それ自体を一律誤用とはしないが、「二丁弓」のように人員・隊形・固有語と混同しやすい連結は避ける。矢は通常「一本」、射手は「一人」とする。

一本の材から作る弓を表したい場合、「一本の木から削り出した弓」と書けば構造が明確になる。「丸木弓」「単材弓」などは作品の参照文化と既出語に合わせる。「一枚弓」は意味が共有されにくいため、定義なしでは警告候補とする。

## 4. 弩・クロスボウ

弩は、弓部、弦、台・銃床に相当する本体、弦を保持して解放する機構を持つ。射撃前には弦を後方へ引き、留め具へ掛け、矢・ボルトを載せる。

- 手で引ける：弦を引く、弦を留め具へ掛ける
- 足掛けや腰鉤を使う：足を掛けて引く、鉤で引き上げる
- 巻上機を使う：巻き上げる、弦を固定する

「弦を起こす」だけでは、どこへ引いて何に保持したかが分からない。機構が場面の判断に関わるなら、使用者の手足と留め具を具体化する。装填後、発射前、発射後を同じ状態として扱わない。

## 5. 槍・長柄武器

| 語 | 指すもの | 注意 |
|---|---|---|
| 槍 | 穂と柄を組んだ武器全体 | 完成品か分解携行かを明示する |
| 穂 | 柄へ取り付ける刃・頭部 | 部品として所持するなら柄の所在も確認する |
| 穂先 | 穂の先端。一般文では穂全体を指すこともある | 精密な損傷描写では穂と先端を分ける |
| 柄 | 長い木製部など | 刀剣の柄と同じ字でも寸法・機能が異なる |
| 石突き | 柄の末端の補強部 | 穂先と反対側。打撃・接地にも使う |

所持品一覧で「槍の穂」だけを数え、後の場面で完成した槍を説明なく使わせない。分解携行なら、柄を現地調達する、組み立てる、予備の柄を持つなど遷移を置く。

## 6. 防具・装具

防具名は地域・時代・翻訳で範囲が揺れるため、名称より装着部位を正典化する。

- 籠手：腕から手を守る防具の総称として使われやすい。作品によって前腕中心、手甲込みなど範囲が異なる。
- 手甲：手の甲を守る部品・防具。籠手の一部として扱う場合と別装備にする場合がある。
- 腕甲・前腕当て：前腕を守ることを普通語で明確にしたいときに使える。
- 胸当て：胴前面を守る防具。背面や腹部まで覆うかは形状を定義する。
- 帯金・金具：固定具か補強材かを動作で区別する。

同一人物の同一装備を、説明なく「籠手」と「手甲」で交互に呼ばない。別部品なら、手甲を籠手へ留める、籠手の手甲部分、と関係が一度読めるようにする。革、鎖、板金など材質から可能な可動域と音を決め、材質名を強さの飾りにしない。

## 7. 監査の最終質問

各出現箇所で次を答える。

1. この名詞は物全体か、部位か、収納具か。
2. 直前の状態で、その動詞を実行できるか。
3. 使用後、その物はどこへ移り、何が変わったか。
4. その専門語は武器形式から確定できるか。
5. 同じ物を前後で別名にしていないか。

一つでも答えられなければ、専門語を増やす前に普通語と具体動作へ戻す。
