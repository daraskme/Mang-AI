# 公開物とローカルデータ

2026-10-09。Mang-AIと専用エンジンStrata-GLMを別のリポジトリとして公開し、エンジンの固定コミットを`integrations/strata-glm.json`で管理します。既存のソース・履歴・第三者ライセンスを維持します。

- 公開対象はソース、設定例、導入手順、試験、人工的なベンチマークの測定値です。
- モデル重み・pack・仮想環境・会話・作品・データセット・認証ファイル・ローカル設定のバックアップはGit対象外です。`.before-glm-*`も対象外にしました。
- 大容量のtrace、GPUの時系列CSV、作業セッションの生ログはローカル保管です。Devinの生セッションJSONも含めず、助言を掲載する場合は回答部分と採否だけを使います。
- GLMの公開JSONでは測定PC固有の絶対パスを変数表記へ置換しています。内容SHA256、固定モデルrevision、実験条件は残しています。
- 履歴の既知トークン形式・秘密鍵・認証付きURLを検査しました。旧UI検査にプロセス限定の起動トークン付きlocalhost URLがあり、現行ソースから削除しました。このトークンはDSHがプロセスごとに生成するもので、記録後のPC再起動により失効しています。履歴の当該文字列は残しています。現行の長期APIキーの検出はありませんでしたが、パターン検査で全ての秘密情報不在を証明するものではありません。
- GLM側の`data/glm5-synth.gguf`は上流由来の小さな人工的試験データです。ダウンロードしたGLMの学習済み重みとは別です。

今後コミットするときも、`git diff --cached --stat`と追加ファイルを確認し、認証URLやセッション状態をログごと追加しないでください。既存のAGENTS.mdへの利用者の編集はそのまま保存しています。
