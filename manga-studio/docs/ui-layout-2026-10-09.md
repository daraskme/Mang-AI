# UI整理と検証（2026-10-09）

Devin CLI 3000.10.48の **Claude Opus 5.5 High** に、現在の画面構造・重複する表示・利用者の要望を文章で伝えて相談しました。回答をもとに、チャットと制作スペースを移動しやすく整理しました。相談に利用者の会話本文・画像・認証情報は含めておらず、Opusによるスクリーンショットの視覚評価ではありません。

## 変更

| 場所 | 整理後 |
|---|---|
| チャットの担当AI | 適用中の担当を1行表示。クリックでアカウント・モデルを開き、明示的に適用。未適用表示・取消・セッション別の変更案保持 |
| 利用枠 | 制作進捗の上に残量・リセット。サイドバーの重複を除き、不明・古い取得値・エラーの区別を維持 |
| 制作進捗 | 具体的な工程 → ％バー → 工程・履歴／設定。処理中を先に、初期表示は2件、残りは展開 |
| ギャラリー | 埋め込み幅850px未満ではカテゴリ・フォルダを2つの選択欄へ集約。検索は展開式。「このセッション」を既定に、メディアを優先 |
| 空のギャラリー | 生成設定を開くボタンを用意。自動では生成しない |
| 埋め込み画面 | ブランド見出しや二重の余白を削減。親の明暗テーマを受け取り、iframeを再読み込みせず反映 |
| 入口 | 「制作スペース」へ名称を統一。セッション内の入口と、サイドバーの予備の入口を維持 |

割合は報告された進捗や完了コマ数から計算し、経過時間から捏造しません。完了・失敗・前回の取得値も必要な情報として残しています。Opus提案にあった新しい状態スキーマへの全面移行、セッション行へのバッジ、モバイル用ボトムシートは今回の変更に含めていません。

## 検証

実データと分離したDSHプロファイル、テスト用アカウント、模擬生成API、Chrome 153で確認しました。

- Nodeテスト52件の各ケースが成功。隔離コピーに既存ガイドラインがなく最初に1件失敗したため参照を補い、該当するprovidersの4件を再実行して成功。
- `accounts-browser.mjs`：残量・リセット、明示適用、未適用の変更保持、取消、別セッションへの混入防止、再読み込み・認証復旧。
- `session-dock-browser.mjs`：実DSHでギャラリー初期表示、担当欄の折り畳み、残量が進捗の上、会話の下書き・参照素材・生成プロンプトの保持、テーマ切替、狭い画面、利用者が閉じたパネルの状態保持。
- `workspace-browser.mjs`：実測値・不明・失敗・完了・切断復帰、未保存編集の移動保護、検索条件保持、空のセッションから設定へ移動、矢印・Home・End操作。
- `generator-browser.mjs`：モデル選択、既存履歴、長尺動画の計画、モバイル幅。
- `models-browser.mjs`：モデル・LoRA強度、用途、サムネイル、再読み込み、セッション分離。

760px幅の制作スペースで最初の画像カードがギャラリーフレーム上端から170px以内に出ることを検査しています。390 / 520 / 849 / 850 / 851px幅でギャラリーの横方向のはみ出しがないこと、1600pxと390pxの実DSH画面も確認しました。生成品質・速度はこのUI試験の対象外で、GPUによる新規生成は実行していません。

## 保存と更新

タブやテーマの切替では訪問済み画面を保持します。ギャラリー条件・未適用の担当選択はセッション別の`sessionStorage`です。別ブラウザへの同期や、未保存の漫画・画像編集、生成プロンプトのページ再読み込み後の全面復元は保証しません。保存済みアカウント・担当・素材参照は従来どおりサーバー側に残ります。

新しい`frame-theme.js`と`embedded.css`を配信するため、この更新時はMang-AI Webサービスの再起動が必要です。実行中の会話・外部担当・生成・ログインを終えてから更新し、編集中の内容を保存したうえでブラウザを再読み込みしてください。
