# 生成情報と投稿用コピー

Krea2の通常出力はPNG内のEXIF UserCommentとPNGテキスト、隣接JSONにプロンプト・モデル・LoRA/強度・seed・サイズ・steps等を保存します。Mang-AIの公式Python直接生成もEXIFとPNGテキストへ生成条件を記録します。H3は動画コンテナのメタデータとJSONへ生成条件を保存します。動画の情報は厳密にはEXIFではありません。

ギャラリーで画像・動画を開き、**「投稿用に保存（生成情報・EXIFなし）」** を押すと、生成情報、EXIF、GPS、XMP、テキストコメント、動画のタイトル・チャプターなどを除いたコピーをダウンロードします。原本は変更せず、ローカルにも `dataDir/.posting-copies/` に保存します。A1からは `media_export_clean(file:絶対パス)` で同じ処理を使えます。

- PNGは圧縮された画像データをそのまま保持し、メタデータチャンクを除きます。表示に必要な色管理情報は保持します。
- JPEG/WebP/AVIF/BMPは向きを反映してPNGへ保存します。再び非可逆圧縮することはありませんが、ファイルが大きくなることがあります。
- 動画は映像・音声を再エンコードせず、選択した映像と音声だけを同じ形式の新しいコンテナへ移します。ffmpegが必要です。任意データストリームは引き継ぎません。
- 画像そのものに描かれた文字や透かし、映像の内容は変えません。投稿用コピーは再生成設定の読み戻しには使えません。

生成情報を残した元ファイルと、情報を除いた投稿用コピーを区別してください。この機能でSNSへの投稿を自動実行することはありません。

# 長い処理の進捗

表示順は **具体的な工程・処理数・残り時間 → 全体％バー → 設定** です。Krea2、H3、Caption Studioの学習画面と統合生成画面へ配置しています。

H3生成画面とLoRA学習画面は全体％・現在工程・経過時間・残り時間の概算を表示します。読み込み直後や順番待ちは「計算中／未定」。複数回の実測進捗が得られたら見積もりを表示し、進捗が止まった場合は古い見積もりを表示し続けません。失敗・停止で100%にはせず、正常な保存完了時に100%になります。

全体％は読み込み・キャッシュ・生成／学習・保存の工程配分に基づきます。残り時間は現在の実測速度による概算で、GPU待ち、I/O、キャッシュ状況、保存処理によって変動します。学習はキャッシュ工程が終わり実際の学習stepが進んでから全体の残り時間を見積もります。H3の新規LoRA学習は引き続き未統合です。
