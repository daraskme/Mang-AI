# 会話とメディアを一緒に使う

標準の会話画面にギャラリーを表示します。幅1024px以上では会話を開くと右側の制作スペースが初期表示され、同じ場所の上部に進捗バーが残ります。一度閉じたパネルや復元済みのタブは、会話を切り替えても強制的に開き直しません。画面の明暗も会話側に合わせます。

左下の **ライトモード／ダークモード** ボタンで全画面を切り替えます。ボタンには現在のモードを表示し、押すと反対へ切り替えます。サイドバーが狭い場合は太陽／月のアイコンになり、名前はツールチップと読み上げ用ラベルに残ります。Harness標準設定と共通なので再読み込み後も保持し、標準設定からの変更もボタンに反映します。同じoriginの単独編集・生成タブも開いていれば追従します。元画像や漫画用紙の色はそのままです。

入力欄の上には、そのセッションで生成・編集した画像・動画と漫画ページを最大8件表示します。狭い画面ではその上に残量と進捗バーも表示し、会話を入力できる領域を保ちます。生成・編集の詳しい画面は **制作スペース** から開けます。生成物が増えると自動更新されます。別の会話の生成物は混ぜません。ネイティブKrea/H3画面だけで生成し、セッションIDを持たない出力は「すべての素材 → 生成環境の履歴」で確認します。

## 参照素材とA1への指示

入力欄上のサムネイル、またはギャラリーの **会話で使う** を押すと、その会話の参照素材として保存します。選択だけでは生成・修正・メッセージ送信を開始しません。

**参照名をコピー** で `[画像 ID]` / `[動画 ID]` / `[漫画 ID]` を指示文へ貼り付けられます。A1は `media_context(referenceId:ID)` でその素材を取得します。選択を後から変えても、以前コピーしたIDは同じ素材を指します。IDを登録していない別セッションからの解決は拒否します。IDなしの `media_context` は現在の選択とモデル・LoRA設定を返します。

選択状態はセッションごとに保存されます。「解除」は現在の選択を外し、元の画像や過去の参照記録は削除しません。ギャラリーから他の素材を明示的に選んで、この会話で参照することもできます。

## 制作スペース

閉じた制作スペースは、参照素材の上・セッション上部・サイドバーにある **制作スペース** から再表示できます。

幅850px未満の埋め込みギャラリーでは、カテゴリと作品・フォルダを選択欄へまとめ、検索は必要なときだけ開きます。「このセッション」のメディアを優先し、カテゴリ・検索・フォルダの選択はセッション別に同じブラウザタブへ記憶します。空のセッションでは **画像・動画の生成設定を開く** から生成設定を開けます。この操作だけではジョブを開始しません。制作タブは左右矢印・Home・Endでも切り替えられます。

| タブ | 操作 |
|---|---|
| ギャラリー | この会話／全体の素材、プレビュー、会話で使用、投稿用コピー、編集 |
| 生成 | 同じ会話のKrea/H3/長尺動画の生成と履歴 |
| モデル・LoRA | モデルとLoRAの選択、強度、サムネイル設定 |
| 編集 | 漫画の文字入力、画像補完、モザイク |

**進捗はタブを切り替えず、上部で確認します。** 漫画の作画は生成済みコマ数＋現在のコマの報告進捗をバーに反映します。単独のKrea/H3/長尺動画も、登録された直近12ジョブの状態を読み取ります。取得できない割合を経過時間から作らず、読み込み・Gemma処理・GPU待ちなどは不定長バーにします。失敗・中止・完了を表示し、接続エラー時は前回の値であることを明示します。**工程・履歴** を開くと漫画の各工程、処理履歴、PC全体のGPU待ち行列を確認できます。

進捗の更新間隔は2秒です。生成環境にはジョブ状態のGETだけを送り、表示を理由にサービス起動・モデル読み込み・生成・結果ファイル取得を行いません。同時の状態取得はまとめ、完了済みジョブの反復問い合わせを避けます。

タブは一度開いたiframeを保持し、タブ・明暗テーマ・セッションの切り替えでもプロンプト・検索条件・未保存の編集を保ちます。別の編集対象を開くときは未保存の文字・マスクを確認します。ギャラリーの条件と担当選択の変更案は再読み込みでも保持しますが、生成プロンプトや未保存の漫画・画像編集の全面的な復元は未実装です。終了・再読み込み前には保存してください。

セッション内のギャラリーは6秒ごとに更新します。プレビュー中、検索中、追加ページを表示中は自動で一覧を置き換えません。会話上の小さな一覧は4秒ごとに更新し、非表示では停止します。利用者が選んだ素材や下書きを新着で置き換えることはありません。

## 検証

`tests/session-media.test.js` は、セッション間の分離、参照IDの永続記録、異なるHost/Originの拒否、同一URL配下でのAPIを検証します。`tests/session-dock-browser.mjs` は独立したDSHプロファイルでギャラリーの初期表示、参照選択、セッション切り替え、実際の会話入力欄の下書き保持、生成画面、スマートフォン幅を確認します。`tests/workspace-browser.mjs` は同じ画面のバーに進捗率・不明・失敗・完了・一時切断を反映し、未保存の文字を保持することを確認します。`tests/progress.test.js` は単独生成の状態取得の分離・重複防止・切断復帰も確認します。GPUや実モデルは使いません。

Devin CLIのOpus 5.5へ一般的なUI構成を相談し、会話ごとの状態保持・明示的な参照名・非同期更新時の混入防止を反映しました。利用者の画像・会話・認証情報は相談文に含めていません。
