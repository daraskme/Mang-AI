# Harnessと制作画面のテーマ統一（2026-10-09）

左下の「制作スペース」の下にライト／ダーク切替を追加しました。現在のモードを表示し、クリックで反対のモードへ切り替えます。サイドバーを畳むとアイコンだけになり、文字の縦折り返しやはみ出しを防ぎます。

## 対象

生成、モデル・LoRA、文字編集、修正・モザイク、ギャラリー、制作進捗、AIアカウントの背景・文字・境界線・操作部品・フォーカス色をHarnessと揃えました。生成フォームの独立した暗色スタイルを廃止し、設定と結果の見出しを整理しています。編集画面内の進捗カードとダイアログも明暗に追従します。

漫画の白い用紙、画像・動画の画素、修正マスク、SVG/PNGの書き出しには画面テーマを適用しません。ライト／ダークはアプリの操作部分の表示設定です。

## 設定と同期

- 設定の正本は導入済みDeepSeek Harnessの`ctx.theme`です。切替には`setTheme('light' / 'dark')`を使い、標準設定の外観と同じ保存先を利用します。
- 外観を標準設定で変更した場合も`theme/change`に追従します。設定にある「システム」の選択肢も残し、左下ボタンを押した時点で明示的なライト／ダークへ変更します。
- 埋め込み先にはHarnessで解決済みの配色、フォント、角丸の値だけを渡します。色を別々に推測する実装をやめ、実際のテーマ属性を参照します。
- 親フレーム・originを確認したテーマ通知と、同一originの外観キャッシュを使います。キャッシュは認証情報を含まず、別タブの描画に使う表示値です。テーマ設定の正本ではありません。
- iframeのURLやDOMを交換しないため、未保存の生成プロンプト、LoRA強度、台詞、マスクを保ったまま切り替わります。
- `localhost`とTunnelのURLは別originです。単独タブの外観キャッシュはoriginごとですが、それぞれのMang-AI本体を開くとHarnessの保存済み設定が反映されます。

## 検証

実データと分離したDSH、Chrome 153、模擬モデル一覧で8種類のブラウザ試験が成功しました。GPU生成や実アカウントのテーマ変更はテストに使用していません。

| 試験 | 確認内容 |
|---|---|
| `session-dock-browser.mjs` | 実際の左下ボタン、Harnessと制作画面の背景色・文字色・角丸一致、明暗双方、設定側からの変更、別ブラウザコンテキストで保存済み設定を取得・再読み込み、単独タブ同期、下書き・LoRA強度・台詞の保持、iframe URL不変、狭いサイドバーのアイコン表示 |
| `theme-media-browser.mjs` | 修正・モザイクの明暗、元画像と未保存マスクのcanvas出力が切替前後で同一、同一originの単独タブ同期、390px幅 |
| `workspace-browser.mjs` | ギャラリー、進捗、タブ、未保存編集、390〜851pxの境界幅 |
| `generator-browser.mjs` | 生成設定、モデル選択、長尺動画の計画、モバイル |
| `models-browser.mjs` | モデル・LoRAの選択、用途・強度、サムネイル、保存・再読み込み |
| `browser.mjs` | 台詞の保存・ドラッグ・脚本確定・SVG/PNG書き出し、モバイル |
| `accounts-browser.mjs` | 担当・残量・未適用変更、認証復旧、モバイル |
| `progress-browser.mjs` | 処理中・失敗・完了・保存前の台詞を保持しながらの自動更新 |

初回の追加タブ試験はPlaywrightの一時ページ用コンテキスト制約で失敗したため、明示的なコンテキストへ直して再実行しました。見た目の確認で編集内進捗の旧配色と狭いサイドバーの文字折り返しを修正し、関連試験を再実行して確認しています。生成モデルの品質や速度を再評価した変更ではありません。
