■━…‥・　このフォントについて　・‥…━■

源暎アンチックは自由で便利に使える「アンチゴチ」として作成したフリーフォントです。

このフォントは「書体は水や空気のようであれ」を原点として、製作者が理想とするアン
チック体を目指し「ニュートラルで懐が広く、明るい仮名」にまとめてみました。

※ アンチゴチ … 線の強弱が弱い太目な楷書の仮名書体「アンチック体」と、漢字や英
 　　　　　　　　数字等を「ゴシック体」で補完したフォントの組み合わせを指す。
 　　　　　　　　一般的に漫画の肉声セリフで用いられるため「コミック体」とも

作成するにあたり「源ノ角ゴシック」や「F910新コミック体」など沢山のオープンソース
フォントをお借りしております。詳しくは下記をご参照ください。
詳細や最新の情報はサイト（http://okoneya.jp/font/genei-antique.html）をご確認ください。

　※ 注意 ※
Ver 4.0 とそれ以前のバージョンには仮名の形や詰め組み情報などが大きく変更されてい
ます。ファイル名およびフォント名を変えておりますので使い分けなどの際はご注意ください。

特に外字として用意していた「!!」や「!?」などの記号類は実装位置を変更していますの
で、以前のバージョンからの切り替えや辞書登録時などは特にご注意ください。

Ver 5.0 で私用領域などに「濁点付き仮名」が追加されましたが、対応アプリでのみご利
用いただけます。後、独自実装なのでわざわざ合わせていただいているフォント以外で表
示した場合に文字化けします。基本的に公開時には画像化やアウトライン化してください。

■━…‥・　リガチャ（合字）について　・‥…━■
　※　私用領域は源暎アンチックの勝手な実装です。他フォントで表示できません　※

従来はリサイクル記号部分に「!!」や「!?」などを組文字にした字を置いてましたが、他
のフォントとの互換性などから Unicode の規定に準拠するように作り直してあります。

そのため「‼」「⁇」「⁈」「⁉」は Unicode の一般句読点に割り当てられています。
その他、斜体バージョンや「!!!」の組文字や独自記号類はは私用領域に置いております。

Photoshop などの OpenType Font のリガチャ機能に対応しているは全角の「！」「？」を
続けて入力すれば自動的に組文字に置き換えられます。加えて、その直後に「・」を入力
すると斜体文字バージョンに置き換えられて便利です。

・Photoshop では直接「‼」「⁇」「⁈」「⁉」を縦組み時に使うと「欧文だと判断」されて
　横倒しされた状態になります。上記リガチャ機能を使うか、縦中横を使ってください。

・CLIP STUDIO PAINT ではリガチャ機能が動作しません。フォトショとは違い、直接入力
　で問題なく利用できるため文字一覧などから入力してご利用ください。

・その他のアプリでは Unicode 非対応ではない限りは上記のどちらかが有効と思われます。


■━…‥・　濁点付き仮名について　・‥…━■
　※　濁点付き仮名は源暎アンチックの勝手な実装です。他フォントで表示できません　※

Ver 5.0 より標準日本語で濁点が付かないひらがなやカタカナにも濁点を付けられる独自
仕様が実装されています。これにより「あ゙」などを使う事が出来ます。

公開を優先したため、濁点付き仮名は文字詰め情報などが含まれません。ご了承ください。

・濁点付きの仮名や半濁点付き「かきくけこ」等は、清音の仮名と合成用濁音(U+3099)／
　半濁音(U+309A)を続けて入力する方法でも、私的領域に割り当てた文字コードから使用
　する事も出来ます。ご利用アプリで正しく表示される方でご利用ください。
　→ 例：「あ゙」（U+3042 と U+3099（結合用濁点）の組み合わせ）／「」（私的領域 U+E082）

　※ Unicode のコードで直接入力する方法（例は結合用濁点 U+3099 を入力する場合）
　・Windows 環境で MS-IME を使う場合
　　… 3099 などを日本語入力モードで入力し[F5]キーを押す。
　・Windows 環境で ATOK を使う場合（事前に「記号入力モード」を有効にする）
　　… [F10]キーを何度か押してコード入力モードに切替、3099 などを押す
　・macOS 環境の標準機能を使う場合
　　… 入力ソース「Unicode 16進数入力」を使用し[Option]キーを押しながら4桁入力。
　・Google日本語入力を使う場合
　　… アルファベット入力モードで U+3099 などと入力し変換する。

■━…‥・　インストールについて　・‥…━■

各 OS のヘルプや解説サイトを参照してください。
Windows の場合はフォントファイルを右クリックして「インストール」を選びます。

最近の Windows 10/11 では右クリックメニューから「インストール」した場合は、その
アカウントのみで使用でき、「すべてのユーザーに対してインストール」した場合は
すべてのアカウントで利用できるようになっています。
