# tests — 検査系の回帰テスト

`guidelines/` や `scripts/check.sh` の検出ルールを変更したとき、意図しない検出漏れ・誤検出が入っていないかを確かめるための固定データ。

```bash
bash scripts/eval.sh
```

## 中身

| 場所 | 内容 |
|---|---|
| `fixtures/*.txt` | 本文の検査用サンプル。違反を意図的に埋め込んである |
| `fixtures/state-repo/` | 状態台帳の検査用サンプル。矛盾を意図的に埋め込んである |
| `fixtures/repeat/` | `repeat_check.py` 用サンプル。話またぎの逐語一致と allowlist 抑止を意図的に埋め込んである（期待件数は `eval.sh` 内に直書き） |
| `fixtures/vocab/` | `vocab_check.py` 用サンプル。監視語の上限超過と上限内を意図的に埋め込んである（期待件数は `eval.sh` 内に直書き） |
| `expectations.tsv` | 各fixtureの期待 exit code と `[NG]`／`[警告]` 件数 |

## 注意

**`fixtures/` の中身は、わざと規約違反を含んでいる。** キリル文字やハングルの混入、マークダウン痕跡、三点リーダの派閥揺れは意図的なもので、修正してはいけない。リポジトリ全体を対象にした表記の一括修正では、このディレクトリを除外する。

検出ルールを意図的に変えたときは、`expectations.tsv` の件数も一緒に更新する。件数を変えずにルールだけ変えると、このテストが落ちる。

配布zipには含めない（テンプレート保守側の道具）。
